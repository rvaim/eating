# Eating 数据归属与隔离

状态：2026-11-02。归属与可替换 Harness 原则已确认，当前 EATING_HOME 布局及严格格式已实现；默认不兼容旧版由 [ADR-0015](../decisions/ADR-0015-默认不兼容旧版.md)确定。加密、三平台 ACL、远端记忆隔离和跨 Harness 迁移仍需独立设计与验证。当前应用／Host／Web0.15.0、plugin-sdk4.5.0、ui-sdk4.1.0、plugin-core4.0.0、QQ0.13.2、DSH0.13.1，仅API4；作者默认生命周期见[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)。

| 数据 | 责任方 | 约束 |
| --- | --- | --- |
| 固定核心人格、分层提示词 | Eating 主人受保护配置 | Agent 不可自行写；schema2、CAS和来源受控，所有代理引用同一启用人格，也可明确为空；提示词以updatedAt:null跟随默认，非null保留主人覆盖 |
| 人格模板与未保存草稿 | 前端静态模板目录与当前页面内存 | 选择模板只填新增草稿正文，不自动创建／启用，不保存模板ID；主人显式保存后才成为普通人格，locale不改正文 |
| 兴趣／关系／经历等长期记忆 | 所选 Harness 可用且主人授权的插件／机制 | 不复制成 Host 人生记忆库；说明本地／远端存储和故障 |
| 会话、上下文、Agent 事件 | 所选 Harness 的实际持久化机制 | 不由 Host 手改内部格式；恢复能力须实测，不假设可跨 Harness 导入 |
| 待交接信封、逻辑身份与运行映射 | Eating | 有界可靠性数据，不冒充 AI 记忆；保留实际来源元数据与未决投递归属 |
| 授权记录、操作账本、安装清单 | Eating | 可信执行者写入；敏感信息脱敏，unknown 不自动重放 |
| 模块配置、注册与资源归属记录 | 各模块通过 Eating 受控接口管理 | 按模块命名空间划分；不得越权删除其他模块数据或全局注册 |
| 平台历史／附件 | 平台与通讯模块 | 按需读取、来源标记、最小保留、联系人范围保护；Eating 不建设聊天历史库 |
| 模型／平台凭据 | 各模块独立受控配置 | 不回显、不进代码／报告／普通日志；当前本地存储不等于已验证系统密钥库或三平台 ACL |

## 根目录与当前格式

统一 `EATING_HOME`，默认 `~/.eating`。Host 队列、动作账本、令牌和运行锁在 host；插件可执行产物在 plugins；机器人配置在 bot 下各插件自管目录，QQ 使用 qq-bot 的 accounts.json 与 accounts/<instanceId>/config.json。Harness 配置、专属运行时、会话和工作区在 harness/<声明目录>。本地 instanceId 稳定且独立于实际 QQ 号；当前只运行一个默认账号。详见[目录与账号规范](../technical/数据目录与账号实例.md)。

各数据格式独立编号，版本号不构成统一迁移开关：

| 数据 | 当前格式与读取边界 |
| --- | --- |
| Host SQLite | user_version=1 且完整当前表形状；旧库、缺表／列或不匹配结构在写入前拒绝，不自动补列、复制旧表或标为当前版本 |
| 提示词与人格 | 唯一 schema2；6 种模板作用域、9 个受信变量，scope／source 必填，无旧群私模板、legacy 集合与外部消息变量 |
| QQ 配置 | schema2 wrapper，完整 11 个配置字段；只有文件不存在才使用完整新实例默认值，坏文件或旧字段不回退成功 |
| QQ 账号索引 | 当前严格 schema1；不从旧单文件或缺字段配置推断并补建实例 |
| 插件安装索引 | 当前严格 schema1；清单、后台入口与实例 kind 必填一致，只接受 API4 |
| DSH 配置／主会话映射 | 各自当前严格 schema1；缺必要字段与旧形状明确拒绝 |
| DSH agent-bindings | schema2，任务 ID 与 refs 必填，不恢复旧无任务 ID 索引分支 |

旧格式明确报错且原数据不被转换、覆盖或删除。仓库没有旧版迁移脚本，也没有旧浏览器 prototype 存储公共入口或 persistence 路径转发；plugin-core 仅保留当前纯注册与[配置类型](../../packages/plugin-core/src/configuration.ts)。坏配置只在对应页面显示错误，不生成可写空表单或补权限默认值。

当前接口明确规定的连接 PATCH、省略字段保留、空 Key 保持、正常重连、同版故障恢复、原生 ACK 重建、幂等和新实例完整默认配置仍保留。OneBot v11 正式协议别名及 OpenAI 接口属于当前外部协议能力，不是旧 Eating 兼容。

## 当前作者存储与默认生命周期

[作者服务](../../apps/host/src/authoring.ts)使用Host SQLite中的`host:authoring`单JSON保存schemaVersion2、全局revision、prompts、personas和activePersonaId，总量不超过5MiB。三份基础文档始终存在；未编辑插件默认按当前注册目录生成，不因读取而保存成副本。曾编辑或恢复的角色／插件文档记录保留，仍受现有数量与字节上限约束。

提示词`updatedAt:null`表示读取时跟随当前代码或注册默认；这既包括从未编辑的revision0，也包括恢复后的正revision。非null合法时间戳表示使用主人保存的body。旧默认副本仍可留在当前schema2存储内，快照、Harness配置与组合在内存解析最新默认，不为更新默认写库。自定义正文不会被升级覆盖；同正文保存核对CAS后只读，不通过正文相等推断跟随。

恢复默认只更新指定提示词：文档revision和全局revision各加一、`updatedAt:null`，保留其他提示词、人格及启用关系。插件恢复记录不能删除归零，卸载也保留，以防旧revision在重装后重新满足CAS；来源缺失时拒绝写入。已跟随默认且版本匹配时只读；陈旧CAS、版本耗尽、容量超限和存储失败保原数据。队列、动作账本、账号配置和会话不属于恢复范围。

[静态模板目录](../../apps/web/src/persona-templates.ts)本轮只有“AI女儿”，不写入作者JSON。套用只填新增人格未保存草稿正文，保留主人已填名称，已有非空正文先确认；不自动创建、启用或迁移数据。显式保存后成为普通人格，不记录模板关联，也不随模板更新回写。模板与人格不是经历／关系记忆库，实际记忆归所选Harness当前可用且获授权的机制。

上述规则使用当前schema2的既有字段，没有旧schema迁移、字段补齐或兼容读取。接口与操作见[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)和[提示词与人格模板](../operations/提示词与人格模板.md)。

## Harness 与 DSH 独立数据

每个适配器须声明并核对配置、用户数据、会话、工作区、插件、缓存和凭据的实际解析范围，不能套用 DSH 环境变量。模块后台与面板通过 Eating 契约注册，见[插槽式扩展](插槽式扩展.md)；Host 最终 Cordis 底座仍未选定。

DSH 使用 Eating 自己的 DSH_HOME、DSH_AGENTS_HOME、runtime-home、Profile 与工作区，不借用户主 DSH 的配置、插件、Key 或会话。agents home 与 DSH home 分别核对；同一 home 的 Profile 行为只属于当前已核版本，不能推导其他 Harness 的隔离。源码依据见[DSH 研究](../research/DSH源码核对.md)，当前实现与验证见[本轮报告](../reports/2026-10-29-删除旧版兼容验证报告.md)。路径分开不等于 OS 权限隔离，也不保证记忆插件使用独立远端命名空间。

Eating 只保存有界未交接规范化信封，senderRole／resourceIds 等公开来源元数据须校验并持久保留。可靠交接依赖原生 sessions.flush 成功与匹配原子 ACK；接纳不等于模型已读、任务成功或动作完成。内存队列退出会丢失未交接消息，持久队列支持当前格式的同版恢复；可靠交接后删除正文，未知动作不盲目重放。

## 单实例与版本处置

同一数据集需取得跨进程排他运行权后才能激活主认知控制者；Host 锁已实现，三平台及更多故障窗口仍须验证。同一时刻只允许一个活跃主控，不支持多设备共同运行或自动切换。

未发布及未来发布均默认不兼容任何旧 Eating 版本，只有用户明确指令才设计兼容、迁移或回退例外。设计须核对源实例停止状态、目标版本、数据与凭据边界、快照及验证方案，设计本身不授权执行。无法确认旧主控已停止时不得激活新主控。跨 Harness 的会话／插件／记忆无损迁移、运行中热切换和能力等价仍未承诺，见[Harness 适配](Harness适配.md)。

删除兼容代码不授权删除、重置真实 `~/.eating`；本轮没有部署，也没有处置真实数据。新 EATING_HOME 初始化的是新实例与新会话，不能描述为已迁移原人格、会话或记忆。保留旧原文件也不表示新版能够读取它们。远端记忆不能假设本地目录备份即可覆盖，记忆机制失效须明确报告，不能以运行日志冒充记忆。

## 停用、保留与删除

模块停用停止新工作与准入、撤销工具／令牌和界面贡献并释放自身资源，保留配置、未交接队列、恢复映射、动作账本和必要授权证据。未能取消的在途或远端动作继续对账；卸载不能抹去不确定性，也不能影响其他模块。

停用、移除可执行包与删除用户数据分别授权。凭据保留／吊销、本地配置删除及远端记忆删除须有明确主人指令，不能默认为一并清空；保留审计记录不等于旧授权继续有效。清空／缩容队列须显式确认，不删除账号配置与动作账本。

实时日志仅可见页签订阅，浏览器内存有界；隐藏、离开、关闭或停用立即停止并清空，不落盘、不后台缓存、不补历史。附件、操作账本的更长期保留、导出、加密与删除策略仍待分别确定，不能无限保存私人聊天。
