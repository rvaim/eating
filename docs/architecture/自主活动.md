# Eating 自主活动与唤醒

日期：2026-11-02，Asia/Shanghai。主 Agent 当前轮次联系权限按[ADR-0032](../decisions/ADR-0032-主Agent当前轮次联系权限.md)，定时协调、统一名单和实际活动时长分别承接[ADR-0023](../decisions/ADR-0023-自主活动协调与主动通讯授权.md)、[ADR-0025](../decisions/ADR-0025-统一主动联系名单策略.md)、[ADR-0031](../decisions/ADR-0031-自主运行状态与可选能力降级.md)。DSH0.12.1的实际验证与限制见[本轮报告](../reports/2026-11-02-主Agent当前轮次联系权限验证.md)；仅独立工作树交付，未部署真实实例。

## 认知与活动机会

同一 Eating 身份只有一个当前主认知控制者。主 Agent 在所有轮次自主决定是否行动、继续、委派、等待或休息，子 Agent 是受限执行者。QQ群／私聊消息、原生主输入、目标续行和定时唤醒提供不同来源的活动机会；来源不决定联系权限，也不将外部正文升级为主人指令。

Eating 不调用另一模型生成生活计划，不用固定任务池或随机提示制造兴趣，不自建第二个 Agent Loop 或长期人生记忆。Host 提供事件、机械调度、授权与恢复；认知及上下文由所选 Harness 承担。

## 无输入时的定时机会

- 同一 DSH 主 Agent 以公开 `Agent.followup` 接收 `eating-autonomy` 来源的机会。1秒机械检查只读状态／时间，不请求模型；保存周期 ID／runtime nonce 后入原生 Inbox，pre-step 再核对。
- Host 可投递或投递中的外部工作、原生 Inbox、armed 目标优先。原生 Schedule 与目标续行保留各自语义，定时协调不重复启动另一循环。
- `enabled`／`ownerPaused` 仅控制无输入时的定时机会，默认关闭，保存配置与开始分开。定时活动关闭、暂停或 AI 等待时，普通有输入主轮次仍可处理工作并联系获准目标；真正自主机会被取消时撤销该轮联系许可。
- AI 先用 `eating_activity_state` 读取 revision，再以 `eating_plan_activity` 登记 active、sleeping 或 waiting。waiting 不产生空模型请求，新消息也不自动把安排改为 active；正文承诺或记忆记录不安排唤醒。

子回执不强制结束当前工作。主 Agent 核对真实结果和未知状态后，可在当前有效许可内继续委派，再决定后续活动安排。人格可影响兴趣和表达，经历连续性依赖当前上下文与实际可用记忆；人格不授予权限或自动共享全部会话经历。提示词约定见[操作说明](../operations/提示词与人格模板.md)。

## 当前轮次的联系许可

真实主 Agent 的原生当前 turn 可调用 `eating_list_contact_targets` 读取对象及精确工具，再以 `eating_contact_target` 提交返回的 `target_id` 和任务。QQ群消息后可联系获准私聊，无需目标先发私聊。后台核对主 Agent 与原生轮次、插件／账号实例／实际账号、类型、对象及工具交集，由受限原生子 Agent 执行，主 Agent 取得 Host 真实回执，不持有全权 QQ 令牌。

普通 `eating_delegate_task` 继续使用当前入站批次的可信 `context_ref` 及消息／资源 scope，群聊 context 不能作为私聊授权；跨目标走联系策略。联系任务不继承旧入站消息／资源引用，不能用旧列表绕过当前策略。

统一 all／allowlist／denylist 同时筛选私聊与群聊。all 允许当前好友和已加入群，空白名单全禁，空黑名单等于全部放行；私聊／群聊只是对象分类，工具仍由原代理权限页管理。列出与准备任务时重新解析当前目录、账号、策略及工具权限。

所有联系任务共用 `maxContactsPerHour`，普通输入、原生目标和定时来源均计入；计数单位为任务，单任务内仍逐次校验工具／目标。保存联系策略核对 CAS，暂停定时活动并撤销旧联系许可；后续任务按新策略重新准入。

## 撤权、防重与恢复

当前 turn 结束、abort、主 Agent 销毁或 runtime 停止时撤权，真正自主机会取消也撤销该轮许可。Host 在真实调用、资源取得后及发送前复查许可与 AbortSignal。旧轮次或迟到调用不能恢复权限，已接受的外部动作不会因撤权自动撤回。

`proactive-bindings.json` 保持严格 schema1、稳定子 UUID 及有界 callId 摘要。`cycleId` 保留为内部联系轮次引用，不迁移、不恢复旧许可。每目标当前轮次最多32个 callId 引用，超额拒绝而不遗忘防重记录；重复／pending／unknown 拒绝，迟到完成不能覆盖 unknown。新 runtime 把遗留 pending 转 unknown；主人核对实际结果后可解除任务阻塞，不删除动作账本或重发。

定时周期另受单轮时长、实际连续活动时长、小时轮次及失败阈值约束；睡眠、等待和停机不计实际活动时长。中断周期 unknown 不重放，自动恢复为主人选项，仍保休息／等待；错过唤醒只合并当前一个机会。状态／配置持久化失败明确报错并拒绝新任务。

## 设置与证据

设置→自主运行显示概览、运行设置和主动联系。配置／活动 revision、wakeAt、窗口计数和最近20项无正文结果保存在独立 `autonomy.json`／schema1；模型状态只提供联系策略摘要，实际对象须重新读取。状态只在页面可见时每5秒读取，隐藏／离页取消；locale 不触发请求或覆盖草稿。详见[配置与查看](../operations/自主运行配置与查看.md)。

此前定时机会的隔离系统 DSH／模型／OneBot 回环是旧阶段证据，见[历史报告](../reports/2026-11-01-自主运行与设置面板验证.md)；DSH0.12.1的群转私聊、官方Web session/prompt输入、定时联系及暂停unknown四项真实回环通过；目标续行仅有runtime单元覆盖，Web浏览器输入控件未单独验证，未部署。额度是轮次、时长及任务数，不是账单金额或每目标消息条数。长期行为与记忆质量、真实提供商和其他 Harness 仍需分别验证，关机／休眠不保证准时触发。
