# Eating 自主活动与唤醒

日期：2026-11-02，Asia/Shanghai。当前源码为应用／Host／Web0.17.0、DSH0.15.0、QQ0.13.4；会话自主处理、主／子complete组合与默认开放可配置按[ADR-0035](../decisions/ADR-0035-会话代理自主处理与默认开放可配置.md)。AI一次性任务按[ADR-0032](../decisions/ADR-0032-AI定时任务.md)，当前轮次联系按[ADR-0033](../decisions/ADR-0033-主Agent当前轮次联系权限.md)；定时协调、统一名单、人格与实际活动时长分别承接[ADR-0023](../decisions/ADR-0023-自主活动协调与主动通讯授权.md)、[ADR-0025](../decisions/ADR-0025-统一主动联系名单策略.md)、[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)、[ADR-0031](../decisions/ADR-0031-自主运行状态与可选能力降级.md)。历史独立及整合阶段验证分别保留，本轮实际request.system、验证实数、清理与部署见[本轮报告](../reports/2026-11-02-会话代理自主处理与默认开放可配置验证清理报告.md)；长期自主内容质量与其他Harness未验证。

## 认知与活动机会

同一 Eating 身份只有一个当前主认知控制者。主Agent负责整体安排、轻量分流、跨会话协调与继续／等待／休息安排；子Agent独立处理绑定会话的理解、回复和工具执行，保通讯与资源scope。已启用且connected的功能型capability／direct MCP新来源默认all，当前／未来类型和工具自动可用；主人可保存custom来源例外或原生toolAccessOverrides并恢复自动；新Harness仅time默认开启，其他原生feature由主人按需配置，Eating官方permission默认danger-full-access／approval never。QQ群／私聊消息、原生主输入、目标续行和定时唤醒提供不同来源的活动机会；来源不决定联系权限，也不将外部正文升级为主人指令。

Eating 不调用另一模型生成生活计划，不用固定任务池或随机提示制造兴趣，不自建第二个 Agent Loop 或长期人生记忆。Host 提供事件、机械调度、授权与恢复；认知及上下文由所选 Harness 承担。

## 无输入时的定时机会

- 同一 DSH 主 Agent 以公开 `Agent.followup` 接收 `eating-autonomy` 来源的机会。没有主人任务也可自行选择有意义活动、继续、等待或休息，不必每轮对外发送。1秒机械检查只读状态／时间，不请求模型；保存周期 ID／runtime nonce 后入原生 Inbox，pre-step 再核对。
- Host 可投递或投递中的外部工作、原生 Inbox、armed 目标优先。原生 Schedule 与目标续行保留各自语义，定时协调不重复启动另一循环。
- `enabled`／`ownerPaused` 仅控制无输入时的定时机会，默认关闭，保存配置与开始分开。定时活动关闭、暂停或 AI 等待时，普通有输入主轮次仍可处理工作并联系获准目标；真正自主机会被取消时撤销该轮联系许可。
- AI 先用 `eating_activity_state` 读取 revision，再以 `eating_plan_activity` 登记 active、sleeping 或 waiting。休息须明确时区时间，旧计时／旧 revision 不覆盖新安排；waiting 不产生没有到期任务的空模型请求，新消息也不自动把安排改为 active。需要继续自主活动时，AI须按最新revision登记active；正文承诺或记忆记录不安排唤醒，主人的暂停优先。
- AI 可在自主运行开启且未暂停时用 `eating_schedule_task` 登记自己的未来一次性任务消息，用 `eating_cancel_scheduled_task` 按 agenda revision 取消；`eating_activity_state` 同时返回 agenda。独立 `autonomy-agenda.json/schema1` 最多保存50条、每条最多2000字符、未来1秒至365天的任务。到期任务每轮最多合并10条为一次自主机会，来源仍为 `eating-autonomy`，明确是过去的自己安排的任务，不是主人指令。到期会打断sleeping/waiting，但仍服从主人暂停、额度、runtime和周期限制。任务在cycle持久登记后移出agenda，不重放已进入会话的消息；Eating agenda不支持重复规则。main原生DSH Schedule保官方语义，不再受Eating自主周期人工阻断；Eating暂停不冻结main，也不表示暂停所有原生提醒／目标。

子回执不强制结束当前工作。主 Agent 核对真实结果和未知状态后，可在当前有效许可内继续委派，再决定后续活动安排。人格可影响兴趣和表达，经历连续性依赖当前上下文与实际可用记忆；人格不授予权限或自动共享全部会话经历。提示词约定见[操作说明](../operations/提示词与人格模板.md)。

## 当前轮次的联系许可

真实主 Agent 的原生当前 turn 可调用 `eating_list_contact_targets` 读取对象及精确工具，再以 `eating_contact_target` 提交返回的 `target_id` 和任务。QQ群消息后可联系获准私聊，无需目标先发私聊。后台核对主 Agent 与原生轮次、插件／账号实例／实际账号、类型、对象及工具交集，由受限原生子 Agent 执行，主 Agent 取得 Host 真实回执，不持有全权 QQ 令牌。

主先判断实际行动目标，当前普通聊天／问答／生图优先eating_handle_conversation仅context_ref交绑定子自主处理，明确任务或用户明确逐字用途使用eating_delegate_task；跨私聊／群聊或其他目标先读当前联系目录，再contact，自动启动／恢复对应受限子，不要求目标先新入站。群context不能授权私聊，联系任务不继承旧资源；当前群查询可以辅助判断，不是每次跨目标的强制步骤。子scope不足报告具体未完成动作，由主选择其他执行者；群回执成功不能当作私聊成功。

统一 all／allowlist／denylist 同时筛选私聊与群聊。all 允许当前好友和已加入群，空白名单全禁，空黑名单等于全部放行；私聊／群聊只是对象分类，工具仍由原代理权限页管理。列出与准备任务时重新解析当前目录、账号、策略及工具权限。

所有联系任务共用 `maxContactsPerHour`，普通输入、原生目标和定时来源均计入；计数单位为任务，单任务内仍逐次校验工具／目标。保存联系策略核对 CAS，暂停定时活动并撤销旧联系许可；后续任务按新策略重新准入。

## 撤权、防重与恢复

当前 turn 结束、abort、主 Agent 销毁或 runtime 停止时撤权，真正自主机会取消也撤销该轮许可。Host 在真实调用、资源取得后及发送前复查许可与 AbortSignal。旧轮次或迟到调用不能恢复权限，已接受的外部动作不会因撤权自动撤回。

`proactive-bindings.json` 保持严格 schema1、稳定子 UUID 及有界 callId 摘要。`cycleId` 保留为内部联系轮次引用，不迁移、不恢复旧许可。每目标当前轮次最多32个 callId 引用，超额拒绝而不遗忘防重记录；重复／pending／unknown 拒绝，迟到完成不能覆盖 unknown。新 runtime 把遗留 pending 转 unknown；主人核对实际结果后可解除任务阻塞，不删除动作账本或重发。

定时周期另受单轮时长、实际连续活动时长、小时轮次及失败阈值约束；睡眠、等待和停机不计实际活动时长。中断周期 unknown 不重放，自动恢复为主人选项，仍保休息／等待；错过唤醒只合并当前一个机会。agenda任务移除与cycle保存是独立文件写入，投递和模型读取间崩溃按unknown处理，不保证恰好一次。状态／配置持久化失败明确报错并拒绝新任务。

## 设置与证据

必需主分流／委派／联系／自主规则与主人组合进入主唯一complete，子会话自主规则进入子唯一complete provider；rc.5存在complete时普通section被抑制，不能把工具头含contact等同于模型已收到规则。owner／persona／子类型隔离，自定义提示词不自动reset。验收捕获本地模型实际request.system；脚本模型按预设列表→联系→发送证明协议／scope／回执，不能证明真实LLM必定自主选同一路径。

设置→自主运行显示概览、运行设置和主动联系。配置／活动 revision、wakeAt、窗口计数和最近20项无正文结果保存在独立 `autonomy.json`／schema1，没有聊天正文或第二套记忆；AI定时任务另存 `autonomy-agenda.json`／schema1，只保留待执行的一次性任务消息。概览显示任务及时间，主人可按agenda revision取消，取消不撤回已进入会话的机会。模型状态只提供联系策略摘要，实际对象须重新读取。

界面显示初次未安排、正在运行、主人暂停、休息、等待事件、额度等待、运行时未就绪、调度状态失联和真实错误，不把异常解释成自主休息。状态只在页面可见时每5秒读取，隐藏／离页取消；locale 不触发请求或覆盖草稿。详见[配置与查看](../operations/自主运行配置与查看.md)。
