# Eating 自主活动与唤醒

状态：DSH路径已实现并经本地原生回环验证，长期自主内容质量与其他Harness未验证。日期：2026-11-02。当前应用／Host／Web0.14.0、DSH0.11.3、QQ0.13.2。本轮仅改进行为指引与工具说明，现有调度逻辑保持。当前决策见[ADR-0023](../decisions/ADR-0023-自主活动协调与主动通讯授权.md)、[ADR-0025](../decisions/ADR-0025-统一主动联系名单策略.md)及[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)，操作见[自主运行配置与查看](../operations/自主运行配置与查看.md)。

## 认知边界

同一Eating身份只有一个当前主认知控制者。所选Harness决定新活动、是否继续、委派、停止与休息；子Agent是受委派执行者。模型一次请求结束后不会自行凭空开始下一轮，需要真实事件、原生续行或结构化安排提供新的活动机会。

Eating不调用另一模型生成生活计划，不用固定任务池、配额或随机提示制造兴趣，不自建第二个Agent Loop与长期人生记忆。Host只提供事件、机械调度、授权和约束；会话与已授权记忆由Harness承担。

## DSH当前实现

- 主Agent通过公开Agent.followup接收eating-autonomy来源的活动机会。没有主人任务也可自行选择有意义活动、继续、等待或休息；不必每轮对外发送。
- 1秒机械检查只读取状态/时间，不请求模型。每个机会先保存cycleId/runtime nonce，再入原生Inbox，pre-step再次核对；同一主Agent不会并行启动另一循环。
- Host已有可投递/投递中的外部工作、原生Inbox、处于armed状态的原生目标优先，普通自主机会不再重复排入。原生Schedule与goal-round-driver保留各自语义，不替换DSH原生循环。
- AI使用eating_activity_state读取revision，再以eating_plan_activity保存active、sleeping或waiting。休息需明确时区时间，旧计时/旧revision不覆盖新安排；文字“我要睡了”不作为状态解析。
- sleeping时间到后合并一个机会，waiting不产生空模型请求。waiting期间新消息仍可处理，但处理消息不会自动把原安排改成active；AI希望继续自主活动时，需先读取eating_activity_state，再以最新revision调用eating_plan_activity登记active。主人的暂停优先于AI安排。

主Agent收到子Agent回执后，先核对真实结果、未完成项和未知状态，可以在当前有效授权与context_ref内继续工作或委派，再判断后续继续、休息或等待。当前回执不是强制停止信号，也不表示未来活动已经安排。已有安排仍合适时可以保持；希望从waiting继续时必须通过现有state／plan重新登记，正文承诺、人格设定或记忆记录都不等于真实唤醒，不另建提醒链绕过自主调度。

人格可影响兴趣、表达和授权范围内自主活动的选择，经历连续性依赖当前上下文与实际可用记忆，不预设人生或强制成长进度。共享人格不意味着所有会话自动共享经历；保存固定人格不安装记忆能力，也不改变后台权限。本轮模板与默认更新见[提示词与人格模板](../operations/提示词与人格模板.md)。

## 主人配置和可观察性

设置→自主运行独立显示运行信息、运行配置、主动联系授权。enabled和ownerPaused由主人控制；配置保存与开始执行分开，默认关闭；配置CAS冲突保留草稿，明确核对最新内容后再保存。

autonomy.json/schema1保存活动revision、wakeAt/说明、窗口计数、连续失败、当前周期/截止时间及最近20项时间/结果/代码，没有聊天正文或第二套记忆。界面显示初次未安排、正在运行、主人暂停、休息、等待事件、额度等待、运行时未就绪、调度状态失联和真实错误，不把异常解释成自主休息。

状态轮询仅在设置页可见时进行，5秒读取，隐藏/离页取消；语言切换不请求或重挂，不覆盖配置草稿。查看状态不调用模型。

## 主动通讯

普通外部批次继续使用受信context_ref及原schema2代理绑定。独立自主周期先通过eating_list_contact_targets列出主人当前策略下可联系的对象及其精确工具集合，再由eating_contact_target提交当前列表返回的对象id和任务；联系仅在当前已准入的自主周期执行。Host/通讯插件按真实连接账号、instance、类型、目标构造scope，没有旧消息/资源引用。

主动联系只有一份同时作用于私聊和群聊的策略：all（全部放行）允许当前账号好友和已加入群；allowlist（白名单）只允许选中对象，空名单全禁；denylist（黑名单）排除选中对象，空黑名单等于全部放行。私聊／群聊只是对象分类，工具权限在原代理权限页管理。proactive-contact-policy.json/schema1保存策略与精确对象绑定；列出和发起时重新按当前目录、账号、模式及工具权限解析，名单不扩大授权，不能用旧列表绕过策略变化。

Host MCP同时核验当前通讯工具政策和自主周期许可，真实调用、资源取得后及发送前检查撤权。原生子Agent继续执行通讯工作，主Agent取得真实动作回执。proactive-bindings.json/schema1独立保存稳定子UUID和有界callId摘要，不修改已存在外部子UUID。当前周期每目标32调用上限，pending/unknown阻止盲重做，迟到完成不能覆盖unknown；主人可核对实际结果后解除任务阻塞，动作防重账本仍保留。

保存联系策略先核对策略与活动revision，再暂停自主活动并撤销旧许可。查询目录只读，不调用模型；主人保存前草稿不生效，未知结果先重读核对。存储与授权细节沿用[统一名单策略](../decisions/ADR-0025-统一主动联系名单策略.md)，本轮没有替主人选择模式或对象。

## 暂停、故障与恢复

配置保存/暂停即时撤销主动任务许可，驱动中断当前自主轮次并保留其他Inbox输入。单轮最长时间、连续活动时长、每小时自主轮次/联系任务、连续失败阈值均执行。普通失败有限退避，unknown立即暂停并要求核对；持久化失败不继续发任务。

重启保持原根会话和资料，自动恢复是主人选项，仍保AI休息/等待。中断周期标unknown，不自动重放；错过多个唤醒只处理当前一个机会，不追跑所有旧时间。主Harness停用时停止机会与许可，不启动另一Harness自动接管。设备休眠或关机不能保证准时触发。

## 验证边界

真实系统DSH＋隔离HOME＋本地模型/OneBot验证了：无入站启动同一主Agent、保存休息后再次唤醒、waiting期间不请求模型、外部消息优先、主动子Agent精确工具/目标和真实发送回执、暂停保unknown及重启保持。未向真人/付费服务试发。额度为轮次/时长/任务数量，不是提供商账单级金额或每目标消息条数保证。

长期有意义自发行为、记忆质量、人格一致性及真实费用需要主人后续观察，不从单次夹具演示推断。其他Harness要声明自己的公开续行/事件/持久化/取消能力并独立验证，不能从DSH泛化接口；见[认知边界](../decisions/ADR-0006-可替换Harness与认知边界.md)。
