## 4. 修改原因

负责人要求增删飞书不影响 QQ 或迫使通用管理系统大改，新增微信通过模块自行注册；同样应允许用户选择 Harness。需要消除原 DSH 永久绑定，并将同意的 Cordis 推荐作为候选留档，不自动宣称最终采用。

## 5. 方案选择

Eating 定义业务契约和前端注册，Cordis 候选负责后台依赖/生命周期，真实运行时通过独立适配器接入。按风险另设计进程/权限隔离，不从作用域推导安全。没有为所有未来功能预建框架。

保留 DSH 为首个真实验证对象，所有 SDK/路径/调度事实放专节；不承诺 Codex/Claude Code 接口等价、热切换或历史/记忆无损迁移。能力知识与当次错误分开。
