## 公开服务和资源

[UI SDK](../../packages/ui-sdk/src/i18n.ts)精确依赖 `i18next 26.5.11`，公开 `registerTranslations`、`useI18n`、`translate`、`getLocale`、`setLocale`、`formatNumber`、`formatDateTime`、`getErrorMessage`。`Symbol.for('eating.ui.i18n.v1')` 让独立安装插件各自 bundle 中的 SDK 共享 locale，无应用私有 import 或宿主硬编码插件链。完整 flat semantic keys、完整句插值与复数由库处理，aria、错误、日期和数值一并本地化。

资源分别归属 [common](../../packages/ui-sdk/src/locales/common.ts)、[app](../../apps/web/src/i18n/app.ts)、[settings](../../apps/web/src/i18n/settings.ts)、[authoring](../../apps/web/src/i18n/authoring.ts)、[QQ](../../plugins/communication/qq/src/web/i18n.ts)、[DSH](../../plugins/harness/dsh/src/web/i18n.ts)。插件自行携带资源，Host 单 catalog 仍是工具／schema 业务来源；工具名称和参数描述按 ID 做 presentation 翻译，未知 metadata 原样回退。

## 语言和内容边界

全局侧栏底部原生 select 替代“我的工作区”，提供“简体中文 / English”，默认 `zh-CN`。`eating.locale` 只存语言偏好，无凭据；刷新保留、storage event 跨标签页同步。document lang、title、meta description 即时更新；切换不重挂面板、不丢草稿／选区／undo，不触发 POST、重启、消息发送或额外日志订阅。

用户名称、模型名、URL、Key、消息、JSON、工具 ID、参数名和 canonical 中文变量（如 `{{当前时间}}`）保持原样。三份 defaultPrompt 正文属于主人内容／AI 策略，不随 UI locale 改写，不能当作翻译遗漏。结构化错误 code 映射用户提示；未知原始后端错误不主要呈现，可在诊断详情查看。
