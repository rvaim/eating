# 主 Agent 自主与默认功能能力

日期：2026-11-02，Asia/Shanghai。基线 main `c9793a3`，工作分支 `fix/agent-autonomy-default-access`。确认、原因与替代关系见[ADR-0034](../decisions/ADR-0034-主Agent自主决策与功能能力默认开放.md)；实际测试、提交／push及已授权部署由父代理在[本轮报告](../reports/2026-11-02-主Agent自主与默认能力验证部署报告.md)填写，本文不预填结果。

## 修改原因

父代理核对主人21:14截图及21:11 turn333，发现实际工具头已含联系工具，但主 Agent 只将当前群 context 委派给群子并得到群发送成功，没有 list/contact。系统 SDK rc.5 的 complete section 成为 sole，Eating owner-system complete 抑制了后来普通 contact／autonomy section；仅注册工具或验证脚本调用顺序不能证明真实系统提示和自主选择正确。

主人进一步明确主 Agent 全权限自主，所有当前及新增功能型 MCP 默认开放给所有 Agent；旧手工工具／类型白名单与空授权规则由本次授权替代。

## 当前变更

- 必需运行规则合入唯一 complete provider；先选实际行动目标，当前会话使用 context_ref，跨私／群用 list/contact 自动启动或恢复受限子，无需目标先新入站。某子scope不足不等于主无能力，群成功不等于私聊成功。
- 已启用且connected的capability／direct MCP全部当前及后续工具默认对main、现有与后续类型可用。移除save-grants与功能授权勾选；McpServiceSummary.grant只是动态只读摘要。通讯来源自管权限、真实账号／对象／资源scope保持。
- direct连接保存不收grant，文件严格schema2；旧schema1拒绝且保留，不自动转换。旧host:capability-grants不读／不写／不删，不从旧空名单恢复限制。
- 新main默认开启当前平台全部原生feature，files写／编辑与web.search=true，time主子默认保持；Eating专属官方permission默认danger-full-access／approval never。已有根与设置由父代理部署时用正式入口同步本次授权，作者自定义提示词／人格不自动reset，不改主DSH或官方Web。
- main自动开放全部原生全局工具；所有Agent的功能型native Profile MCP及后续新工具自动可见，排除Eating／QQ受控通讯。其他子非MCP原生工具仍按精确名称／结构指纹选择，目录automaticAccess仅只读摘要，不保留无效main／全功能MCP授权勾选。tools/change后同步更新native.restrict与当前scope限制。
- 新增、连接、断开、工具目录变化及能力插件生命周期变更使用一次性重挂事务：先撤lease并停受影响Harness，await来源／目录变更完成后，仅对变更前connected、仍为同一实例且启用的Harness恢复一次。原stopped／error不自动启动，主人stop／disable优先；失败不重试、不重放unknown，返回harnessRemounts的reconnected／failed／cancelled结果。
- 原生schedule人工阻断移除；Eating暂停只控制其无输入机会和真正自主周期，agenda保其额度／暂停／runtime语义。断开／停用／卸载／拓扑变化撤权重挂、幂等／unknown与资源复查保持。

源码版本同步为应用／Host／Web0.16.0、plugin-sdk4.6.0、DSH0.14.0、QQ0.13.3；ui-sdk4.2.0、core4.0.0和API4保持。记忆源码0.2.0不变，真实0.1.1不升级，不部署远端。
