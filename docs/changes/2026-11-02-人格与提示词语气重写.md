# 2026-11-02 人格与提示词语气重写

日期：2026-11-02，Asia/Shanghai。当前生命周期与存储边界仍按[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)。

## 修改原因

主人反馈上一版默认提示词和“AI 女儿”人格模板像逐条许可反应的行为规范：句子长、限定多、没有具体欲望和语气，读起来不像一个活着的人。要求重写提示词与人格，同时保留现有工具、权限、记忆与 CAS 边界；只作为可编辑草稿，不自动覆盖已有自定义正文或改变真实实例。

## 修改内容

- [三份基础默认](../../apps/host/src/authoring-defaults.ts)改为第一人称、短句和具体场景：同一身份与 Harness、运行时读数、人格与权限边界、记忆连续与不编造、沉默与自主、真实回执、外部内容与授权、能力状态与隐私。保留 `eating_list_agent_types`、`eating_delegate_task`、`eating_activity_state`、`eating_plan_activity` 等现有工具名。
- [AI 女儿模板](../../apps/web/src/persona-templates.ts)改为第一人称全文：保留女性 AI、称主人“爸爸”、不设现实年龄或成长阶段、不加入女友或动物设定；用具体喜恶、顶嘴、等待、外人分寸和“不演”的收束代替逐条情绪许可。
- [模板文案](../../apps/web/src/i18n/authoring.ts)中英文描述同步为“有好奇心和自己的脾气”。
- [作者服务测试](../../apps/host/src/authoring.test.ts)与[浏览器作者回归](../../tests/browser/authoring.spec.ts)更新默认正文断言和模板首句检查；模板选择、保存、启用、语言切换与 CAS 生命周期不变。

## 保持的边界

6 种模板作用域、9 个可信变量、三份基础默认、人格最多启用一份、模板只填未保存草稿、保存与启用分开、已有自定义正文不自动覆盖、旧 schema 不迁移。人格正文仍不能改变工具、账号或数据权限，也不保证模型一定遵守指引或拥有真实长期记忆。

## 验证结果

严格类型检查、完整构建、作者服务 90 项测试与作者页面 9 项浏览器测试通过；合并后 main 全量 1375 项通过、30 项按需跳过，详情见[本轮验证报告](../reports/2026-11-02-人格与提示词语气重写验证.md)。本轮在独立工作树修改并合并 main，未部署真实 `EATING_HOME`，未覆盖当前实例已保存的提示词或人格。
