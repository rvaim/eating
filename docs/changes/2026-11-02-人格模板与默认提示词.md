# 2026-11-02 人格模板与默认提示词

日期：2026-11-02，Asia/Shanghai。当前设计与实现见[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)，用户操作见[提示词与人格模板](../operations/提示词与人格模板.md)。完整命令、最终计数、截图与实际运行状态由[本轮验证报告](../reports/2026-11-02-人格模板与默认提示词验证.md)集中记录。

## 修改原因

主人已批准一份“AI 女儿”人格，并要求正式默认指引能准确说明当前能力、上下文和可用记忆的连续性、人格对自主兴趣的影响，以及主子回执后的后续选择。人格模板应作为可编辑草稿提供，不能悄悄创建、启用或替换已保存人格。

作者服务此前把保存过的基础默认副本一直作为正文读取，导致从未编辑的文档无法跟随代码更新。单纯删除插件覆盖来恢复默认，又会让 revision 回到0，留下旧 CAS 请求重新生效的问题。本轮在现有 schema2 内明确跟随状态，并以单调版本保存恢复操作。

## 实现内容

- [前端模板目录](../../apps/web/src/persona-templates.ts)仅提供本会话批准的“AI 女儿”。模板明确女性 AI、称主人为“爸爸”、依据上下文与可用记忆延续真实经历，不设预定人生或成长阶段，不加入女友设定或动物比喻。
- [人格页面](../../apps/web/src/pages/Authoring.tsx)新增“从模板新建”和“使用「AI 女儿」模板”，仅替换新增人格未保存草稿的正文，名称留主人填写且保留已填名称，已有非空正文先确认。没有模板创建／启用接口，不自动写 `host:authoring`；显式保存后成为普通人格，再由主人手动启用。语言切换只改界面，不改正文。
- [三份基础默认](../../apps/host/src/authoring-defaults.ts)独立维护。默认规则说明唯一身份、事实和推测、记忆可用性、兴趣与权限、真实工具回执、主子继续协作及后续自主安排，不点名任何记忆插件。共享人格不冒充自动共享全部会话经历。
- [作者服务](../../apps/host/src/authoring.ts)以 `updatedAt:null` 表示跟随当前代码或注册默认，非 null 表示主人覆盖。旧默认 body 可保留在存储，普通读取、Harness 配置与组合使用当前默认且不落盘；自定义正文不自动覆盖，同正文保存不写。
- 单文档 `resetPrompt(id, expectedRevision)` 先核对来源和 CAS；恢复时保留文档记录，文档及全局 revision 各加一、`updatedAt:null`。已跟随默认时只读。基础、角色和插件文档均防止恢复归零导致 ABA，来源卸载与重装保留稳定记录和 revision。
- [HTTP 路由](../../apps/host/src/app.ts)新增 `POST /api/prompts/:encodedId/reset`，严格仅接受非负安全整数 `expectedRevision`，返回完整作者快照，继续执行主人会话和 CSRF 校验；作者相关保存及人格操作拒绝未知字段。
- 提示词界面显示跟随／自定义状态，提供当前默认预览与明确“恢复默认并保存”确认。只替换目标文档及其草稿，冲突或未知结果保留草稿并要求重读。
- QQ 角色说明、DSH 使用说明及自主工具描述对齐当前能力。主 Agent 可在回执后继续当前授权工作；规划下一次活动仍使用现有 state／plan，`waiting` 收到消息后不自动变 `active`。主动联系只能使用当前列表按全部放行／白名单／黑名单策略返回的对象及精确工具集合。

## 保持的边界

6种模板作用域、9个可信变量、同一启用人格、现有原生 UUID、受控委派和真实回执保持。来源校验、工具权限和账号范围由后台执行，提示词与模板不扩大权限。模板与固定人格不是长期记忆库，保存计划或正文承诺不等于真实唤醒。

本轮自主调度状态机、额度、暂停与名单政策逻辑未改，不新增提醒链或第二套 Agent Loop。恢复提示词保留其他提示词、人格、启用关系、设置、队列、账本和会话；容量超限、版本耗尽、来源缺失及写入失败保留原存储。

旧作者 schema、缺字段或旧形状仍明确拒绝，不迁移、不补齐、不自动回写。历史报告和旧 ADR 正文保持原阶段事实。
