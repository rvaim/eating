# 会话代理自主处理与默认开放可配置

日期：2026-11-02，Asia/Shanghai。基线：main `bfc381f`；工作树：`dialogue-ownership-and-config`。决策见[ADR-0035](../decisions/ADR-0035-会话代理自主处理与默认开放可配置.md)，实际验证、清理、部署与 Git 状态见[本轮报告](../reports/2026-11-02-会话代理自主处理与默认开放可配置验证清理报告.md)。本页记录源码与当前契约，不预填已清理、已部署或已提交。

## 修改原因

主人纠正主子职责：main 负责整体安排、轻量分流与必要协调，普通会话由绑定子代理独立理解和组织回复、选择工具与执行；默认全开放仍保留主人配置例外的能力。现场已出现 main 在有 `image_generate` 时把未经核对的“无生图能力”当作事实下发，实际未调用生图。这里只记脱敏事实，不复制私聊正文、账号、旧 UUID 或原始 trace。ADR-0034 和旧经验中删除 save-grants／只能只读的说法不再是当前要求。

## 本轮契约

- [原生会话入口](../../plugins/harness/dsh/src/backend/runtime-agents.ts)新增 `eating_handle_conversation`，严格仅 `{context_ref}`；核对当前 root、批次／digest、owner 绑定和 callId 后，把固定中立任务与原始 context/events 交给绑定子。子独立原生会话负责理解、回复、必要工具与发送，main 取得真实 Host actions 和摘要。`eating_delegate_task` 留给明确执行任务或用户明确逐字内容；跨目标仍 list/contact，不新增关键词 router 或另一 Agent Loop。
- [默认提示词](../../apps/host/src/authoring-defaults.ts)、[QQ说明](../../plugins/communication/qq/src/backend/agent-policy.ts)与原生主／子唯一 complete provider 明确会话自主职责；升级不 reset 主人自定义正文／人格，不把工具可见写成实际业务成功。
- [公开 MCP 契约](../../packages/plugin-sdk/src/capabilities.ts)增加 `McpAccessPolicy`，summary.accessPolicy 返回 all/custom 或自管来源 null，grant 返回当前有效摘要。[Host策略](../../apps/host/src/capability-access.ts)默认 all 含未来类型／工具；主人 custom 精确选择来源的类型和工具，可恢复 all，新来源仍默认 all。通讯和资源 scope 保持。
- [管理入口](../../apps/host/src/app.ts)恢复严格 `save-grants` DTO 与一次性重挂。新 `host:mcp-access-policies` 保存严格 schema1／revision／policies，CAS 为 direct＋policy revision。direct 文件仍严格 schema2，仅连接／秘密；旧 host:capability-grants 不读／不写／不迁移／不删。原 connected 恢复一次，owner stop 优先，unknown 不重放。
- [原生配置](../../plugins/harness/dsh/src/backend/native-configuration.ts)在 schema1 增加可选 toolAccessOverrides。省略保持、[]恢复自动；同名 override 按精确指纹＋类型优先，可关 main／空列表禁用，指纹变化也不回落开放。[工具面板](../../plugins/harness/dsh/src/web/NativeCapabilities.tsx)恢复逐项自动／自定义保存；automaticAccess 继续说明默认，feature 选择保持，reserved／来源／scope 不绕过。
- [MCP面板](../../apps/web/src/pages/Mcp.tsx)保留默认全部开放的说明，并允许主人保存自定义类型／工具、恢复 all；草稿、CAS、连接和来源自管权限分别处理。新main平台全 feature 与 Eating 专属 danger-full-access／approval never 默认保持，主人仍可显式再配。

当前 direct 限制：在途撤权可能中断 transport 并使来源 error，需主人显式 connect；不自动重放未知动作。

## 数据、版本与验证边界

源码为应用／Host／Web0.17.0、plugin-sdk4.7.0、ui-sdk4.2.0、plugin-core4.0.0、DSH0.15.0、QQ0.13.4，表情包0.1.1、生图0.2.0、记忆源码0.2.0、API4。真实记忆0.1.1保持，不安装0.2.0或远端部署。

主人现授权删除 Eating 本地主／子会话，云端自行删除。清理以停机后的精确审计白名单和混合字段维护执行，保配置／凭据／人格／资源／账本／去重／设置，不生成含正文的新备份；父代理已执行apply并独立复核，实际清理与保留数量见本轮报告。正常恢复保持UUID，本次明确清会话后创建新UUID，人格身份不变。完成后 QQ／DSH／记忆保持关闭；助手主 DSH 和60182服务不在范围内。浏览器 localStorage 草稿与 OS 快照不属于已覆盖范围，不宣称全机 forensic 抹除。

验证仅使用临时数据、系统 SDK、scripted mock／本地 provider 和 OneBot 夹具，覆盖普通回复、生图查询取图与 mock 私聊实际发送、策略例外和冷恢复。必须核对真实 request.system 规则与主子隔离；预设脚本链可执行不代表真实 LLM 必然自主选择相同链路。全量、浏览器、清理、Git 与部署最终实数由报告回填，不向真人、真实付费模型或远端服务试发。
