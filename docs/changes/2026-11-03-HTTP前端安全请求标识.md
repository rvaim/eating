# 2026-11-03：HTTP 前端安全请求标识

源码验证与实际云端保留数据更新完成。修复代码 `ab19cbb` 已本地commit／push，由云端GitHub取同提交完整构建与Host回归后更新原数据目录。决策见[ADR-0044](../decisions/ADR-0044-HTTP前端安全请求标识.md)，最终测试实数、真实公网浏览器、Git及保留数据证据见[报告](../reports/2026-11-03-公网HTTP面板修复与保留数据更新验证报告.md)。

## 原因

公网 HTTP 是非安全上下文，浏览器没有受 secure context 限制的 `crypto.randomUUID()`，QQ 面板初始化请求 ID 时直接调用导致渲染失败。前次 localhost 隧道下 `isSecureContext === true`，该 API 存在，使验证遗漏真实公网 HTTP 情况；不是后台安装或资料损坏。本次修复当前 HTTP 平台契约，保留安全随机，不要求用户改 HTTPS、网关或防火墙。

## 修改范围

- 公开 UI SDK 统一导出 `createRequestId()`，始终用 `crypto.getRandomValues` 生成16字节并设定 RFC UUIDv4 的 version／variant 位，返回小写 `8-4-4-4-12` ID。不调用 randomUUID，无其 fallback，无 Math.random／时间／计数器，无新增依赖。
- workspace、QQ panel、image panel、DSH NativeCapabilities、memory ranges 五处前端文件统一引用公开 helper；新 ID 的分配时机、同一意图复用原号、unknown 不换号与不自动重发保持。Node 后台 UUID 实现不改，五个后台入口仅同步版本。
- 应用／Host／Web0.17.5、ui-sdk4.2.1；QQ0.13.7、DSH0.15.4、生图0.2.1、记忆源码0.2.1的 package、清单、前端 entry、后台 version 四处同步。plugin-sdk4.7.0、core4.0.0及API4保持。表情包功能保持；父代理封存核对发现共享SDK导出使压缩UI产物字节变化（升级前后台／CSS保持），因此按同版本不可变规则仅升0.1.2四处version，不绕过安装校验或扩展功能。
- pnpm workspace 依赖仍解析为 link，锁文件无需版本改写，不安装或新增依赖。存储 schema、真实配置、人格、权限、会话、资源及账本不迁移、不清空。
- README、工程规则、状态、交接、待确认问题、接口与文档索引补本轮契约，旧 ADR、报告、测试计数与前轮 README 历史保留。

## 验证与交接

浏览器回归以 `eating-http.test` 在测试浏览器内映射 `127.0.0.1`，真实断言 `isSecureContext === false`、randomUUID 不可用及 getRandomValues 可用，不 mock crypto API。覆盖HTTP面板打开、UUIDv4格式、同一意图原ID复用与unknown不换号。完整构建与严格类型通过；最终全量1743项通过／8项条件跳过（114.58秒），最后真实非secure HTTP三项与表情真实安装保库一项共4项浏览器通过（8.2秒）。前两轮全量各一项QQ／表情旧version literal失败已修，生产guard未放宽。

实际公网浏览器确认HTTP secure=false、randomUUID=undefined、getRandomValues=function；QQ配置可见，UUIDv4请求ID切tab复用，pageerror／UUIDerror均0，无POST mutation，Token已去URL。用户用原Token链接重入刷新即可，无需重装，端口与Token不变。

云端GitHub取 `ab19cbb` 构建／Host回归时原服务不停；停Eating前确认idle=true／队列0，项目外备份既存小数据，再通过正式服务脚本更新同一数据目录。12受保护文件哈希、Host settings摘要／数据库各表行数与schema、保存插件公开配置canonical摘要、ownerToken全保持，原所有系统服务仍running；实际五插件为QQ0.13.7、DSH0.15.4、表情0.1.2、生图与记忆0.2.1。本次没有新增依赖、TLS、网关、防火墙或本机运行时改动，不重置资料。真实目标、端口、目录、别名及Token只存项目外，报告仅记脱敏证据；缺依赖仍先说明并询问安装。
