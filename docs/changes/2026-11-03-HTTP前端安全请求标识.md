# 2026-11-03：HTTP 前端安全请求标识

当前源码验证中，实际云端保留数据更新待执行与核验。决策见[ADR-0044](../decisions/ADR-0044-HTTP前端安全请求标识.md)，最终测试实数、浏览器读图、Git及云端保留数据更新由父代理维护的[报告](../reports/2026-11-03-公网HTTP面板修复与保留数据更新验证报告.md)记录，不以本文宣称完成。

## 原因

公网 HTTP 是非安全上下文，浏览器没有受 secure context 限制的 `crypto.randomUUID()`，QQ 面板初始化请求 ID 时直接调用导致渲染失败。前次 localhost 隧道下 `isSecureContext === true`，该 API 存在，使验证遗漏真实公网 HTTP 情况；不是后台安装或资料损坏。本次修复当前 HTTP 平台契约，保留安全随机，不要求用户改 HTTPS、网关或防火墙。

## 修改范围

- 公开 UI SDK 统一导出 `createRequestId()`，始终用 `crypto.getRandomValues` 生成16字节并设定 RFC UUIDv4 的 version／variant 位，返回小写 `8-4-4-4-12` ID。不调用 randomUUID，无其 fallback，无 Math.random／时间／计数器，无新增依赖。
- workspace、QQ panel、image panel、DSH NativeCapabilities、memory ranges 五处前端文件统一引用公开 helper；新 ID 的分配时机、同一意图复用原号、unknown 不换号与不自动重发保持。Node 后台 UUID 实现不改，五个后台入口仅同步版本。
- 应用／Host／Web0.17.5、ui-sdk4.2.1；QQ0.13.7、DSH0.15.4、生图0.2.1、记忆源码0.2.1的 package、清单、前端 entry、后台 version 四处同步。plugin-sdk4.7.0、core4.0.0及API4保持。表情包功能保持；父代理封存核对发现共享SDK导出使压缩UI产物字节变化（升级前后台／CSS保持），因此按同版本不可变规则仅升0.1.2四处version，不绕过安装校验或扩展功能。
- pnpm workspace 依赖仍解析为 link，锁文件无需版本改写，不安装或新增依赖。存储 schema、真实配置、人格、权限、会话、资源及账本不迁移、不清空。
- README、工程规则、状态、交接、待确认问题、接口与文档索引补本轮契约，旧 ADR、报告、测试计数与前轮 README 历史保留。

## 验证与交接

新增浏览器回归应以 `eating-http.test` 在测试浏览器内映射 `127.0.0.1`，真实断言 `isSecureContext === false`、randomUUID 不可用及 getRandomValues 可用，不 mock crypto API。覆盖真实 HTTP 面板打开、UUIDv4 格式、同一意图原 ID 复用与 unknown 不换号；localhost 仅作对照。单元验证安全字节来源及格式，定向核对所有版本字段。

完整类型／构建、最终相关测试数字及截图由父代理统一执行与回填，本子任务不并发全量构建、不 commit／push或连接云端。云端更新仍须本地验证并 commit／push后从 GitHub 拉取确认提交，只更新 Eating 并保现有数据，不上传本地工作区，不增加 HTTPS／证书／网关或操作防火墙，缺依赖先说明并询问安装。真实目标、端口、目录、别名及 Token 只存项目外，报告仅记脱敏证据。
