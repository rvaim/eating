## 修改原因与当前契约

主人明确选择本次服务器 HTTP 公网直连，不要登录页面或账号密码，不加 HTTPS、证书或网关，防火墙由用户管理。HTTP 传输不加密。旧本机前提不能直接用于公网 bootstrap，增加[ADR-0043](../decisions/ADR-0043-公网Token入口与Git发布部署.md)定义显式模式：默认 `127.0.0.1` 保持，`0.0.0.0` 必须提供规范 `publicOrigin` 和随机32至256字符 URLsafe `ownerToken`。

入口仅根 `GET /?token=<OWNER_TOKEN>`，已有 query 时用 `&token=<OWNER_TOKEN>`；成功签发独立入口 Cookie、以303去掉 Token，保留其他 query，再沿用 bootstrap／管理 session／CSRF。Token 错误、重复、非根或非 GET 不交换权限。管理页面、插件资源和 API 需入口校验；MCP 继续使用自己独立 Bearer，owner URL Token 不代替 MCP 令牌。官方 DSH Web、回环监听和官方鉴权入口保持，不随 Host 入口改写。

监听参数为 `EATING_LISTEN_HOST`／`EATING_PUBLIC_ORIGIN`／`EATING_OWNER_TOKEN`／`EATING_HOST_PORT`；数据目录由 `EATING_HOME` 及外部服务配置提供。真实值、端口、目录、Token、密钥和最终用户链接只能保存在项目外私有配置／文件，报告和 Git 只写明显占位符。
