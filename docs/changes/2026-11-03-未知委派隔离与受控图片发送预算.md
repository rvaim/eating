# 未知委派隔离与受控图片发送预算

日期：2026-11-03，Asia/Shanghai。基线：`6541a77`，工作树：`fix/delegation-errors-and-image-send`。决策见[ADR-0037](../decisions/ADR-0037-未知委派隔离与受控图片发送预算.md)，验证与交付见[本轮报告](../reports/2026-11-03-未知委派隔离与受控图片发送验证报告.md)。

## 修改原因

授权生图资源转Base64后撞上QQ旧1MiB通用发送限制，发送前not-sent；委派超时unknown又锁住后续新批次。改走联系耗尽每小时6次后，错误过度泛化及控制层丢字段使模型不能正确判断。活动状态读取实际成功，不是状态文件损坏。

## 修改内容

- 普通入站unknown仅拦原contextRef或原taskId，新context＋新call可复用同child并重取scope；pending仍串行，旧actions／finish不覆盖或撤销新任务。启动遗留pending转unknown保原nonce；最多32引用，仅淘汰旧completed／failed，保护unknown／当前批次，满则明确capacity。
- QQ后台仅为授权readAsset且checked后的实际Base64提供额外预算：普通wire扣除实际Base64≤1MiB、额外≤14MiB、总JSON≤15MiB；单图5MiB、4张／10MiB聚合和入站／response／ws1MiB保持，模型不可伪造预算。
- autonomy分类报错及只读contactLimit摘要；lease前预检、计数时再检，不改每小时6次及主人配置。agent-control保真实HTTP状态／outcome／details，RuntimeControlError保大小写安全code与脱敏typed字段，不按409猜unknown。
- 应用／Host／Web0.17.2、DSH0.15.2、QQ0.13.5；SDK4.7.0／UI4.2.0／core4.0.0／API4及数据schema保持。普通会话仅context_ref、主轻量子自主、功能MCP all／custom、人格／历史／ledger、新Harness仅time默认及已保存revision5 time＋web保持。
