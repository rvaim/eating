# 空闲整批交接与统一会话身份

日期：2026-11-03，Asia/Shanghai。状态：源码修复与隔离验证完成，尚未部署；最终命令、测试实数与限制以本轮验证报告为准。

## 修改原因

主Agent空闲时应一次取得当前全部可交接输入，再自主安排各会话；原Host逐conversationId硬切并逐桶交接，不能满足该要求。普通入站与主动联系同对象应延续同一子会话，不能因入口不同拆成两份新历史；混合批次也不能沿用首组身份作为整轮记忆权限。

## 修改内容

- Host按完整pluginId／instanceId／accountId／conversationId／source.kind／targetId分组。静默／最长等待有效，条数与体积只提前触发，不截断；任一身份ready时，所有无冷却前缀按global sequence一次交接。忙时零attempts，wake重取全部。
- SDK批次conversationId为string|null；仅单一完整身份使用其ID，多身份null，导出groupHarnessEvents统一分组语义。总队列容量及溢出保护保持。
- DSH一个主信封保留全量events与逐组context_ref，owner bindings和contexts一一核对，主自行分配，子只收所属组。真实root idle与入箱为空通过受认证递增状态反馈；run结束或ACK不能替代就绪证据。
- 同parent／插件／实例／账号／类型／私聊或群聊／目标的普通与联系后续任务共用child UUID选择，保护在途任务；不合并、不删除已有重复原生历史，不迁移真实数据。
- 记忆按实际scope逐组召回与采集，主人许可不跨组扩散；含糊主轮次MCP拒绝，混合协调输出不复制给每个Peer，原生主人追加按self处理。真实记忆安装不升级、不远端部署。
- 保留原生flush＋ACK、本地结果保存重试、明确拒收冷却、unknown不重放、detach／重启恢复、动作账本、人格与官方Web。

当前规则见[ADR-0038](../decisions/ADR-0038-空闲整批交接与统一会话身份.md)、[Harness适配](../architecture/Harness适配.md)、[接口契约](../technical/接口契约.md)与[操作说明](../operations/QQ配置与功能测试.md)。ADR-0038部分替代ADR-0013的逐会话及硬切规则，历史ADR和报告事实不改写。

## 验证与剩余边界

父代理统一完成源码整合后的类型／构建、相关测试与独立原生回环，最终实数及未覆盖范围写入[本轮报告](../reports/2026-11-03-空闲整批交接与统一会话身份验证报告.md)。原生500ms状态反馈／3s有效期与SDK enqueue非原子，竞争输入仍由原生串行Inbox承接。ACK后未claim的持久输入按精确messageId／digest与既有绑定恢复，仅用无正文sentinel唤醒原有输入，不重新prompt；局部routingError unavailable保全部来源可见；同child先reserve和本地flight gate再drain，以保护首任务。脚本模型链路不证明真实LLM必然自主选择同样委派，不向真人或付费服务试发，不将默认跳过当作通过。
