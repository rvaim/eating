# 统一身份核实与自然短消息

日期：2026-11-03，Asia/Shanghai。状态：源码实现与隔离验证完成；未部署、未提交或 push。最终命令、实数与限制见[本轮验证报告](../reports/2026-11-03-统一身份核实与自然短消息验证报告.md)。

## 修改原因

同一 AI 在群聊和私聊保持同一身份。当前会话缺少另一会话记录，只能说明尚未核实，不能据此否认真实参与；主 Agent 需要协调已有记录、获准记忆与对应会话事实，再由原会话子 Agent 自然回答，避免先否认后更正。普通聊天的自然短句还需要真实独立发送，不能把一次调用内的换行当作多个气泡。

## 修改内容

- [Host 默认](../../apps/host/src/authoring-defaults.ts)明确共享身份、局部未知先核实、主协调与子自主表达。已有记录、真实回报及获准记忆优先，缺来源时由对应执行者只核实回报，不向被查询群或私聊发送。
- [DSH 共享策略](../../plugins/harness/dsh/src/backend/conversation-policy.ts)集中提供身份／表达、主协调、子核实规则，[原生运行时](../../plugins/harness/dsh/src/backend/runtime-agents.ts)分别合入主、子唯一 complete provider。主人即使完全自定义正文，必需规则仍须进入实际模型 system；保留已保存正文、人格与类型隔离，不执行 reset。
- [QQ 角色与主说明](../../plugins/communication/qq/src/backend/agent-policy.ts)同步核实与表达约定。核实后给原会话子可披露事实及来源范围，由它结合人格与历史回答；当前账号／目标／消息／资源、记忆和成员设置继续核验，联系权限不自动授予全部历史读取或披露权限。
- 主人后续纠正已合入：一条消息允许多句话，一次回复允许多条消息，没有句数、字数或条数配额。撤回“一条一个意思”的机械限制，普通短聊两句话间不插大空行，另一个接话或补充适合独立气泡时实际另发；追问按真实需要，不套固定结尾。复杂需求、必要详细说明、逐字原文、代码和链接保持完整。内部任务摘要不直接当聊天原文发送。
- 独立气泡分别调用真实发送工具，每条使用不同且稳定的 `request_id`，按顺序核对真实回执；unknown 时停止自动续发与重发，先核对原回执。不新增固定截字发送器、人为等待或打字模拟。
- [AI 女儿模板](../../apps/web/src/persona-templates.ts)仅同步新增可编辑草稿中的自然表达约定。模板更新不改真实已保存人格，不自动保存、启用或替主人恢复默认。

完整决策见[ADR-0039](../decisions/ADR-0039-统一身份核实与自然短消息.md)，操作及送达边界见[提示词与人格模板](../operations/提示词与人格模板.md)和[Harness 适配](../architecture/Harness适配.md)。旧 ADR、历史报告和前轮未提交修改保持。

主人后续多句与独立气泡纠正的实际验证单列于[补充报告](../reports/2026-11-03-自然聊天多句与独立气泡纠正验证报告.md)，不把前轮全量数字当作纠正后的再次实跑。

## 验证与生效边界

父代理统一核对类型／构建、相关回归与独立系统 DSH 回环，捕获主、子实际本地模型 `request.system`，检查全部自定义正文时必需规则仍送达、人格与角色隔离，以及只核实不发群消息、原私聊回答、分泡独立调用及回执顺序。实际范围、最终实数和未知停止续发的覆盖程度以[本轮报告](../reports/2026-11-03-统一身份核实与自然短消息验证报告.md)为准，本页不预填测试数或通过结论。

本地脚本模型与 OneBot 回环只能证明预设链路可执行及规则送达，不能保证真实 LLM 已经学会或每次自主选择相同行为。真实实例需要另行获准部署相应应用／插件并加载新规则后才生效，主人保存正文与人格保留。

本轮不写真实配置／人格／历史，不重启、部署或真人／付费试发，不提交或 push；不实施[前轮主动活动方案](../plans/2026-11-03-主动活动行为改进方案.md)，不改额度、sleeping／waiting 或自主节奏。最终交付状态由父代理据实际结果回填。
