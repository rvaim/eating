# 聊天参与感与人格场景指引

日期：2026-11-03，Asia/Shanghai。状态：新增源码实现与隔离验证完成、未部署、未二次提交。决策见[ADR-0041](../decisions/ADR-0041-聊天参与感与人格场景指引.md)，最终测试实数及状态由父代理填入[本轮验证报告](../reports/2026-11-03-聊天参与感与人格场景指引验证报告.md)。

## 修改原因

补足群聊中判断说话对象、选择接话与停止的具体指引，使自然参与有明确的正向依据，同时保留沉默和尊重对方反馈的空间。人格通过场景变化表达，不靠固定台词、事实编造或强制活跃。

## 修改内容

- DSH 共享 conversation-policy、Host common 默认及 QQ group defaults 同步：先看真实 @／引用／说话对象，读完本批再选择回应；有具体态度、新信息、真实好奇或联想可以自然参与，没被点名也可接话，不逐条点评、不当主持／调解／气氛组。
- 对方不接、拒绝或话题翻篇即停；适应本群语气但不照抄；只在相关且可披露时提记忆，不把旧消息说成刚发生，不编造刷手机吃饭或故意答错、装傻、刻薄。
- “AI 女儿”模板草稿补被关心、被误会、玩笑和认真提问四类小例子；不是固定台词或已发生事实，不覆盖已存人格，不自动保存／启用。
- 普通多句／多条自由、真实发送回执、verify／reply、权限与资源 scope 契约完全保持；不增加字数、句数或条数配额。
- 主动活动只在[待审方案](../plans/2026-11-03-主动活动行为改进方案.md)补正向社交动机，不实施 autonomy-runtime、调度、额度或 waiting／sleeping 变化。

参考 [Derpyu520/qq-bridge，b80fa51](https://github.com/Derpyu520/qq-bridge/tree/b80fa51) 的二代预设和 roles card 概念后自行编写，不照抄角色正文或工具架构；未采纳固定字数条数、强制五分钟等待、完全跨会话隔离、故意乱答或假装线下活动。
