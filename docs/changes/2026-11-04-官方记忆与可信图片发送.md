# 2026-11-04：官方记忆与可信图片发送

当前状态：已实现，完成本地和云端验证并部署更新云端 Eating。用户已明确批准修复及云端 Eating 更新；完整证据见[验证报告](../reports/2026-11-04-官方记忆与插件能力更新验证报告.md)。

## 修改原因

记忆0.2.x只接受Eating增量扩展，正常官方OpenViking服务因私有能力与写入协议无法接入；删除guard无法修复后续链路。插件图片发送只拿到预览Base64，缺少经过来源／lease与真实字节核验的文件能力；同名本机路径也不能证明远端共享可用。部署提示混淆服务器安装、浏览器环境与实际模型配置，生图尺寸还需要明确单次参数和保存默认的优先级。

## 当前实现

- 记忆改用官方Session消息批量追加、commit与Task API。逐轮同步为synced，commit才归档并提取；已知task只GET恢复，未知追加／提交保留元数据并阻塞同Session，不换号重发。移除扩展必需、私有durable receipt／重试及diff counts承诺。
- 记忆config／state严格schema3，移除archiveMaxMiB；autoCommit默认true，commitTokenThreshold为1至1000000、默认20000。阈值、压缩和正常结束尊重自动开关，主人手动提交可强制。固定eating-standard-<peer>及-local，不接管eating-live旧扩展根，不删除远端记录；真实scope／群成员名单保持。
- plugin-sdk公开PluginImageAsset与getAsset lease；来源插件自验证固定blobs，Host复核同source／callerlease／scope／signal／hash／MIME。AI预览保Base64，发送用字节和可选文件能力，模型只见opaque资源引用。
- QQ独立media-transport.json/schema1仅主人get／save。确认映射包含sourceRoot／hostMappingRoot／onebotRoot／ownerConfirmed并绑定真实连接；逐图本地hash一致才用标准file，否则发送前选Base64。不声称标准get_image已自动探测远端任意localfile，unknown不换传输发第二次；手工OneBot file／URL／Base64保持。
- 生图单次size优先于保存默认，省略沿用默认，空串不传size并用服务默认；接受WIDTHxHEIGHT或服务原生标识／auto，最终支持由provider决定，不自动换尺寸付费重试。Base URL／模型需配置，Key可选。
- DSH顶部区分尚未检测、服务器未安装、已找到但version=null及真实运行错误，提供官方说明与重新检测；不自动安装、不拿浏览器OS推断服务器。QQ提示必须先在OneBot端登录，Eating不代办登录。

## 已授权部署与数据保留

云端更新已获明确授权，仍执行本地修改验证、commit／push、云端从GitHub拉取确认提交构建的链路。真实连接值、别名、目录、凭据和映射留项目外；本机记忆0.1.1保持，不配置／安装／重启真实OpenViking服务端，不安装额外依赖，不加TLS、网关或防火墙。

源码`91b18c3`先本地commit／push；云端首候选构建成功但Linux一项Buffer深比较测试5秒超时，旧服务保持未切。等价native `Buffer.equals`与长度断言修复为`72fecad`再push；服务器从GitHub拉取72fecad完整build及扩展Linux回归通过后，才只停Eating、私有全data备份并执行转换。

转换前复核旧state schema2、jobs0／scopes0及原字节SHA；独立[一次性工具](../../scripts/server-memory-transition.mjs)读取项目外EATING_MEMORY_TRANSITION_CONFIG，存在Host锁、哈希不符或非空jobs／scopes即停止核对。config只改schema3／revision+1，settings仅移除archive并加入autoCommittrue／commitTokenThreshold20000，Key／endpoint／user／范围规则及其他设置保持；空state仅schema2→3，其余metadata保留。生产读取始终严格schema3，无自动迁移层。

正式五插件同data目录安装运行：全部connected、DSH ready、nativeWeb ready、gateway idle／queue0、service active／enabled、异常restart0、tracked tree clean。记忆真实公网HTTP `isSecureContext=false`、插件ready／schema3 connected／无错误、扩展错误消失，autoCommit=true／阈值20000；四plugin面板pageerror0、无意外mutation／测试发送／生成。Host settings／各表行数与schema、除明确memory转换外的保存配置与Token、原native UUID、2份原生日志prefix保持。首次raw hash比较有11个DSH正常派生／运行文件变化（nonce／outcome／bridge source／systemprompt／url／index record rows／日志追加），无缺失，故按语义保留＋私人备份报告，不称全部文件逐字节不变，也不把strict差异当数据丢失或回滚。

本地完整1824项通过／8跳过（122.16秒）、build／type通过、24项相关浏览器通过；官方stock3项实跑且未加载扩展，72fecad Linux专项23项2.18秒、云端扩展Linux回归11文件363项42.70秒。媒体当前默认auto且没有confirmed mapping，实际仍Base64；用户以后按实际部署配置sourceRoot／hostMappingRoot／onebotRoot并确认一次才尝试标准file，机器人可读性未真人probe。用户原Token链接重入即可，无需重装。
