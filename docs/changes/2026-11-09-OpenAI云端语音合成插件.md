# OpenAI云端语音合成插件

日期：2026-11-09。本地开发与验证完成，未部署。

- 新增独立text-to-speech@0.1.0，通过OpenAI Realtime将DSH组织的文本合成为语音；主人配置音色，AI按次选择语气。
- 增加稳定请求、异步任务、查询／分页、转写核对、试听与主人删除，错误／未知不自动重新计费。
- SDK／Host提供受控音频资源与lease，QQ用独立record段发送真实资源引用，复用既有scope及发送幂等。
- 面板支持中英文、配置CAS和非秘密草稿保持，隐藏清Key／Blob并停止轮询；宿主CSP仅增加同源和Blob媒体。
- 应用0.20.0、plugin-sdk4.10.0、QQ0.15.0；其他既有插件因SDK产物字节变化按封存规则同步补丁版本，无新增外部依赖版本。

当前契约见[ADR-0051](../decisions/ADR-0051-OpenAI云端语音与受控音频资源.md)，[使用说明](../operations/OpenAI云端语音合成插件.md)与[验证报告](../reports/2026-11-09-OpenAI语音插件本地开发验证报告.md)。

实际验证：完整构建／严格类型、全量1902项通过／11项条件跳过、11项相关浏览器通过，语音最终补充12项通过，离线构建／服务脚本32项通过。已授权本地提交；未push、未安装真实Key或部署，真实音质及真人QQ播放待主人明确验证。
