# 自主思考休息上限

日期：2026-11-09。应用／Host／Web0.19.0、plugin-sdk4.9.0、DSH0.18.0；API4、其他版本与依赖保持。

- 增加默认15分钟的主人可配置最长休息／等待时间，两种状态到期均可重新考虑，不要求发言。
- 超长休息按上限缩短；实际下次资格时间同时考虑更早任务与小时配额。
- 保存更短上限会缩短旧安排，但保持保存后暂停与原有额度／失败规则。
- 新自主文件严格schema2；已授权部署通过独立离线工具显式转换原schema1，生产不增加兼容或自动迁移。
- 设置页提供双语字段、范围与关联校验，保草稿与现有布局；修正滚动测试对明确只读POST的误判。

根因和当前契约见[ADR-0050](../decisions/ADR-0050-自主思考休息上限.md)，实际验证及部署见[本轮报告](../reports/2026-11-09-自主调度边界与可行性验证报告.md)。
