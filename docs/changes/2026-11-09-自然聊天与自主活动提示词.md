# 自然聊天与自主活动提示词

日期：2026-11-09。应用／Host／Web0.18.1、QQ0.14.2、DSH0.17.1。

- 区分正常找我的交流、正在接话、选择性群聊参与和明确无需回复，减少“多回复／少回复”同时影响所有场景。
- 先回应眼前内容，后续随对话展开；先删多余内容再选气泡，保持必要完整内容与真实发送回执。
- 为自主机会补充真实话题、兴趣和社交选择，明确暂时休息用有唤醒时间的sleeping，waiting会停止普通定时思考。
- 按已授权范围通过正式CAS接口定点更新云端common的相关表达指引与匹配的旧默认尾段，保留其余主人正文和人格。既存waiting可通过现有wake重新规划一次，配置及调度语义保持。
- 原有浏览器断言误将POST media-transport读取计作写入，只排除该明确空input读取，其他POST仍计入写入检查。

范围、根因与验证边界见[ADR-0049](../decisions/ADR-0049-自然聊天与自主活动提示词.md)和[本轮报告](../reports/2026-11-09-自然聊天与自主提示词部署验证报告.md)。
