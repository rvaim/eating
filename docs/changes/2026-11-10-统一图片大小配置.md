# 统一图片大小配置

Eating 原先在图片资源、插件、下载和发送多个环节写死 5 MiB，并为可信 Base64 图片单独写死总预算。现在由主人在“设置 → 图片大小”统一配置，默认单图 10 MiB、范围 1–50 MiB，多图合计为 2 倍、最多 4 张，传输预算随之计算。

新增 Host 独立严格设置与 CAS 管理 API，SDK 提供实时快照；生图、表情库、QQ 收图／发图和预览使用同一限额。库格式验证与操作上限分离，调低后保留已有图片；旧发送 lease 撤销，已经接受的生图任务保留提交时上限及结果。普通 QQ 参数、来源权限和未知不重发规则保持。

最终应用0.21.1／plugin-sdk4.11.0／ui-sdk4.3.0／QQ0.16.0／生图0.4.0／表情包0.3.0／语音0.1.2，其他 SDK 产物消费者补丁升级；无新依赖和锁文件变化。决策见[ADR-0052](../decisions/ADR-0052-统一可配置图片大小.md)，操作见[图片大小设置](../operations/图片大小设置.md)，实际验证与 Git／部署状态见[本轮报告](../reports/2026-11-10-图片大小配置验证报告.md)。

源码de79aee已push并由云端从GitHub拉取构建部署；公网检查发现的停用语音查询误报按ADR-0053修复，保留配置编辑。原有五插件与DSH正常，默认图片10MiB，原数据保留。
