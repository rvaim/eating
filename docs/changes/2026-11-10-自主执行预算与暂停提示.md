# 自主执行预算与暂停提示

maxRunMinutes改为累计自主轮次准入至结算的执行时间，间隔、额度等待及停机不再消耗；已结算用时跨重启保留，休息／等待或主人恢复开始新预算。预算耗尽仍暂停，真实超时／失败和unknown防重保持。

概览直接区分预算暂停与运行故障，显示上限、代码和累计执行时间。补齐简中／英文恢复按钮翻译，保留成功的周期历史，不把预算停止写成模型失败。

应用0.22.0、DSH0.19.0，自主状态严格schema3。独立停机工具显式转换schema2→3并从零开始新的执行预算，保其余配置、安排、历史、暂停和错误；旧格式不在生产自动迁移。主人已授权本轮提交／push和云端保留数据部署，实际结果见[报告](../reports/2026-11-10-自主执行预算修复部署报告.md)，契约见[ADR-0054](../decisions/ADR-0054-自主执行预算与暂停原因.md)。
