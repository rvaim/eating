# ADR-0003：唯一长期主 Agent 与主 Session

- 状态：Proposed
- 日期：2026-10-26
- 来源：v0.3 §7 的推荐方向
- 2026-10-26 范围补充：依据 [ADR-0006](ADR-0006-可替换Harness与认知边界.md)，唯一身份不绑定 DSH 原生 Session；本提案用于选定 Harness 的主运行脉络，以下 DSH ID/SDK/Preset 是首个适配器案例，跨 Harness 迁移和单 Session 可行性仍未验证。

## 背景与决策提议

唯一 AI 身份需要连续的主要生活脉络。建议以一个逻辑主 Agent 和长期主 Session 接收各平台必要的新事件，按需取聊天历史和插件记忆；子 Agent 仅做委派执行。

外部会话 ID 不当作 DSH Session ID。保存逻辑别名与真实 ID 的映射，并在恢复时验证会话和 Agent 配置。原候选 `eating-main` 仅为设计名称，未写入真实数据；内部命名尚待确认。

## 原因与备选

主 Session 可降低多入口人格分裂风险。每个联系人新建自主 Agent 不采用。按外部上下文路由多个技术会话是否仍可共享同一身份是替代方案，但只有单主方案验证不满足需求时再评估，不改变唯一身份基线。

## 影响与风险

长会话混合来源的隐私、上下文压缩、工具权限和忙碌时事件排序均需实测。单 Session 不能自动提供联系人隐私隔离。

SDK 接受的真实会话标识和恢复流程以接口为准；创建句柄不等于持久创建会话，恢复也不等于恢复 Preset。

## 验证依据与后续

见[Session 设计](../architecture/主会话模型.md)与[源码核对](../research/DSH源码核对.md)。Phase 1 验证持久恢复与配置，Phase 2 验证忙碌消息及隐私，Phase 3 验证连续性。尚无运行实验，不提升为 Accepted。

替代关系：无。
