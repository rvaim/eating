# ADR-0019：统一插件与 MCP 能力管理

状态：Accepted。日期：2026-10-30，Asia/Shanghai。用户已确认两种能力接入方式（直接 MCP 与插件提供 MCP），要求侧栏有 MCP／插件入口，每个插件有独立面板，并交付支持手动与 AI 添加、描述、标签、分页筛选的表情包插件。

## 当前决定

插件是安装及生命周期单位，MCP 是工具接入协议。插件分 communication、harness、capability 三种；机器人和 Harness 是对应类型的业务视图，插件页统一安装、更新、启停、卸载和进入独立面板。面板从验证后的贡献加载，不在通用页硬编码表情包、QQ 或 DSH 的私有 UI。

MCP 页汇总直接 stdio／Streamable HTTP 连接与插件提供的工具。保存直接配置不执行命令；连接时使用官方 MCP SDK，stdio 不经 shell，敏感环境变量、请求头和 URL 查询值只保存在私有配置中。连接状态、工具目录、授权给哪个代理以及 Harness 挂载状态是不同事实；目录不得用默认成功掩盖未连通或接口缺失。

每种能力按代理类型和精确工具名授权。新能力初始不自动授予，主人可通过管理页选择。QQ 原有通讯 MCP 仍依据账号／目标／消息／资源 scope 管理，总 MCP 页不能发放绕过该限制的全权 QQ 连接。主和普通 Harness 会话按 main 授权，QQ执行代理可组合通讯工具与额外能力。宿主给每 Agent、每服务签发短期内存 lease，撤销后旧连接和在途资源操作失效；安装启用不等于授权所有工具。

授权或工具拓扑变化时，撤销旧 lease 并停止受影响的运行 Harness，明确提示重新启动，使下一次 Agent 创建按新目录装配；不偷偷让旧进程保有工具。逻辑 scope 和令牌不是操作系统沙箱，用户安装可信代码或授权 ADB／浏览器服务仍代表它们实际拥有的本机权限。

## 插件安装

复用原有路径、文件树、哈希、大小和不可变版本校验。预览只读并封存同一份内存快照，确认安装不重新读取可变来源目录。当前只接受本机已构建插件目录；在线市场、任意仓库安装和自动依赖下载不在本轮范围。

Host 持有工作区锁时允许通过专用内部选项执行安装事务，仍持有安装索引锁并确认本进程真实持锁。磁盘提交后停止旧实例、导入新入口并激活；激活失败说明已发布代码与运行失败的区别，保留版本和数据。卸载不等于删除配置或表情库，重装可继续使用。新插件代码不经无确认的页面请求自动运行。

## 资源与表情包

表情包收藏属于插件自己的资源库，不要求 OneBot 提供 QQ 收藏接口。每项有稳定内容哈希 ID、描述、标签、MIME、大小及创建／更新时间。支持手动本地文件添加，以及执行代理从当前获准消息的 image 引用收藏；AI 提供描述和标签，但不能传任意宿主路径或从文字伪造收到图片。

列表只返回元数据，默认20条、最多50条，支持描述关键词和标签AND筛选、offset／nextOffset、total／hasMore，分页可带revision检测中途变化。不会每页附带全部原图或让模型重复识图。get 才提供图片预览和可发送引用，模型内容中同时有真实的发送引用与元数据。

跨插件媒体通过公开资源服务：表情包返回 `eating-asset://stickers/<assetId>`，QQ 发送前在同一授权生命周期中解析为标准 OneBot base64 图片。主机或 OneBot 即使不共用文件系统也不依赖本地文件路径；原始图片不通过模型参数搬运，也不进 Host 动作账本。读取前后复查授权，在真实发送或资源提交前检查调用未被撤销。

写入要求稳定 request_id，元数据更新／删除要求CAS；未知外部动作不盲目重发。外部 MCP 写工具使用独立 arguments＋request_id 信封，不改上游工具参数，Host 记录有界动作结果，不把任意远端原图和秘密作为新历史库存储。

## 版本和数据

本轮统一插件 API4、共享 SDK4.0.0、应用／Host／Web0.11.0、QQ0.11.0、DSH0.8.0、stickers0.1.0。不保留旧 API3 的运行兼容层。Host SQLite、作者、QQ、DSH现有数据schema不因此重置，生产代码包升级应停机备份后一并切换，保原Key、人格、会话与账本。

MCP 私有配置与表情库各自采用schema1及revision；插件资料位于自身数据目录。卸载保留的数据不自动授予新工具，工具目录变化需要重新核对授权。

## 验证

实际执行证据记录于[本轮报告](../reports/2026-10-30-MCP插件与表情包验证.md)。必须覆盖直接 stdio／HTTP、真实系统 DSH 挂载、手动及 AI 收藏、分页、表情发送、撤权竞态、防重复、插件安装更新和卸载保留、重启保持，以及明暗／窄屏管理界面。只使用临时数据和回环模型／OneBot，未验证的真实第三方设备或浏览器行为不得声称可用。

本决策扩展 ADR-0007／0012 的插件种类与管理流程，承接 ADR-0018 的系统 DSH 和原始官方 Web，保留其余认知、授权、数据和当前不兼容原则。
