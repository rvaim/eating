# ADR-0020：独立OpenAI Images生图能力

状态：Accepted。日期：2026-10-30，Asia/Shanghai。用户确认使用OpenAI Images API，配置Base URL、Key、模型并提供MCP；明确本轮不处理OneBot部署与图片发送。

## 决定

新增image-generation@0.1.0能力插件，插件API4、平台0.11.0不因独立新插件而变更。后台、面板、配置及资源独立发布，复用平台插件目录与MCP授权；不在通用管理页硬编码本插件。它不引用QQ、表情包或DSH的私有实现，只依赖公开SDK。

请求为配置Base URL加/images/generations，Bearer独立Key，配置模型和prompt，固定n=1，可选size、quality和response_format。空参数不猜测、不发送；按服务实际模型支持填写，不根据模型名字推断。不回退聊天、Responses或Gemini原生协议；图生图、编辑与批量另行设计。

Key私有写入，公开状态仅配置值及apiKeyConfigured；CAS更新，省略／空Key保持、显式clear才删除。保存与connect不触网，不把本地配置就绪说成服务认证已通过。明确手动生成按钮和MCP授权才允许调用可能计费的生成。

## 异步与计费

文生图可能超过单次MCP工具期限，因此提交后返回持久任务ID，后续查询状态与资源。平台不在超时后自动重发。稳定request_id对应同一输入和同一任务，参数冲突拒绝；独立任务索引与Host提交账本共同防重。提交成功只表示任务接受，只有图片校验并落库后才succeeded。

发出后超时、断网、撤权或重启可能已经计费，状态unknown；运行中任务重启后不自动重放。每插件至多一个活动任务，容量有界并在生成前核对。提交前核对Agent调用授权signal；已持久并正式提交的后台任务由插件自己的controller管理，Agent正常结束不丢弃已付费结果。停用/dispose才中止本插件等待并标unknown，后续查询与取图仍需当前Host授权；主人任务离页同理继续，UI取消轮询不伪称取消了提供商计费。DSH子任务最多120秒，低于生图默认180秒，不能把异步任务错误绑定到子回合结束。

## 图片与界面

支持data[0].b64_json或data[0].url。认证仅向配置服务发送，结果URL不带认证下载，禁重定向、有界大小／时间、校验MIME和真实字节。Key、签名URL和完整响应不写普通任务或Host账本，错误固定脱敏且区分失败与未知。

图片保存在capabilities/image-generation，列表只有元数据，单项get返回实际MCP image和文本可见sendable引用。它是用户主动生成的资源库，不是聊天媒体历史。卸载保留数据，AI不传本机任意路径。图片预览Blob在隐藏／离页清理；轮询仅可见且有活动任务，locale不进入请求effect，不触发付费调用。

本轮沿用公开资源5MiB单图和分页50条上限，不借机修改OneBot或本地文件读取策略。既有QQ/DSH/表情库/作者数据schema和系统DSH官方Web不动。

## 验证与边界

必须覆盖真实本地HTTP请求及认证、路径前缀、Base64／URL结果、无重定向／凭据传播、超时、失败／未知、不重复计费、跨重启、授权撤销、独立产物安装和明暗／390px浏览器；系统DSH实跑验证Agent提交／查询／取图，模型和生图服务均为回环。无用户真实Key时，不声称真实提供商、具体模型和付费生成已验证。
