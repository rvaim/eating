# ADR-0021：DSH 原生能力与插件管理

状态：Accepted。日期：2026-11-01，Asia/Shanghai。确认来源：用户提出在 DSH Harness 面板选择启用原生能力和 DSH 插件，并明确要求“把功能加上”“一次完成”。

## 背景与原因

Eating 原有 DSH 适配在启动 overlay 关闭文件、终端等工具，并在主/子 Agent 处过滤继承工具，只挂载 Eating 受控委派和获准 MCP。系统 DSH 同时已经提供原生插件、作用域、PluginManager 和 ConfigEditor。只增加前端开关无法改变模型的真实工具集合；把所有插件全局加载后让所有 Agent 继承，又会破坏既有主子授权。

## 决策

1. 在 DSH 独立面板增加“连接配置”“原生能力与插件”两个页签。原生管理区包含功能目录、DSH 插件、插件工具授权，读取真实系统安装和 Eating 专属 Profile 的目录，不读取主人主 DSH 配置或凭据。
2. 官方原生功能在每个选中 Agent 的独立 scope 加载；保存时先由实际 DSH 原生配置与依赖校验。功能目录提供时间、文件读写与图片读取、文件搜索、工作目录、Bash/PowerShell、后台任务、网页、技能、提醒、目标、待办、结构化提问和交付。平台或模块缺失明确显示，不根据名字虚报可用。
3. 时间上下文默认保留现有主子代理行为，其余原生功能初始关闭。开启文件功能默认只读，主人可编辑完整模块 JSON 配置选择写入/编辑等参数。功能的启用、代理范围与保存独立于连接和图片能力。
4. DSH 插件以原生 Bundle 为安装单位，以实际 Loader entry 为模块单位。官方 PluginManager 负责 inspect、install、enable、disable 和 remove；ConfigEditor 负责完整配置替换。检查来源后主人确认才安装，默认安装为停用；启用、工具授权和卸载分别操作，卸载保留资料。
5. 实例级插件可贡献全局工具，但不会自动授予 Agent。精确工具名、schema SHA-256 指纹和代理类型共同构成授权；当前继承过滤器和最终执行 guard 同时检查。新增、消失或变更的工具不会继承旧授权；模型不能通过插件工具绕开 Host 的 QQ 会话 MCP scope。原生能力与作用域不是 OS 沙箱。
6. 原生内核、Eating 桥与官方 Web 必需组件展示为基础组件；不得从该面板停用维持自身管理、交接和原生 Web 的组件。其他实际可管理模块可配置、启停。原生 Web 自身仍保持官方 UI 和正常主人操作，不增加自定义客户端或只读访问层。

## 生命周期、协议和数据

新增独立 native-capabilities.json，严格 schema1/revision/CAS。旧版本或坏文件拒绝且不覆盖；文件不存在代表新功能尚未配置，使用完整当前默认值。现有连接、图片能力、会话、绑定和 Host/QQ schema 不变，无迁移分支。

已运行 Harness 的目录读取和挂载观察复用同一原生进程。停止时按需启动短生命周期 SDK 管理进程，和正式运行互斥；不创建 Agent/会话、不调用模型、不处理 QQ。连接配置修改、启动和原生管理具有排他检查，清理失败阻止另开实例。模型连通、模块可解析、配置校验、实际挂载和任务成功分别报告。

内部管理仅随机 loopback 端口，带协议版本、nonce、本次令牌、大小和超时限制。原生控制入口和令牌不进入普通配置/日志/模型上下文。插件配置不回显保存值和秘密；留空保持，显式提交完整对象替换。安装错误只返回原生结构化原因，不透出原始 pnpm 输出或凭据。写操作带稳定 requestId，冲突或未知不自动重复执行。

前端隐藏/离页取消读取并清理插件配置与安装来源输入；语言切换只改变文案，保留非秘密草稿、选区与授权选择，不发请求或保存。选择与实际应用版本同时显示，重启后按真实 Agent 创建观察挂载状态。MCP 挂载从运行记录读取，授权继续使用既有 MCP 页。

## 影响与替代关系

DSH 插件升级至 0.9.0，应用、共享 SDK 和 API4 不变。扩展 ADR-0014 的固定两工具集合为主人显式授权的原生功能及插件工具；受控通讯委派、身份、会话与 QQ scope 保持。ADR-0018 的系统 DSH、原生 Web 与独立数据原则保持，ADR-0019 的 Eating 插件与 MCP 授权不被复制或绕过。

操作见[使用说明](../operations/DSH原生能力与插件.md)，设计和接口见[实施契约](../plans/2026-11-01-DSH原生能力与插件管理实施契约.md)，实际运行、构建和浏览器证据见[验证报告](../reports/2026-11-01-DSH原生能力与插件管理验证.md)。真实第三方服务的凭据、提供商搜索和业务效果需要各插件自己的正确配置；本地隔离验证不冒充这些外部业务已经验证。
