# ADR-0023：自主活动协调与主动通讯授权

状态：Accepted。日期：2026-11-01，Asia/Shanghai。实现与设置页由用户在评估[自主轮询设计](../architecture/自主活动.md)后明确授权，实施边界见[契约](../plans/2026-11-01-自主运行与设置面板实施契约.md)。

## 问题

原Host wake只重新检查已存在的外部消息队列，空队列不会产生思考机会。time-context只在已有模型步骤补读时间。原生持续目标可以推进主人任务，不能代表没有任务时的自主选择。QQ委派绑定当轮入站批次，不能借用过期来源主动联系别人。

## 决策

1. 认知和工具调用始终使用同一原生主Agent及DSH Agent Loop。桥接服务仅负责活动机会的机械准入、持久状态及已授权通讯，不生成任务、兴趣或长期记忆。只检查时间/状态的1秒心跳不调用模型。
2. 主人独立设置enabled/ownerPaused与上限。AI通过eating_activity_state/eating_plan_activity登记active、sleeping、waiting及wakeAt、说明；AI不能开启主人暂停或修改限额/联系人。配置保存有CAS，独立于开启/恢复，保存即暂停并撤旧许可。默认关闭，不因升级发起费用。
3. 新autonomy.json/schema1保存配置和活动revision、窗口计数、轮次nonce/ID/截止时间、最近20次无正文结果。每小时限制自主轮次/联系任务，连续运行时长、单轮时长、失败阈值均生效。未知立即暂停；正常失败有有限退避和连续阈值，不解释成自主休息。进程崩溃中的轮次不自动重放；自动恢复为主人选项，仍保未知阻塞、既有休息/等待，过期唤醒合并一次。
4. 入站消息/原生目标/原生其他Inbox输入优先。只有主Agent空闲且无上述工作时，持久登记一次活动机会再用公开Agent.followup入队；pre-step重新核对当前nonce、cycleId、主人状态和竞争事件。原生目标的自动续行不再重复另排自主轮次。新一轮开始前与每个自主步骤再次核验，保存/暂停立即撤销通讯MCP并取消自主轮次。普通外部事件不伪装成主人指令，自主事件有独立eating-autonomy来源。
5. 通过可选公开SDK能力发现通讯ProactiveChannel和构造范围；实际自主启用要求Host具备必要队列协调与scope接口，缺失明确报不支持。通用设置页不硬编码DSH/QQ。
6. 主人精确保存主动联系人：plugin/instance/account/agentType/target和工具集合。模型仅提供已保存target引用和任务，后台构造没有旧message/resource引用的scope，复用原生子Agent、受控Host MCP和真实动作账本。每次调用重新核对有效周期及授权，AbortSignal传入资源/发送检查。主动联系每小时限额是任务数，任务内多次调用仍受工具/目标和单轮时长限制。
7. 主动子会话使用单独proactive-bindings.json/schema1和稳定UUID，不改外部消息代理schema2及UUID。每目标保留有界32个native callId摘要，当前周期不能溢出后遗忘防重。pending/unknown阻止新联系；迟到任务ID或nonce不能覆盖状态。主人在设置页明确核对未知任务后解除任务阻塞，不删除动作账本或重发。
8. 主Agent主动周期安排使用eating_plan_activity。周期中拒绝再创建/编辑独立原生Schedule，避免通过第二条提醒链绕过主人暂停；既有主人原生提醒和目标保持其自身语义。原生Web保持官方界面和正常操作。

## 设置与信息

设置→自主运行提供Harness选择、运行信息/运行配置/主动联系授权页签。显示主人暂停、AI安排和说明、下次时间、运行时、小时窗口用量、连续失败、当前cycle/截止时间、最近结果/错误、未知联系任务核对。配置全量CAS，草稿不随状态轮询或locale丢失；冲突展示最新设置、主人明确核对后才保留草稿重存。隐藏/离页取消读取，变更结果不确定先重读；按当前页面5秒查询，无历史聊天正文缓存。

## 验证与限制

系统DSH在独立HOME与本地模型/OneBot执行无入站唤醒、休息后继续、等待无模型调用、外部消息优先、真实主动发送回执、暂停保未知及重启保持。负面测试含错误nonce/目标、旧callId、权限撤回、配置CAS、额度、损坏文件保留。版本及最终结果见[验证报告](../reports/2026-11-01-自主运行与设置面板验证.md)。

额度是轮次/时长/任务计数，尚无提供商账单级货币预算或每目标消息条数保证。普通入站处理及主人原生目标/提醒由其原生机制执行，不受自主轮次额度代替控制。关机/休眠不保证实时唤醒；长期有意义自主性和长期记忆质量需要用户以真实授权、费用和运行观察进一步判断，自动夹具不能证明人格、兴趣或长期行为质量。
