# ADR-0025：主动群聊对象黑白名单

状态：已被替代。用户后续明确要求统一的“全部放行／白名单／黑名单”同时作用于私聊和群聊，不接受本文件的群聊独立规则/逐个联系人方案。当前唯一实施契约为[统一主动联系名单策略](ADR-0025-统一主动联系名单策略.md)。以下保留本轮被否定方案的记录，不代表现行产品或数据迁移要求。

## 对象规则

按通讯插件、账号实例、真实登录账号及群聊代理类型配置一条规则；可停用，启用时明确选择白名单或黑名单。白名单只允许所列群号，空白名单不允许任何群；黑名单允许当前账号实际已加入且未列入排除名单的群，空黑名单意味着当前已加入的全部群。界面必须把这个范围写清楚，保存不立即启动自主活动。

每条规则仍需精确选择当前已获准的工具；允许全部只展开成当前工具名，不自动授权将来新增工具。群号列表与工具列表分别表示对象和动作，不能混淆。已有精确联系人保留，启用某账号群规则后，该规则同时约束其已有群联系人；私聊联系人不受群规则影响。

## 原数据与协议

新增独立proactive-group-rules.json/schema1保存规则及CAS revision；没有文件的新规则集使用完整空默认值，不读旧格式、不迁移或改写autonomy.json/agent-bindings/QQ配置。损坏或旧schema明确报错，不覆盖。读取规则与列群不写配置。

SDK扩展通讯插件的受信群目录查询、Host到Harness的目录接口以及公开规则类型。QQ通过OneBot get_group_list读取当前账号已加入的真实群，只返回群号/名称；查询前后核对登录账号、实例和连接状态。模型不能把任意群号当成已加入群。

DSH将固定联系人和对象规则解析出的群合并为可联系目录。列出与发起任务均刷新目录，名单/账号变化会拒绝迟到结果；每次任务仍固定真实账号、代理、目标和工具，保留动作防重、次数额度、子UUID与unknown语义。群规则覆盖的已有精确群联系人遵守规则；重复对象使用已有联系人工具与群规则工具的交集；交集为空不产生第二份更宽授权。

## 保存与撤权

规则保存使用自身revision及当前自主配置/活动revision核对，先做完整校验，随后暂停自主活动并撤销在途主动任务许可，再提交新规则。任何失败明确显示，不把暂停或未知结果冒充未执行。保存后需要主人明确恢复；规则修改不能让旧周期或旧MCP许可继续发送。规则停用/移除也按相同流程保存。

## 验证范围

需要白/黑/空名单、停用、重复与非法群号、账号变化、列表迟到、保存冲突、损坏文件、原文件保持、群规则与固定联系人交集、精确工具、发起/在途撤权以及双语/窄屏/键盘测试。只使用独立OneBot和模型回环夹具，不改真实名单或试发真人消息；真实页面仅查看和截图。
