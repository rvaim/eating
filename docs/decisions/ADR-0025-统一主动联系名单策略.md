# ADR-0025：统一主动联系名单策略

状态：Accepted。2026-11-01用户明确纠正：主动联系应使用一个“全部放行／白名单模式／黑名单模式”选择，同一模式同时用于选中的私聊和群聊。先前群聊独立规则、单个联系人逐项工具授权的设计被否定，不作为当前产品行为。

## 模式与界面

“主动联系”只有一个模式选择。全部放行允许当前连接账号的好友和已加入群；白名单只允许选中的私聊对象和群聊，空名单全部禁止；黑名单禁止选中的私聊对象和群聊，其余好友/已加入群允许，空黑名单等于全部放行。

私聊/群聊是对象选择分类，不是两套策略。按账号从真实好友/已加入群目录中搜索、勾选，也可手动添加号码；白名单手动私聊可表示主人明确指定的精确账号，群聊仍必须是已加入群。切分类、搜索、语言和切模式不丢已选对象。全部放行收起对象列表，回到名单模式后保留此前选择。工具权限使用通讯插件的代理权限页，本页不重复配置工具。

## 数据与接口

新增独立proactive-contact-policy.json/schema1，包含revision、mode和entries。每个对象由pluginId/instanceId/真实accountId/agentTypeId/targetId绑定，带展示label；最多1000项、256KiB，严格形状/数值/唯一性校验。没有该文件时使用完整空白名单默认值，读取不写文件；不迁移或覆盖原autonomy.json、QQ配置、代理绑定或之前试作的群规则文件。旧字段/损坏格式明确报错，不做兼容读取。

SDK提供受信联系人目录接口。QQ分别调用OneBot get_friend_list/get_group_list，只返回号码/名称，查询前后检查真实登录账号、实例、类型和连接。Host再次核对插件身份及启用状态，拒绝迟到的旧账号结果。

DSH模型使用同一策略解析可联系对象：列出和发起时重新获取当前目录，按统一模式筛选两类对象；目标ID稳定绑定真实账号、类型和号码，不能由模型提供额外scope。工具集合来自该类型当前已授权工具；未获工具的类型没有可联系对象，名单不扩大工具权限。仍复用受控子Agent、真实动作回执与额度/unknown防重。

## 保存与撤权

configure-contact-policy同时核对联系策略revision和自主配置/活动revision。完整校验后，先暂停自主活动并撤销旧主动任务许可，再提交新策略；失败如实报告，未知结果先重读，不自动重试。存在未保存策略草稿时不能开始或提前唤醒。策略提交后旧周期和旧MCP许可不能继续发动作。

list-contacts只读真实目录，不写策略或调用模型。新策略只有主人保存后生效；实际验证不得替主人选择或保存全部放行。

## 验证

覆盖三种模式同时作用于私聊/群聊、两种空名单、账号/类型区分、手动精确私聊/已加入群、工具权限、重复/非法对象、CAS、损坏存储、异步目录迟到、暂停撤权及实际Host/OneBot/MCP回环。界面覆盖单模式/双分类、搜索与草稿、语言、390px、冲突核对及MCP/插件固定二级侧栏。只使用独立协议夹具，不真人或付费试发。
