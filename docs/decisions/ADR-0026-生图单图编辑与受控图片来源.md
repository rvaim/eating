# ADR-0026：生图单图编辑与受控图片来源

状态：Accepted。日期：2026-11-01，Asia/Shanghai。用户确认使用 Magpie 中转的生图模型，并会在 QQ 或其他平台会话插件中发图给机器人和 AI，要求直接加入“给一张图让 AI 改”的能力。

## 背景

image-generation@0.1.1 只调用 `POST <baseUrl>/images/generations`，输入只有提示词、尺寸、质量和返回格式。用户发来的图片虽然可被通讯插件读取，但生图插件不能把它作为编辑底图；ADR-0020 也明确把图生图、编辑和批量留待另行设计。

Magpie 网关当前提供 `/v1/images/edits`，接受 multipart 的 `image` 文件、`model`、`prompt`、`n` 等字段；实际模型返回 JPEG 或 Base64，和 OpenAI Images 兼容。Eating 的通讯插件已经通过 `PluginResourceServices.readReceivedImage` 提供受控的当前会话图片，表情包插件也验证过 `messageId + imageId` 的授权模式。

## 决定

image-generation 升级到 0.2.0，增加单图编辑 MVP：

- `image_generate` 增加可选 `source`。`kind:"received"` 使用当前会话消息的 `messageId` 和 image 段原始 `file` 引用 `imageId`；`kind:"asset"` 使用本插件已有图片的 `assetId`。不传 source 仍走文生图。
- 生图服务面板增加“参考图（可选）”本机上传；owner `manage.generate` 使用 `source={kind:"upload",data,mimeType}`。参考图大小和格式按公开资源接口的 5 MiB、PNG／JPEG／WebP／GIF 校验。
- 有参考图时 provider 使用 multipart `POST <baseUrl>/images/edits`，字段至少包含 `model`、`prompt`、`n=1` 和 `image`；仍沿用现有超时、禁重定向、响应大小、MIME／字节校验及不回显服务原响应。
- 任务幂等哈希加入参考图 SHA-256；同一 request_id 更换参考图会拒绝，不会误复用旧任务或重复计费。任务只保存来源类型、媒体类型、字节数和哈希，不保存图片 payload、原始消息引用或签名 URL。
- 任务 schema 保持 schemaVersion 1，新增可选 `source`／`sourceHash` 字段；旧文生图任务没有这些字段仍可读取，不自动重写、不迁移、不删除原数据。
- MCP 只允许当前会话已授权收到的图片或本插件自身资源；不接受任意路径、任意 URL、其他插件私有图片或不存在的 assetId。来源读取前后复核调用 signal 与 Host 授权。

## 备选与否决

- 在聊天或 Responses 接口里隐式改图：否决。会绕开独立生图配置、计费隔离和任务状态。
- 让模型传任意本机路径或 URL：否决。无法保证来源、授权和大小边界。
- 用 JSON Base64 代替 multipart：只在某些兼容服务可用，不能作为 OpenAI Images 编辑接口的统一契约；MVP 明确只走 `/images/edits` 兼容路径。
- 蒙版、多图参考、批量编辑：本轮不做，另行设计。

## 影响与边界

- 目标服务必须实际支持 `/images/edits`；不支持时明确失败，不回退 `/images/generations`。
- 当前只支持单张参考图、无蒙版；输入和输出均 5 MiB 上限。
- 通讯插件必须实现 `readReceivedImage`；QQ 使用 `messageId + imageId`，其他平台沿用同一公开资源契约。
- DSH/QQ 发送、表情库、主 DSH 和原生 Web 不改。

## 证据

本地独立回环 HTTP 夹具覆盖 multipart 字段、参考图字节、鉴权、无重定向、同请求异图冲突和 MCP／owner 两种来源；Host 集成覆盖真实 capability MCP 的会话 scope。浏览器覆盖上传参考图、`/images/edits`、任务来源标记和预览；完整插件在临时数据目录中使用已保存 Magpie 模型完成一次真实编辑，任务 succeeded 并返回可解码 JPEG（1024×1024），另直接请求 Magpie `/v1/images/edits` 得到 HTTP 200。实际实例已通过运行中 Host 插件管理升级到 0.2.0，旧 0.1.1 保留，配置与生图 state 哈希不变，页面实际显示参考图入口。完整结果另见[本轮报告](../reports/2026-11-01-生图单图编辑验证.md)。
