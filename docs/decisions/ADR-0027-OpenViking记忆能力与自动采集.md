# ADR-0027：OpenViking 记忆能力与自动采集

状态：Accepted。日期：2026-11-01，Asia/Shanghai。确认来源：用户在本会话确认记忆设计并要求开始开发，随后明确使用 impeccable、ui-ux-pro-max 改善交互。当前选择是 OpenViking SDK、可读会话区分、全局记忆开启、按群启用/成员黑白名单、主人跨会话查看、自动采集与提取、无每日提取上限。用户自行创建服务用户。

## 背景

Eating 已有统一人格、单主 Agent、QQ 私聊/群聊的可信来源和原生自主活动。用户希望没有主动调用保存工具时仍能记住自己的对话与行动。官方 DSH 记忆插件将非 user 来源视作合成输入，而当前 QQ 来源是 eating-external，不能直接依赖其默认用户采集规则。长期记忆应交给外部服务，Eating 不增加另一个认知循环。

## 决策

1. 新增独立 API4 capability 插件 openviking-memory@0.1.0，用官方 @openviking/sdk@0.1.0 连接用户提供的服务。普通 Node24 运行；不安装 Python 中转、不复用用户主DSH的记忆Key或Profile。SDK暂未覆盖的当前HTTP配置字段仅使用同一已验证传输的小范围公开HTTP调用，不调用SDK私有方法或旧接口回退。
2. 使用 OpenViking 原生目录。全局为 viking://user/<user>/memories；会话为 peers/<platform>-<account>-<private|group>-<target>/memories；自身为 peers/self/memories。不做哈希，不根据昵称推身份，主人仍属于其原私聊Peer。平台/账号/目标作为单段严格校验，目录可读可核验。
3. 全局记忆默认开启：召回同时查询全局与当前Peer，提取允许self及peer两个原生目标。全局是共享信息，不保证服务会将私聊事实只存局部；需要更严格隔离时由主人关闭全局。统一人格不自动复制为OpenViking identity/soul。
4. 主人私聊可显式跨Peer检索，owner由Host根据通讯插件当前owners和可信入站发送者复核。群聊内的主人不自动获得跨会话权限。自动召回仍只查当前Peer＋全局，不因主人身份每轮全库召回。原生主人Web会话使用self并有主人管理语义，自主周期self没有跨会话主人权限。
5. 记忆提供方通过公开MemoryProvider注册；HarnessMemoryServices协调当轮上下文，不保存历史。CapabilityInvocationScope.memory只由Host补充。MCP提供memory_search/read/save/scopes，精确工具授权继续走既有MCP管理；自动采集由插件已保存enabled/autoCapture授权，不依赖模型调用工具。模型不接受任意peer_id或任意URL/路径，删除仅主人面板精确文件操作。
6. DSH主Agent在公开pre-step中等待所有准入判断后，用真实本轮文本检索并注入来源为plugin:eating-memory的历史参考消息；保留其他钩子字段、拒绝和请求序列。注入不进入系统提示词、不构成授权。主turn/end提交可见助手文本、原用户消息和工具名/结果摘要，子Agent不重复采集。returned只说明函数返回，不冒充QQ成功；没有工具参数、原结果、内部推理、图片或机械唤醒正文。QQ原生ACK仍由原入箱flush负责，记忆失败不撤ACK、不阻止聊天。
7. 采集按Peer缓冲。默认小批量8条/6000字符/静默300秒，有工具动作或显式保存立即提交；另可选每轮或估算token阈值。默认自动召回、自动采集和全局开启，不设每天/每小时提取次数限制。内存/并发/索引有机械容量保护，不等于费用额度。
8. 原生临时Session以稳定任务标识创建，禁用服务自动提交，与插件自身显式commit保持单一提交控制。记忆类型preferences/entities/events。commit accepted仅表示归档已接收，继续检查task和memory_diff，记录实际变化计数，完成后deleteSession，只留下提取记忆。任务未明确终止不删除其归档；未知提交不自动重放。已知task重启后可继续查询/清理。正文仅在RAM，重启前未提交缓冲丢失并报告；落盘只有有界配置、任务元数据、来源及幂等摘要。
9. 私聊默认允许采集/召回；群聊采集默认关闭并支持逐群覆盖。规则按平台/账号/类型/目标精确匹配；群成员支持全部/白名单/黑名单，按真实senderId过滤。混合拒绝成员的回合只保留允许成员的原文，不保存可能复述拒绝成员的助手总结和工具摘要。名单更改立即影响新操作，旧记忆不自动删除。
10. 配置保存CAS，秘密留空保持、明确清除。保存不请求模型；测试连接只验证当前服务初始化及用户身份。连接、规则启用、MCP工具授权分别表达。变更配置撤销在途操作；停用/断开立即阻止新请求，结果未知保元数据。正常退出对已授权缓冲有界提交，手动断开明确丢弃未提交RAM缓冲。

## 配置与交互

插件面板为连接配置/记忆范围/运行记录三个页签，沿用Eating白绿/暗色语义令牌和公开ui-sdk。连接优先地址、用户、Key，高级账号/超时/自动连接折叠；规则摘要、按需单项编辑、搜索、可撤销删除和目录路径预览。保存栏跨页签保持，CAS/未知须显式核对，错误可定位、键盘可操作；语言不触发业务请求，隐藏停止读取并清秘密/记忆正文。运行记录区分缓冲、提交中、提取中、清理中、成功、失败和未知；浏览/搜索/读文/确认删除真实记忆文件，不保存另一份聊天。

## 影响、验证与替代关系

新增通用可选记忆契约，应用/Host/Web0.14.0、plugin-sdk4.5.0、DSH0.12.0；ui-sdk4.1.0、QQ0.13.1及原有存储保持。只在独立快照和临时EATING_HOME验证，不部署真实资料、开真实服务用户或付费提取，不修改另一会话在途文件及用户主DSH/官方Web。

此项将此前“长期记忆未接入”扩展为外部OpenViking适配，不改变ADR-0006的认知边界；承接0019、0023、0024。官方API/SDK和实际回环证据、跳过/未验证项见本轮验证报告；其他Harness可通过通用接口和MCP复用，完整自动钩子需相应Harness实现，不声称已完成其他引擎移植。
