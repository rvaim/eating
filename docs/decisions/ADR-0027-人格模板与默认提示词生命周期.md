# ADR-0027：人格模板与默认提示词生命周期

状态：Accepted。

日期：2026-11-02，Asia/Shanghai。

确认来源：主人在本会话批准一份“AI 女儿”人格模板，以及通用、主 Agent、子代理默认提示词的改进；授权提供模板草稿入口、未自定义文档跟随最新默认和单文档显式恢复默认。选择模板本身不构成人格创建或启用、覆盖自定义正文、旧数据转换或真实部署的授权。

## 背景

人格模板是主人创建固定人格的起点。模板选择、人格保存与人格启用需要保持独立，避免页面操作无意改变正在使用的身份。人格可以影响表达、兴趣和相处方式，但不能改变工具、账号和数据权限。

此前基础提示词的默认正文随其他作者操作写入后，读取仍使用保存的副本，代码更新无法作用于从未编辑的文档。恢复插件默认若删除覆盖记录，还会让文档 revision 回到 0，使旧请求再次满足 CAS，产生 ABA 问题。需要在当前 schema2 内明确“跟随默认”和“主人覆盖”的状态，并保留恢复后的版本历史。

主子协作还需区分真实动作回执、当前任务后续与未来自主安排。收到回执不等于必须停止；在 `waiting` 中处理新消息也不自动切回 `active`。本轮改进指引，不改变现有自主调度状态机。

## 决策

### 人格模板只生成草稿

[前端静态模板目录](../../apps/web/src/persona-templates.ts)本轮只有一份经本会话批准的“AI 女儿”：女性 AI，称主人为“爸爸”，依据当前上下文与可用记忆延续真实经历，不设真实年龄、固定成长阶段或预定人生，不加入女友设定或动物比喻。模板不指定记忆插件，也不假定记忆能力可用。

“人格管理→新增人格→从模板新建→使用「AI 女儿」模板”只填当前未保存草稿的正文。名称由主人填写；已填名称保持，已有非空草稿正文先确认替换。正文可自由编辑，选择模板不发起创建或启用请求，不向 `host:authoring` 保存模板目录、模板 ID 或未保存草稿。

主人显式保存后得到普通人格文档，后续模板修改不回写该人格。创建不自动启用，最多启用一份，也可以全部停用。语言切换只翻译界面，不翻译或替换模板正文、人格正文和名称。

### 默认提示词与主人覆盖独立

三份基础默认正文由 [Host 默认提示词模块](../../apps/host/src/authoring-defaults.ts)提供；角色和插件说明的默认正文来自当前注册贡献。[作者服务](../../apps/host/src/authoring.ts)仍只接受当前 schema2，使用现有字段表达状态：

| 文档状态 | revision | updatedAt | 有来源时使用的正文 |
| --- | --- | --- | --- |
| 从未编辑 | 0 | null | 当前代码或注册默认 |
| 恢复默认后 | 保留并递增的正整数 | null | 当前代码或注册默认 |
| 主人覆盖 | 正整数 | 合法时间戳 | 主人保存的 body |

`updatedAt:null` 是跟随默认的标记；不能用 `revision===0` 判断文档是否自定义。即使存储中仍有旧默认 body，快照、Harness 配置读取和组合预览也直接解析当前默认，不为刷新默认而落盘。非 null 的自定义正文保持，包括恰好与某版默认相同的主人覆盖。

`updatePrompt` 先检查文档 CAS，再判断正文是否相同。相同正文不写入，不推进文档或全局 revision；实际编辑推进两级 revision，并设置时间戳。保存当前默认的相同正文不会额外创建覆盖。

### 显式恢复保留单调 CAS

`resetPrompt(id, expectedRevision)` 在同一同步 CAS 操作中取得当前贡献、读取存储、核对来源可用性与目标文档 revision。目标已跟随默认时只读返回；目标为主人覆盖时，正文改为当前默认、文档 revision 加一、`updatedAt` 置 null，全局 revision 加一。

恢复角色或插件默认也保留该文档记录，不删除后归零。来源卸载后记录保留且只读，来源以同一稳定 ID 恢复时继续使用当前注册默认和原有单调 revision。来源缺失时拒绝恢复，即使保存记录已经是跟随状态。来源插件仅停用、仍有注册贡献时可以编辑或恢复，执行仍受插件启用状态限制。

恢复只改变目标文档及全局版本，保留其他提示词、人格、启用选择、设置、投递队列与动作账本。陈旧 revision 在幂等判断前拒绝；存储失败、容量超限、版本耗尽或来源缺失均保留原存储。现有文档和总字节数上限继续生效，恢复默认不借删除版本记录释放保存名额。

### 主人接口与界面

[Host 路由](../../apps/host/src/app.ts)新增 `POST /api/prompts/:encodedId/reset`。ID 使用 `encodeURIComponent` 编码，请求对象严格仅接受非负安全整数 `expectedRevision`，成功返回完整 `AuthoringSnapshot`。沿用主人会话、CSRF、Host 与 Origin 校验；提示词保存和人格操作也拒绝未知请求字段。

提示词页显示已保存文档当前跟随默认或使用自定义。“恢复默认”先展示确认及当前默认预览，确认后保存目标文档，并替换该文档未保存草稿；其他草稿保持。已跟随且没有未保存修改时无需恢复。冲突或结果未知时保留草稿，要求重新读取核对，不自动重复提交。

### 行为指引与实际运行分开

默认正文明确实际能力、事实与推测、上下文与可用记忆的连续性、人格对自主兴趣的影响及主子协作。子 Agent 回报真实结果与必要情境，主 Agent 可在当前有效授权内继续工作或委派，再判断后续继续、休息或等待。共享人格不表示所有会话自动共享经历。

自主安排继续使用 `eating_activity_state` 和 `eating_plan_activity`。`waiting` 处理新消息后仍保留原安排；希望继续自主活动时，AI 需读取最新状态并登记 `active`。正文承诺、人格设定和记忆记录都不等于真实唤醒，不增加提醒链绕过暂停和限额。

主动联系先通过 `eating_list_contact_targets` 取得主人当前全部放行、白名单或黑名单策略下可联系的对象及精确工具，再在当前准入自主周期使用 `eating_contact_target`。列出与发起均复核当前目录、账号、模式和工具权限，不继承旧入站消息或资源权限。策略仍按 [ADR-0025](ADR-0025-统一主动联系名单策略.md)执行，本轮未改调度、名单或执行权限逻辑。

## 影响、备选与边界

应用／Host／Web 为 0.14.0，QQ 为 0.13.2，DSH 为 0.11.3；plugin-sdk4.4.0、ui-sdk4.1.0、plugin-core4.0.0 与唯一插件 API4 保持。仍为 6 种模板作用域、9 个可信变量；DSH 继续现有 `openai-completions` 模型路径，不因模板新增模型 API 路线或第二套认知循环。

不采用自动把模板保存或启用为人格、用正文相等推断跟随状态、删除覆盖记录后恢复 revision0、升级时覆盖全部正文或读取时批量回写默认。这些做法会混淆主人选择、引入无意写入或破坏 CAS。

当前 schema2 的字段含义按本决定执行；旧 schema、缺字段和旧形状仍明确拒绝，保留原数据，没有迁移、补齐或兼容读取。人格与默认提示词不授予后台权限，不改原生 UUID 或已有会话历史，也不保证模型一定遵守指引或拥有真实长期记忆。

## 证据、后续与替代关系

回归覆盖旧未编辑 body 的只读默认解析与组合、主人覆盖保留、恢复后默认升级、基础／角色／插件单调 CAS、陈旧零和非零 revision、来源卸载与恢复、故障及容量保护、其他数据隔离、真实 HTTP 与 CSRF，以及模板草稿、确认、语言和恢复预览交互。具体命令、最终计数、截图与实际部署状态统一见[本轮验证报告](../reports/2026-11-02-人格模板与默认提示词验证.md)。真实数据部署与长期人格、记忆和自主内容质量不由这些隔离测试推定。
