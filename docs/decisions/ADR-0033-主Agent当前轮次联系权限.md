# ADR-0033：主 Agent 当前轮次联系权限

状态：Accepted。日期：2026-11-02，Asia/Shanghai。确认来源：主人明确“主agent所有行为都是自主的”，要求联系能力不再仅限定时自主周期。原独立工作树 `fix/main-agent-contact-authority` 的DSH0.12.1已完成本地及隔离系统验证，具体层级见文末与报告，当时未部署。本轮在 `integrate/main-contact-deploy` 与main `10aa62c`整合为DSH0.13.2；为保留主分支[ADR-0032：AI定时任务](ADR-0032-AI定时任务.md)，本联系决策由原0032重编号为0033。整合验证与部署分别见[本轮报告](../reports/2026-11-02-定时任务与当前轮次联系整合部署.md)。

## 背景与根因

此前把联系任务的许可绑定定时自主周期，将活动机会的来源误作通讯权限边界。结果是主 Agent 收到群消息、私聊或原生输入时，即使当前联系策略允许目标，也无法直接委派联系任务。这与主 Agent 自主决定行动、子代理执行具体任务的职责冲突。

## 决策

1. 联系许可绑定真实主 Agent 的原生当前 turn。QQ群／私聊消息、原生主输入、目标续行、定时唤醒产生的当前轮次，均可调用 `eating_list_contact_targets` 和 `eating_contact_target`。主 Agent 自主决定是否行动及如何委派；获准目标无需先发来私聊。
2. 普通 `eating_delegate_task` 继续绑定真实入站批次的 `context_ref`、会话及消息／资源范围。群聊 context 不能作为私聊授权，跨目标联系必须走联系策略；联系任务不继承旧入站消息或资源引用。
3. 主 Agent 先读取当前目标及精确工具集合，再提交返回的 `target_id` 和任务。后台核对主 Agent 身份、原生轮次、账号实例／实际账号、对象、代理类型、当前策略与工具交集；具体通讯由受限原生子代理执行，Host 返回真实动作回执。主 Agent 不取得 QQ 直连能力或全权令牌。
4. `enabled`／`ownerPaused` 只控制无输入时的定时活动机会。定时活动关闭或暂停时，有输入的普通主轮次仍可联系获准目标；真正的自主机会被取消时，撤销该机会所属轮次的联系许可。暂停定时活动不等于清空联系策略。
5. `maxContactsPerHour` 继续统计所有联系任务，不因普通输入、原生目标或定时来源分开计算；它统计任务数，不是消息条数或费用。保存联系策略撤销旧许可，后续任务必须按当前策略重新准入。
6. 当前轮次结束、abort、主 Agent 销毁或运行时停止时撤权；异步资源取得后及真正发送前复查。许可仅在内存生效，旧轮次、错误账号／对象／工具与迟到调用不能重新取得权限。
7. 使用公开原生 `callId` 防重，每目标当前轮次最多保留32个调用引用；重复、pending、unknown 拒绝重发，超额拒绝而不淘汰防重记录。迟到完成不能覆盖 unknown 或撤销新任务权限，未知动作只核对实际回执，不自动重放。
8. `proactive-bindings.json` 保持严格 schema1，`cycleId` 字段保留为内部联系轮次引用，不迁移、不据持久记录恢复旧许可。新 runtime 启动将遗留 pending 任务转为 unknown；稳定子 UUID 与动作账本保留，核对后解除任务阻塞不重发、不删账本。

## 原因与备选

继续仅允许定时周期联系，会使同一主 Agent 因唤醒来源不同而失去已获准能力。放宽普通委派的会话 scope 会混淆群聊、私聊和资源授权；向主 Agent 提供全权 QQ 令牌会绕过现有子代理边界。采用原生当前轮次许可，可让主 Agent 自主决策并复用现有受控执行和撤权链。

## 替代关系与影响

本决策替代 [ADR-0023](ADR-0023-自主活动协调与主动通讯授权.md)、[ADR-0027](ADR-0027-人格模板与默认提示词生命周期.md)中“联系仅在准入自主周期”的边界，并明确 [ADR-0025](ADR-0025-统一主动联系名单策略.md)的旧许可按当前联系轮次撤销。其定时协调、统一名单、工具授权、共享人格、CAS、真实回执和未知不重放原则继续生效；[ADR-0031](ADR-0031-自主运行状态与可选能力降级.md)的真实策略摘要和实际活动时长规则保持。历史 ADR 与报告原文及数字保留。

当前操作与提示词约定见[自主运行配置与查看](../operations/自主运行配置与查看.md)、[提示词与人格模板](../operations/提示词与人格模板.md)；接口和存储见[接口契约](../technical/接口契约.md)、[数据目录](../technical/数据目录与账号实例.md)。其他 Harness 须分别映射并验证真实轮次生命周期。
