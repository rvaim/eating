# ADR-0037：未知委派隔离与受控图片发送预算

状态：Accepted。日期：2026-11-03，Asia/Shanghai。基线：`6541a77`，工作树：`fix/delegation-errors-and-image-send`。本决策补充[ADR-0035](ADR-0035-会话代理自主处理与默认开放可配置.md)的任务隔离和[ADR-0033](ADR-0033-主Agent当前轮次联系权限.md)的错误、额度可见性；不改变主轻量分流、绑定子自主处理的职责。

## 已确认根因

父代理实读主／子运行记录确认：合法MCP生成图通过 `eating-asset://` 的 `readAsset` 授权检查及单图5MiB校验后转为Base64，QQ发送端却共用入站／响应1MiB上限，在真实发送前返回 `not-sent`。子代理多次尝试后，总委派60秒超时成为 `unknown`；旧控制器将整个同会话锁住，后来的不同context也被阻断。main转走联系后用尽每小时6次额度，通用“配置或状态无效”及控制层丢失code／outcome／details又诱发反复误试。`eating_activity_state` 本身实际读取成功，不能据报错推断状态文件损坏。仓库只保脱敏根因，不收录真实聊天、账号、旧会话标识、原始图片、trace或秘密。

## 决策

1. **普通入站委派按任务隔离。** `unknown` 拒绝原contextRef或原taskId；新的contextRef配合新的公开callId可复用同一child，以当前批次重新取得scope。同runtime仍有pending时拒绝并发。此规则不解除主动联系任务自身的unknown防重。
2. **迟到结果不能影响新任务。** actions／finish同时匹配当前pending任务的nonce、contextRef及taskId，旧unknown与迟到回调不能覆盖新状态、读新动作或撤新权限。运行时启动把遗留pending转unknown，保原nonce及原索引身份；不恢复旧lease。
3. **防重索引有界且不丢未知。** 普通子绑定最多32条引用；当前批次引用和unknown不淘汰，仅可淘汰旧批次completed／failed。无法腾出位置时明确 `AGENT_TASK_CAPACITY`，不清Host动作／request_id账本，不自动重放。
4. **图片扩容仅来自受控资源。** QQ后台解析获准 `eating-asset://`、调用 `readAsset` 并经 `checkedImageResource` 校验后，按实际Base64字符字节累计内部 `resolvedImageBase64Bytes`。模型不能提供该预算；标准模型输入、文本及普通Base64／URL／路径的限制保持，不增任意URL或磁盘读取入口。
5. **发送大小分账核验。** 全JSON wire减去上述实际Base64后仍须≤1MiB，额外Base64预算≤14MiB，全JSON硬上限15MiB。原单图5MiB、最多4张／原图合计10MiB保持；入站事件、API响应及WebSocket maxPayload仍1MiB。异步资源返回后及发送前复核账号、scope和撤权。OneBot普通retcode100仍为failed；unknown不重试。
6. **额度与错误按真实原因暴露。** autonomy按code区分额度、暂停、未启用、失效runtime、配置／活动CAS冲突及输入错误。`snapshot.state.contactLimit` 只读派生 `{limit,used,remaining,exhausted,windowStartedAt,resetAt}`，不新增持久化字段。联系签发lease前执行 `assertContactAvailable`，最终计数时再检查；保持每小时6次，不修改主人配置。额度耗尽报告真实used及resetAt，读取或安排active不会重置。
7. **控制错误保留语义。** agent-control使用真实HTTP statusCode并返回code／message／outcome／可选details；客户端 `RuntimeControlError` 的message含code和outcome，typed字段保留statusCode及脱敏details。安全code允许大小写、数字、下划线、点和连字符，保留 `onebot_xxx`；不按HTTP409推断unknown。凭据、认证头、nonce、URL等在错误文本及details中脱敏。

`eating_handle_conversation` 仍严格仅收 `{context_ref}`，main不预写回复、不另建router。功能MCP all／custom、人格、历史、动作账本及原生Web保持；[ADR-0036](ADR-0036-功能插件与Harness原生功能默认边界.md)的新实例仅time默认及既存revision5 time＋web选择保持。

## 版本、验证与交付

源码应用／Host／Web0.17.2、DSH0.15.2、QQ0.13.5；SDK4.7.0、UI4.2.0、core4.0.0、API4与各数据schema不变。真实记忆0.1.1不升级，不远端操作、不向真人或付费模型试发，不清历史或动作账本。

回环验收覆盖1.25MiB有效PNG的原asset到OneBot发送字节一致性、provider／发送各一次，以及首发成功后子流挂起转unknown、新入站同child新任务完成和旧SQLite动作保留。原生SDK可规范化给模型的图片，模型预览只要求合法native image block，不要求与原asset的Base64一致；最终大图复跑结果待父代理记录。完整构建／全量测试、Git及部署由父代理在[本轮报告](../reports/2026-11-03-未知委派隔离与受控图片发送验证报告.md)补充实际结果；阶段成功不等于最终全量或真实实例部署成功。当前服务正常connected，后续部署如需短暂停机，须恢复原运行状态。历史报告与旧ADR保留当时数字及结论。
