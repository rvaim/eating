# ADR-0041：聊天参与感与人格场景指引

状态：Accepted；新增源码实现与隔离验证完成、未部署、未二次提交。日期：2026-11-03，Asia/Shanghai。最终验证实数与状态由父代理维护的[本轮报告](../reports/2026-11-03-聊天参与感与人格场景指引验证报告.md)收口。

## 背景与选择

已有规则允许自然多句、多条和沉默，但群聊还需要具体的参与判断：谁在对谁说话、哪些话值得接，以及何时停止。只强调避免打扰，容易让模型把未被点名理解为不该参与；只强调活跃，又容易逐条点评或变成主持人。通过共享行为指引和人格场景示例补足判断依据，继续由同一 Agent 理解语境，不增加关键词路由或另一认知循环。

主人要求先提交并 push 全部既有修复，再开始增加新规则。父代理已完成 `71e20cd` 并成功推送 `origin/main`，随后才开始本轮；本轮新规则留工作区，不自动再次 commit／push，不部署或重启服务。旧 ADR、变更与历史验证报告保留当时事实，不回写其提交状态和测试数字。

## 群聊参与指引

DSH 共享 conversation-policy、Host common 默认和 QQ group defaults 同步表达以下原则：

- 先判断真实 @、引用关系和实际说话对象，读完当前批次再选择回应；群成员之间的对话不自动当成对 AI 的提问。
- 有具体态度、新信息、真实好奇或自然联想时可以参与，没被叫到也能接话；无需逐条点评，不默认当主持、调解者或气氛组。
- 对方没有接话、明确拒绝或话题已经翻篇，就停下来；不为保持存在感继续追问、总结或拉回旧话题。
- 根据本群实际语气调整表达，不机械照抄别人。只有相关、可信且可向当前对象披露的记忆才自然提及；旧消息不能说成刚发生。
- 不编造刷手机、吃饭等线下活动，不以故意答错、装傻或刻薄冒犯营造人格。

这些是语境判断与表达指引，不保证每次真实 LLM 都选择恰当时机，也不把“允许参与”变成必须回复。

## 人格场景示例

“AI 女儿”模板仅为新增人格的可编辑草稿，补充被关心、被误会、玩笑和认真提问四类小例子，示范回应态度与场景变化，不给固定台词，不把例子当成已发生事实。认真问题仍认真回答，亲近、顶嘴或玩笑服从真实上下文，不编造共同经历。模板更新不覆盖已保存人格，不自动保存或启用。

## 保持的契约

普通聊天一条可多句、一次回复可多条，仍无固定字数、句数或条数配额。独立气泡逐条真实发送、稳定不同 request_id、顺序核对回执，unknown 停止自动续发。

[ADR-0040](ADR-0040-主Agent核实交接与只读任务阶段.md)的 verify／reply、context_notes、只读调用限制，以及当前主子职责、唯一 complete、真实账号／目标／资源 scope 和权限契约完全保持。记忆可读与可披露仍分别核验，不以共享身份自动取得跨会话全部记录。

主动活动仅在[待审方案](../plans/2026-11-03-主动活动行为改进方案.md)补充正向社交动机，未实施 autonomy-runtime、调度、额度、waiting／sleeping 或主人配置变更。
