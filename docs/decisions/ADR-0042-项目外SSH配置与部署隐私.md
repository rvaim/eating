# ADR-0042：项目外 SSH 配置与部署隐私

状态：Accepted。日期：2026-11-03，Asia/Shanghai。依据：负责人明确要求真实服务器连接信息不得进入项目，即使文件已被 Git 忽略也不例外，并要求交付交互脚本供自己运行。

## 背景与决策

SSH 别名可让用户在本机保存连接配置，而仓库只保留通用操作入口。真实 host、端口、登录用户、主机指纹、密钥内容或位置、密码／Token、跳板机、部署目录及关联映射只保存在项目外的本机 SSH 配置、凭据存储或私有部署配置；源码、测试、文档、报告、截图、产物和 Git 记录只允许明显的示例占位符。项目内被忽略的文件不作为备选存储位置。

交付仅依赖 Python 标准库的[交互脚本](../../scripts/配置SSH别名.py)，由用户在本机终端运行：别名普通输入，地址、用户名、端口与可选已有私钥路径通过 `getpass` 隐藏输入；拒绝管道和无法隐藏输入的终端。确认 `yes` 后，写入项目外的 `~/.ssh/config.d/eating-<alias>.conf`，在 `~/.ssh/config` 前置 Include 并保留原正文，文件 `600`、目录 `700`，不覆盖同名配置；拒绝项目内目标和 SSH 目录／配置符号链接，私钥引用解析后仍须在项目外且不读取内容。

选择本机 SSH 配置可避免在仓库维护真实目标映射；终端隐藏输入减少回显，但不等于配置内容被加密。脚本不询问或保存密码，不生成密钥、不自动连接或部署。用户配置完成后自行运行 `ssh <alias>` 测试；服务器操作不因本决策获得额外授权。

## 用户授权导入已有私钥

主人后续要求提供输入PEM路径后自行复制、编辑别名的脚本，新增[导入脚本](../../scripts/导入SSH私钥.py)。只在用户本机确认后，为复制而读入原文件、检查匹配的私钥头尾，保存到项目外SSH目录并设600；原文件保留，仅编辑该别名的IdentityFile／IdentitiesOnly，先在项目外备份配置，保留其他目标和Host段。重复不同密钥、歧义共享Host段、未被全局Include接入的独立文件、配置符号链接或并发改动拒绝，不上传、不联网、不输出密钥内容或真实路径。该授权不改变项目禁止保存真实服务器值的约束，不表示助手可以读取用户真实密钥，也不代表服务器接受该公钥。

## 影响与证据

本轮只交付本机配置脚本与[使用说明](../operations/配置SSH别名.md)，未运行真实 setup、未读取或修改用户 SSH、未连接服务器、未 commit／push；后续真实配置与连接由用户自行执行。隔离夹具与临时配置的解析验证见[验证报告](../reports/2026-11-03-项目外SSH别名脚本验证报告.md)，不能据此声称真实连接或部署完成。

本决策补充现有数据与授权边界，不替代旧 ADR 的功能契约，也不重写历史报告。
