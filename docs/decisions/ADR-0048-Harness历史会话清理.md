# ADR-0048：Harness 历史会话清理

状态：Accepted，**本地验证及云端发布部署完成**。日期：2026-11-04，Asia/Shanghai。确认来源：用户先要求本地预览，之后明确“部署到服务器上”，授权本轮提交／push和云端GitHub更新。由主代理独立执行，不再启动子代理；只部署功能，不执行真实历史清理，不动用户主 DSH 或当前 DSH GUI。

## 背景与原因

官方 DSH rc.5 的 `SessionController` 与 `sessionPersistence` 均没有删除会话 API，本功能属于 Eating 实例的带外文件维护。完整 Web helper 的官方 schedule host timer 启动会恢复冷会话并可能请求模型，因此清理不能借启动 helper 取得会话目录或执行删除。

## 决策与交互

Harness 面板新增第三个“历史会话”页签。完全停止 Harness 后，主人点击“扫描历史会话”，按实际原生日志展示总会话、主会话、子会话数量和有效期 5 分钟的预览；显式确认区说明范围，勾选确认复选框后才能“确认清理 N 个会话”。取消不删除，预览过期或内容变化须重新扫描。

只提供主人管理 API `preview-session-history`／`clear-session-history`，不注册 MCP 工具。执行沿用同一意图的稳定 `requestId`，以持久回执核对原请求；结果 unknown 或进程中断不能换号重放，也不能仅凭页面取消声称已提交操作未发生。

## 离线计划与互斥

- 扫描和执行前，必须确认本实例全部 SDK、子运行时、原生 Web 与管理 helper 已真正退出，且 Host 无待交接消息；停止状态标签不能代替这些检查。POSIX 的 `session.lock` 在停止后会保留空文件，应原样保留；文件存在不能作为仍在运行的判据。
- 仅在固定 Eating 专属数据根下规划，以 v4 session header 为会话身份事实；不能只凭绑定、文件名或标题猜测归属与数量。
- 逐项保存目录、stat 与内容 hash 快照，执行前复核有效期和全部快照；遇变化、符号链接或越界路径拒绝，不扩大清理目标。
- 原生定时任务若引用目标会话，阻止清理并要求主人先到官方 Web 删除相关提醒，已停用的提醒也须删除，再停止并重扫；仅停用仍保留目标引用，不能解除阻断。清理不自动删除调度策略。Goal 仅随 Session 日志及 projection 清理，不另造目标清理文件。

## 清理与保留边界

| 清理 | 保留 |
| --- | --- |
| 本实例全部原生主／子日志及同 Session 的 generation | 配置、Key、人格和原生能力选择 |
| 对应原生附件、派生缓存、桥接正文与绑定元数据 | Host queue／actions、业务图片和外部 OpenViking 数据 |
| workspace 文件中仅 session 关联数组内的目标引用 | workspace 实体、路径、标题及其他字段 |

范围不延伸至浏览器草稿、OS 快照或用户主 DSH；不承诺 OS forensic 抹除。清理后需要新会话时由后续正常启动创建，不将维护成功等同于模型任务成功。

## 影响、备选与证据

本地源码 DSH 插件从前轮云端 0.16.0 升 minor 至 0.17.0；应用／Host／Web0.18.0、QQ0.14.1、生图0.3.1与 SDK 等保持，无新依赖。复用完整 Web helper 会触发冷恢复，直接按文件名删除则缺少身份与快照依据，均不采用。

完整 SDK／五插件／Host／Web 构建与严格类型通过；引擎40项（1.98秒）、真实Host／系统DSH集成2项无跳过（2.60秒）、最终全量98文件通过／2条件跳过、1871项通过／8项跳过（120.26秒），历史页9项浏览器（6.1秒）与reader／双语8项（256ms）通过，四张最终关键图已实际读取。隔离集成真实创建root、停止后清理root及示例child、再次启动得到新UUID和nativeWeb就绪；保护配置／Key／profile／人格／Host设置与动作／业务图片／外部记忆测试文件及POSIX空锁inode保持，模型请求为0。HTTP主人／session／CSRF／MCP隔离及真实待交接队列阻断已验证，拒绝时历史hash／mode／mtime保持。

终版独立预览仅安装DSH0.17.0、关闭自动连接、无真实配置或Key，浏览器扫描1主2子共3个示例一致；确认区取消优先获焦、未勾选时确认禁用，取消没有清理请求、页面异常0，并由父代理实读终版图。3个示例保留供主人查看，未点击清理；全部删除测试仅用独立临时数据，不代表真人或真实模型验证。完整构建、测试、读图与预览证据见父代理维护的[本轮报告](../reports/2026-11-04-Harness历史会话清理验证报告.md)。

源码 `29387f9` 已由主代理独立commit／push并控制云端GitHub拉取，完整构建／严格类型与Linux14文件410项全部通过（56.99秒，含独立系统DSH两项实际集成）。私有全量备份后在原data目录更新DSH0.17.0，公网历史页、前端产物和运行中扫描拒绝已验证，五插件connected、DSH／nativeWeb ready，原3份日志前缀、会话身份、配置／人格／图片／账本、17条记忆任务身份与Token保持。只部署功能，未执行真实清理；记忆范围仅动态lastSeenAt变化，设置保留。最终文档提交不改变生产代码，无需重复重启。
