# ADR-0049：自然聊天与自主活动提示词

状态：Accepted；本地验证、Git发布与云端保留数据部署完成，证据及行为质量边界见本轮报告。日期：2026-11-09，Asia/Shanghai。

## 问题与现场证据

主人反馈缺少自主行为、回复过密与修改后过度沉默，以及普通聊天长篇化，并明确要求修改提示词、push并部署服务器。本轮只调整行为指引与工具描述，不改变调度、额度、权限、存储或消息发送机制。

云端只读核验时，自主运行 enabled=true、autoResume=true、ownerPaused=false，AI处于waiting，nextWakeAt为空、agenda为空，无错误。当前waiting确实停止普通定时思考，新增提示词本身不会使已有waiting自动重新规划。普通消息仍可进入同一原生Agent。定时机会与普通发言选择分别判断。

云端common有一份约2.2万字符的主人自定义正文，包含工作交付与专业表达要求，末尾附加当前旧版common默认。源码默认更新不会替换自定义文档。仅泛化的“少回复”不能区分直接交流、正在接话与群聊围观，也无法证明真实LLM会选择合适时机。

## 决策

1. Host common／main默认、QQ私聊／群聊与主说明、DSH共享聊天层及自主说明保持一致：私聊对方在找我、明确叫我或接着我的话聊时通常回应；围观选择性加入；明确不用回复、收尾或当前不便时可以停。允许沉默不等于尽量不答，允许主动不等于每轮发言。
2. 普通聊天先接眼前真正想回应的内容，后续随对方继续；避免把分析、建议、安慰和追问一次讲全。先删除多余内容，再按意思选择气泡，不把长回答分开发完。不设固定字数、句数或条数，不机械切句；必要详细解释、完整原文、代码和链接保持。
3. 自主机会明确允许延续真实兴趣、探索、问候获准对象、分享实际发现与未完话题，聊天无需工作理由。联系仍先查当前目录、遵守对象回应与真实scope，未回应不反复催促，不编生活。
4. 三种活动安排保持原语义。active按主人间隔继续；暂时没想法但希望稍后再考虑时可用带wake_at的sleeping；waiting只在确实希望等待事件并停止普通定时思考时选择。同步真实机会指令和eating_plan_activity的description，不偷改waiting实现或给它添加后台模型心跳。删除eating_schedule_task描述中已被ADR-0034替代的原生schedule禁令，原生能力配置仍依当前契约。
5. 保留主／子各自唯一complete provider和必需协调契约，更新后的共享行为规则在主人自定义正文时仍进入真实模型system。编辑器的已保存组合仍只展示主人组合层，不将本轮表述为新增最终system预览功能。
6. 部署保留人格与其他自定义内容。对本次已明确要求修改的common，只在原revision／摘要与预览一致时，通过正式提示词CAS接口定点修改工作表达要求的适用场景，并替换其已确认完整匹配的旧默认尾段；原其余正文逐字保留，不reset整份文档、不把私人正文提交仓库。
7. 现场自主运行已获主人开启且未暂停。部署后可以通过既有owner wake入口给同一主Agent一次重新规划机会，使新提示词能作用于既存waiting；不改主人开关、自动恢复、额度、联系人或人格，不把唤醒当成真实QQ试发或强制安排回复。

## 发布与验证

应用／Host／Web0.18.1、QQ0.14.2、DSH0.17.1；SDK、其他插件和依赖保持。QQ、DSH四处版本同步，封存产物不覆盖同版本。现有本地模型／OneBot回环核验真实system送达、自定义保留、沉默与独立气泡、verify只读和回执；浏览器核验编辑／CAS／人格保留。真实LLM聊天质量需要后续观察，不用字符串断言或脚本回复宣称已获得活人感。

本地修改验证后commit／push，云端从GitHub取同提交构建和回归；空闲且队列为空时仅停Eating、项目外全量私有备份、同data更新。真实服务器信息与自定义提示词只留项目外。详细结果见[本轮报告](../reports/2026-11-09-自然聊天与自主提示词部署验证报告.md)。
