# ADR-0053：插件面板启停状态

状态：Accepted，2026-11-10。部署后的公网检查发现：新语音插件安装在原有实例中默认未启用，面板仍按可见状态请求任务列表，Host 按既有权限边界拒绝，页面因而误报通用错误。

根因是面板没有收到宿主已经掌握的真实启停状态，仅凭页面可见启动查询。UI SDK 4.3.0 为当前 `PluginPanelProps` 增加必填 `enabled`，插件页与业务页从同一工作区状态传入；不让插件再查询或推断状态，也不放宽停用插件的后台管理权限。

语音面板停用时停止任务请求、取消在途任务查询／试听并撤销播放器，服务配置仍可编辑和保存；启用后读取列表，仅列表存在运行中任务时定时查询。提示主人先保存服务配置再启用，未配置 Key 不连接云端。切语言不重挂请求；默认不启用或借用其他插件密钥。

应用／Host／Web 0.21.1、语音 0.1.2；UI SDK 4.3.0 仅增加类型契约，其他五插件的运行产物须与前次封存一致，不因类型字段改写同版本产物。plugin-sdk 4.11.0、插件 API4 与数据 schema 保持，无新增依赖或锁文件变化。

真实安装的浏览器回归覆盖停用时零任务请求、配置保存、启用恢复一次读取、空列表不轮询及再次停用停止读取。其余语音试听、语言、图片设置及滚动用例一并验证；最终结果与部署证据见[本轮报告](../reports/2026-11-10-图片大小配置验证报告.md)。
