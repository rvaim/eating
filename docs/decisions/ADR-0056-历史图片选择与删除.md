# ADR-0056：历史图片选择与删除

状态：Accepted。日期：2026-11-13，Asia/Shanghai。用户要求生图历史图片单选／多选删除、列表交互优化，并在完成后部署。

## 当前契约

image-generation0.5.0新增主人管理操作delete，仅在现有带鉴权及CSRF的manage入口提供，不注册为MCP工具。参数严格为assetIds（1～50个唯一合法资源ID）、expectedRevision、confirmed:true。一次操作完整验证选择、索引版本、资源路径及无生成中任务后才修改，过期列表返回IMAGE_GENERATION_REVISION_CONFLICT／not-sent。列表分页仍默认20、最大50，响应新增必填revision；图片list支持query按描述或模型搜索。

删除原图、图片索引条目和全部任务的相应输出引用，保留生成任务／requestId／requestHash及已有编辑来源摘要。成功任务的assetIds为空表示原图已由主人删除，UI明确标识；任务结果仍是真实生成结果。编辑来源摘要记录历史来源，允许其原资源已删除，但后续读取／编辑仍必须通过当前资源索引。既有存储schema1及字段不变，不迁移、不清空数据。重启和同request_id查询保留原任务，不能因删图再次计费。

删除采用独立schema1的image-deletion.json记录已确认的精确ID及索引revision，先原子写入删除记录，再原子移除索引／任务引用，最后逐一删除受控blobs并同步目录。索引尚未提交时不删图，丢弃未提交删除记录；索引已提交后才按该记录完成文件清理。启动及下一次写入先核对并完成已提交的同版本删除；这属于已确认操作的故障恢复，不是旧格式迁移或新删除。清理失败返回unknown并保留恢复记录，不吞错误；其他未选图片不受影响。

## 交互

图片列表增加搜索、单行勾选、选择本页、已选数量、单图删除和批量删除。选择只作用于当前页，翻页／刷新／搜索／隐藏清除选择，不从不可见页面带入删除目标。确认弹窗列出图片、数量和文件大小，默认焦点在取消，Escape取消；未确认不发送delete。确认发起后禁用重复操作，结果丢失只重新读取核对，不自动重放。

图片与任务列表采用有界滚动区，描述折行收束，窄屏优先显示图片历史。既有图片预览保留，新增本页上一张／下一张；读取始终按点击，不后台下载全部原图。删掉末页最后一项时返回有效页，任务里显示“图片已删除，生成记录保留”。删除不会撤回已发到QQ的图片，不删除其他副本或部署备份，不承诺全机清除。

## 验证与发布

必须验证批次原子准入、旧revision拒绝、未知结果、任务幂等、共享输出和历史编辑来源、文件／目录安全及中断恢复；浏览器验证单删／多删／取消／翻页／搜索／空列表／双语明暗窄屏。生产部署只上线能力，不点击真实删除。证据见[报告](../reports/2026-11-13-历史图片删除与列表交互部署报告.md)。
