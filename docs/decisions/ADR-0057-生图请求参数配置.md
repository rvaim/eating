# ADR-0057：生图请求参数配置

状态：Accepted。日期：2026-11-13，Asia/Shanghai。用户要求生图插件支持moderation等配置参数，并明确默认moderation=low；沿用本会话修改完成后的提交、push和保留数据部署授权。

## 当前契约

image-generation0.6.0提供主人专用的“请求参数（JSON）”编辑、保存、重读和恢复low默认草稿。参数为最多32项、紧凑JSON最多16KiB的对象，值仅支持字符串、有限数字和布尔值，单字符串最多4096字符；参数名仅字母开头、字母／数字／下划线。moderation若提供须为low或auto，其余参数由服务决定支持。保存不连接提供商，不触发真实生成。

全新独立`request-parameters.json`使用严格schema1／revision／parameters和文件摘要CAS；无文件时当前默认为`{"moderation":"low"}`，只读不补写。原config.json和state.json的严格schema1及既有字段均不变，不存在旧字段读取、自动迁移或清理。显式保存`{}`表示不发送额外参数、采用服务默认值；恢复默认只改草稿，保存后才生效。

仅owner manage提供request-parameters及save-request-parameters，不新增MCP配置工具或允许模型覆盖。不能覆盖model、prompt、size、quality、response_format、n、图像／蒙版／来源、鉴权／地址、request_id及stream／partial_images等受控字段。每次仍n=1，文件只走已有受控图片来源，响应仍为单次JSON。字符串／数字／布尔值在文生图JSON中保持类型，编辑multipart字段按协议编码为对应文本。

主人的保存参数在任务准入时快照，生成中拒绝修改保存值，已接受任务固定使用提交时的值。相同request_id查回原任务，保存参数后不自动创建新任务、不改变旧请求结果；结果未知或服务不支持参数时不移除参数重试，也不重新计费。原动作意图／幂等算法及历史任务摘要不变。

## 界面与验证

参数表单独立保存，未保存草稿阻止新生成；切换语言保留草稿，不触发保存或计费。重读有草稿时明确确认放弃，CAS冲突保留草稿及原revision，未知保存结果只由主人重读核对。支持中英文和390px窄屏，沿用现有主题。

验证须包含真实回环JSON与multipart中的low、auto、额外字段、数字0／布尔false、显式空对象；默认只读不落盘、CAS和损坏文件保留、运行中锁定、已接受任务快照以及服务拒绝不重试。

官方[生成参数](https://developers.openai.com/api/reference/resources/images/methods/generate)和[编辑参数](https://developers.openai.com/api/reference/resources/images/methods/edit)均声明moderation支持low／auto；官方默认auto，本插件按主人要求默认low。该配置不等于特定服务或模型已验证支持所有自定义字段。
