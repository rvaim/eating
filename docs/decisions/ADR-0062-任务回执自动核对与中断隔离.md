# ADR-0062：任务回执自动核对与中断隔离

日期：2026-11-14。状态：已采纳。修正ADR-0058中整条任务共用单次请求超时、主动联系unknown长期阻塞目标及依靠面板人工恢复的行为。

## 已确认根因

生产旧任务在04:00:32启动，04:01:32被60秒任务时限中止。调用过三次发送与一次撤回：两次发送明确失败，一次发送及撤回有成功回执，动作账本没有unknown。但子任务总体未正常结束，被一律登记unknown；prepare-proactive按联系人身份拒绝之后的新任务，只提供人工确认按钮。

timeoutMs既作为单次模型／MCP请求时限，又用于整个多步骤委派与联系许可。Host回执只按Agent暂存在RAM，联系超时会撤权，功能MCP还清除RAM回执；下一任务重挂又换了回执集合，重启无法核对旧任务。因此不能只调大超时、隐藏按钮或把unknown全标为成功。

## 机械记录与模型分工

Host新增host:agent-task-actions严格schema1设置，最多256任务／每任务100动作／8MiB。记录可信Harness、Agent、taskId、来源、作用域账本键、原request_id、工具名及有限回执（message_id或jobId／code／outcome）。不保存消息参数、正文、人格、凭据、媒体或模型输出。

Host SDK4.14.0的getMcpConnection及getCapabilityMcpConnections由控制层传可信taskId；不暴露为模型scope字段。Host公开readTaskActions／finishTaskActions；任务关联在外部副作用前持久化，不成功即不执行。通讯、插件能力、direct MCP均接入，授权、撤权、原Host幂等账本仍负责实际动作。调用结果迟到只更新原taskId，不覆盖同Agent新任务；ID参数冲突不能覆盖原成功／unknown。断线／异常仍保留明确状态。

回执关联独立于短期MCP租约，重挂／撤权／重启不丢失。结果提交后但任务回报前崩溃，从原账本恢复真实结果。正在执行或没有明确账本结果的动作保持unknown，不能因返回空数组认定未执行。缺失历史任务关联明确available=false，不伪造空成功。只移除已关闭且全部结果明确或主人已显式核对的旧索引；未知及在途不自动淘汰，容量满先拒新，原动作幂等账本不删除。

主Agent仍决定任务目标、是否继续、中断和如何回复。后台仅核对结构化事实并隔离旧任务，不作意图决策、不自动补发。主规则要求查询真实status/actions，interrupted不等于目标完成；仅确有主人判断需求才说明，不让主人常驻面板。

## 生命周期

单次请求继续使用主人timeoutMs（1～120秒）；完整多步骤任务采用独立15分钟界限，主动机会仍受主人cycleTimeoutSeconds、执行预算、暂停与撤权限制。正常主轮次结束不打断已接受子任务。

增加任务interrupted：表示执行已结束且已发生动作均已核对，不是completed。中断／期限／停机先撤权并关闭任务关联；全部动作已明确则自动收尾，否则保留unknown。后台每5秒自动核对原账本，不依赖面板。重启和主任务查询同样核对。一个结果未知动作只保护自己的原request_id；旧taskId禁止重放，新的独立taskId仍可复用同联系人／同子Agent。pending串行、真实目标／账号／类型、只读模式、未知动作与迟到nonce防护保持。

原生异步通知和task_control返回核对后的status/actions，不能把普通终结文字当平台成功。任务引用和动作索引均有边界；控制层只允许精确当前任务收尾，旧任务查询不能撤新权限。

## 界面与发布

面板对已核对中断显示普通状态，新任务可继续；无历史索引只说明已隔离而未重放；只有真实unknown动作显示人工标记兜底，文案明确不会阻塞其他新任务或自动重发。中文／英文、桌面／窄屏都以当前严格响应字段校验。

应用0.25.0、SDK4.14.0、DSH0.21.0；其他六插件的同版本封存字节须保持。无外部依赖或锁文件变化。原DSH绑定schema保持，当前状态增加interrupted；没有旧格式兼容读取或自动迁移。

截图对应旧记录没有任务关联。本次部署在停机且全量备份核对后，用GitHub提供的独立server-dsh-task-recovery.mjs核对主子日志哈希、parent／child／taskId／callId／contextRef／真实scope和所有原动作账本。仅完整匹配且每个动作已有明确结果时导入有限关联，再由正式启动逻辑核对收尾；不修改原日志／动作／其他设置，不标为成功、不发送。工具拒绝活跃Host、变动日志、路径越界、未知动作或身份冲突。后续生产读取不扫描原生日志。
