# ADR-0070 插件面板恢复与 QQ 图片引用

## 页面恢复

宿主状态轮询复用内容相同的插件配置对象，避免把每次轮询当作配置变更。面板恢复可见时继续使用已完成的配置和列表，接续中断的读取和正在运行的任务。配置变动、分页、搜索和显式刷新按当前面板状态读取。

生图与表情图库共用缩略图加载逻辑。首次读取图片时生成长边最多 128 像素的缩略图，最多并发三张。只在当前页的浏览器内存里保留缩略图，隐藏时撤销显示用的 Blob URL，返回时用内存里的缩略图重新显示。翻页回收离开当前页的条目，停用、离页和卸载时清理缓存。未保存密钥、实时日志和原图临时预览仍按各面板的隐藏策略处理。

生图任务存储与面板共用参考图摘要校验。任务列表显示人格参考图及多图任务的来源标识和张数，任务列表与图库分别报告读取结果。上游任务失败显示实际任务状态及可用的 HTTP 状态码。

## QQ 单图发送

`image_get` 与 `sticker_get` 在 MCP 结果中提供顶层 `image_ref`。现有私聊、群聊和通用发送工具支持同名字符串字段。单张插件资源图使用 `image_ref`、目标和稳定的 `request_id`，图片引用、语音引用和消息内容三种内容参数选一。QQ 后台构造标准图片段，复用现有账号与目标权限、资源租约、图片大小及传输设置和动作幂等。

`message` 继续支持纯文字及标准 OneBot 消息段。含序列化消息段的字符串仍在发送前拒绝，已有图片的引用与等价的单图段形成同一发送意图。格式失败后可以使用原请求标识纠正参数，结果未知的动作应核对原回执。

## QQ 号码编辑

主人和管理员号码输入框在失焦时保留正在编辑的数字。正常回车或点击「添加」转为标签，也支持按换行、逗号及空格批量粘贴。输入法组合期间的确认键只用于输入法。待添加文本也属于草稿，保存时按原规则校验并使用开始编辑时的权限版本。

本地工作与线上证据见[验证报告](../reports/2026-11-22-插件面板与QQ发送验证报告.md)。
