# Eating 界面设计规范

## Overview

**设计北极星：“浅色标签”**

本规范记录负责人已实际选择并实现的浅色标签方向。它借用生活收纳系统的分类标签：浅灰全局侧栏承载稳定位置，近白平台分类栏承载插件目录，白色工作区承载配置任务。绿色负责选中、主要动作和正向反馈，细分隔线与清晰文字层级负责组织内容。

这是以操作为中心的中文管理界面。密度适中，标题克制，表单与状态先于装饰。宿主提供“概览／机器人”及机器人页内分类两层导航；各插件提供自己的配置内容。注册、配置保存与真实连接分别表达，不把浏览器示例包装成真实平台运行。

**关键特征：**

- 浅灰与白色的连续工作区，小圆角、细边框、有限绿色强调。
- 两层导航保持清晰归属，平台名称与配置面板来自插件。
- 中文动作和状态可直接读懂，字段标签、说明、错误与结果紧邻任务。
- 桌面保留横向工作空间，窄屏保留图标导航与可横向浏览的平台分类。

正文唯一维护在本中文文件；根目录 [标准设计入口](../../DESIGN.md)仅为符号链接。[设计扩展数据](../../.impeccable/design.json)保存机器格式无法容纳的扩展与组件示例。抽取依据为[产品上下文](产品上下文.md)、[首版界面约定](首版界面约定.md)、[全局样式](../../apps/web/src/styles.css)、[应用框架](../../apps/web/src/App.tsx)、[表单组件](../../apps/web/src/components/ConfigurationForm.tsx)、[插件目录](../../apps/web/src/components/PluginCatalog.tsx)、[概览页](../../apps/web/src/pages/Overview.tsx)、[机器人页](../../apps/web/src/pages/Robots.tsx)及 [QQ](../../plugins/qq/entry.tsx)插件入口；原飞书/微信抽取依据保存在[源码历史索引](../research/源码历史索引.md)。视觉证据为[桌面配置](../../.impeccable/review/desktop.png)、[概览](../../.impeccable/review/overview.png)、[窄屏配置](../../.impeccable/review/mobile.png)、[插件目录](../../.impeccable/review/catalog.png)。截图用于核对实现，不是随产品发布的图片素材。

## Colors

颜色以前置令牌为准：中性底色略带灰绿，主要动作使用稳健绿。实现没有渐变或连续色阶；以下按使用角色解释现有颜色，不扩造配色。

| 角色 | 令牌 | 实际用途 |
| --- | --- | --- |
| 主要强调 | `primary`、`primary-hover`、`primary-deep` | 主按钮、焦点、图标、正向结果；加深色用于悬停、选中文本与添加入口 |
| 主要表面 | `sidebar`、`surface`、`platform-sidebar` | 全局侧栏、内容区、平台分类栏 |
| 内容层级 | `ink`、`muted`、`subtle` | 正文与标题、说明、版本和时间等辅助信息 |
| 导航状态 | `tint`、`global-nav-*`、`platform-nav-*` | 两层导航各自的默认、悬停和选中状态，保留两层底色差异 |
| 分隔与控件 | `line`、`secondary-*`、`input-*` | 页面分隔、次按钮轮廓、输入边框及悬停边框 |
| 只读与静态状态 | `readonly-*`、`quiet-*`、`status-*` | 只读方式字段、已注册禁用按钮、未连接状态标签 |
| 错误与移除 | `field-error`、`field-invalid-border`、`result-error`、`danger*`、`confirmation-*` | 字段错误、失败结果、确认移除；移除入口平时保持低强调 |
| 提示与概览 | `notice-text`、`welcome-*`、`storage-*`、`toast-*` | 本地示例说明、概览引导、存储异常、动作反馈 |
| 插件识别 | `qq-icon`、`feishu-icon`、`wechat-icon` | 仅用于平台符号的品牌识别，不替换宿主导航的绿色选中状态 |

**颜色归属规则。** 平台品牌色用于平台符号，宿主操作与选中状态使用宿主绿色。中性色状态标签配合“未连接”等文字，不用绿色虚构在线状态。

## Typography

全界面使用系统无衬线字体栈，优先匹配操作系统与中文字体；没有引入网页字体、展示衬线或专用等宽字体。字号与字重的规范值见前置令牌。

| 层级 | 令牌与局部实现 | 用途 |
| --- | --- | --- |
| 页面标题 | `headline`；窄屏（600px 及以下）改为 22px | “概览”“机器人” |
| 面板标题 | `title`；窄屏改为 22px | 平台名称、“全部平台” |
| 表单小节 | `section` | “连接配置”“应用配置”等小节 |
| 基础正文 | `body` | 导航与通用内容，基础行高为 1.6 |
| 动作与标签 | `label`；输入文字同为 13px、常规字重 | 按钮、字段标签 |
| 辅助说明 | `supporting`、`hint` | 说明、状态、版本及字段帮助；字段帮助行高为 1.8 |

概览引导标题沿用面板字阶，字距局部为 -0.6px；在 850px 及以下为 21px，在 600px 及以下为 20px。概览分区标题为 17px，窄屏为 16px；插件目录标题为 19px，窄屏为 18px。这些是已有组件覆盖，不建立额外展示字阶。计数与操作时间使用等宽数字特性，平台名称保持正常大小写。

**中文操作规则。** 保留中文动作与状态；技术名称、协议、地址和示例标识按其实际格式显示。主要操作不使用全大写英文或额外装饰性字距。

## Layout

桌面应用框架为 200px 全局侧栏加剩余内容。全局侧栏贴顶，独立高度为一个视口；页面头部最小高度为 119px，内边距为纵向 29px、横向 38px。机器人页在头部下使用 208px 平台分类栏加弹性配置工作区；配置区内边距为上 31px、左右 44px、下 48px。两列均使用可收缩的剩余宽度，避免表单撑破工作区。

表单标签列为 132px，列间距为 24px；表单容器上限为 920px，输入上限为 670px。字段纵向间隔为 23px，操作区与复选项按标签和列间距合计的 156px 对齐。保存与本地校验在同一操作区；插件信息和移除区通过独立分隔线留在表单之后。

概览内容上限为 1400px，插件目录上限为 1100px。概览事实栏桌面四列，底部为活动区和版本说明两列；平台条目使用整行分隔和清晰的符号、文案、状态、动作序列。根样式声明 8px 基础间距，同时实际使用前置间距索引中的多种值；不得把所有既有间距强制改成同一倍数。

| 条件 | 已实现的变化 |
| --- | --- |
| 宽度至少 1700px | 配置区右内边距取 44px 与 `(100vw - 1500px) / 2` 的较大值 |
| 宽度不超过 1100px | 全局栏 172px、平台栏 175px；主要横向内边距 28px；表单标签列 95px、间隔 16px，操作区左对齐量 111px |
| 宽度不超过 850px | 全局栏 72px，仅视觉隐藏导航文字并保留可访问名称；平台栏 158px；字段改为上下排列，操作区取消标签列缩进；概览事实改两列、底部改单列，隐藏引导图形与条目配置摘要 |
| 宽度不超过 600px | 全局栏 60px；头部最小高度 98px、横向内边距 20px；平台分类移到内容上方并横向滚动；配置区左右 20px，平台条目与目录动作按需换行 |

页面最小宽度为 340px。移动端平台分类项保持不收缩，允许横向浏览；不把分类和全局位置合并为一层。隐藏的导航文字仍保留在可访问树中，跳到主要内容入口在获得焦点时显示。

## Elevation & Depth

界面主体通过相邻表面、单像素分隔线和留白建立层次。常态按钮、表单、平台条目、概览引导区没有阴影。概览引导使用淡色填充与边框；示例说明使用上下分隔线；移除确认在当前位置展开，插件目录在头部下方展开。

唯一已有投影用于右下角动作提示（`0 7px 24px #273f2a14`），使短暂反馈与滚动内容区分。提示层级为 10，跳转入口为 20。交互控件使用绿色 2px 外轮廓和 3px 偏移表达键盘焦点；焦点轮廓不作为装饰性阴影。

**平面优先规则。** 保留现有平面工作区；投影只承担已有提示浮层的分离作用，不给每个分区或列表项添加浮起效果。

## Shapes

形态以细边框和轻微圆角为主。输入和平台分类项使用 `field`，按钮和全局导航使用 `control`，概览引导与动作提示使用 `panel`；平台符号以 `symbol` 圆角包裹。状态标签使用 `status` 圆角形成紧凑胶囊，概览插接符号容器与活动圆点才使用圆形。

平台符号容器为 44px 方形，图标以细线条和当前颜色绘制。线条图形来自实际组件，没有随产品发布的栅格图、摄影、背景纹理或外部图片。图标在工具组件示例中以内联矢量路径呈现，不依赖应用运行时加载图标库。

## Components

主按钮提供明确的下一步：稳健绿底、白字、轻微圆角，内边距为纵向 8px、横向 15px，最小高度 39px，图文间距 7px；悬停使用已有加深绿色。次按钮保持白底、墨字与轮廓，悬停同时改变底色和边框。危险按钮仅承担“确认移除”；“已注册”使用低强调样式并禁用，禁用控件透明度为 0.55。文本入口以绿色文字和悬停下划线表达，移除入口悬停才转为危险色。

输入与选择框均为 42px 高，内边距为纵向 8px、横向 12px，使用相同轮廓与圆角。最终输入边框和悬停边框分别引用 `input-border`、`input-hover-border`，聚焦边框使用主要绿色。只读方式字段保留淡底与可读文字；错误以红色边框、就近文字及无效状态共同表达。标签通过关联标识连接字段，说明或错误通过描述关联；不使用占位文字代替标签。复选框为 16px，强调色跟随主要绿色。

全局导航由两个链接构成，当前项带页面状态；默认最小高度为 44px。平台分类由注册目录产生，当前项以选中底色和字重强调，并在桌面显示右向指示。平台分类与配置内容来自各插件，宿主只组织位置与通用状态。整行可点击的概览平台条目与平台目录中的独立“配置”按钮分别保留其已有交互方式。

“未连接”标签是只读状态，字号 11px、内边距纵向 3px 和横向 9px，配合文字和断开连接符号显示；不因状态标签本身制造额外焦点停靠点。平台条目另行展示“等待配置”或“配置已保存”，使连接与保存两个事实可以同时读到。

配置保存成功后的完整结果为“配置已保存在此浏览器中，尚未连接真实平台。”；本地校验结果明确不会发起外部连接。保存区显示尚未保存、未保存更改或已保存。结果以状态或警报语义呈现；失败不会显示成功。右下动作提示在 4200ms 后消失，并保留中文名称的关闭按钮。移除需要当前位置的确认区，取消与确认按钮并列；配置保留的说明靠近操作。空目录提供重新注册入口；单个配置面板渲染失败提供“重新加载面板”。

按钮、输入和选择框的背景、边框及文字颜色使用 140ms 的缓动过渡；键盘焦点沿用全局轮廓。开启减少动态效果偏好时停用过渡并恢复直接滚动。页面切换和目录变化没有入场、位移或缩放动画。

[设计扩展数据](../../.impeccable/design.json)包含十个独立示例：主按钮、次按钮、低强调已注册按钮、危险确认按钮、带标签输入、全局导航、平台分类、状态与配置入口、概览平台条目、概览引导容器。交互元素保留悬停与可见焦点；只读状态维持非交互语义。示例中的矢量图标为内联路径，颜色变量带有实际值回退，不依赖框架、工具类样式包或图标运行时。

## Do's and Don'ts

应当：

- 沿用浅色标签的中性表面、稳健绿动作与细分隔，按前置令牌引用现有颜色。
- 保持“概览／机器人”全局位置与插件平台分类的两层导航关系。
- 为操作提供中文名称、可见焦点、就近错误和与真实结果相符的反馈。
- 分开呈现注册、配置保存和真实连接状态，示例明确标注本地与未接入。
