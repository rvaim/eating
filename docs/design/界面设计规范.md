# Eating 界面设计规范

## Overview

**设计北极星：“浅色标签”**

延续负责人已选择的白绿浅色方向：浅灰全局侧栏承载稳定位置，近白插件分类栏承载目录，白色工作区承载任务。绿色用于选中、主要动作和正向反馈，细分隔与清晰文字层级组织内容。前置颜色、字体、间距与组件令牌保持，本轮不重设计或修改工具 sidecar。

这是以操作为中心、支持简体中文／English的本地管理界面。全局导航为“概览／机器人／Harness／提示词管理／人格管理／设置”，中文“机器人”保留、英文“Connections”；目录来自已安装插件。QQ五页签为“连接配置／代理与权限／实时日志／功能测试／MCP能力”，DSH含“配置／会话看板”。提示词公共层与主层保留，每个平台的插件说明和角色合入一个可折叠条目，按平台展开选择。

关键特征：浅灰与白连续工作区、小圆角、细边框、有限绿色；两层导航保持归属，配置与状态优先；桌面保留工作空间，390px 窄屏仍可操作、长英文允许换行，无横向溢出。插件启用、配置保存、真实连接和模型处理分别表达。

正文维护在本文件，[标准设计入口](../../DESIGN.md)仅为符号链接。[设计扩展数据](../../.impeccable/design.json)保留既有机器格式示例，本轮未修改；旧示例不作为当前业务状态。当前实现依据为[产品上下文](产品上下文.md)、[全局样式](../../apps/web/src/styles.css)、[应用框架](../../apps/web/src/App.tsx)、[语言选择框](../../apps/web/src/components/LanguageSelector.tsx)、[公开语言服务](../../packages/ui-sdk/src/i18n.ts)和各插件自有资源。当前固定布局与平台折叠的证据见[修复记录](../changes/2026-10-29-平台提示词折叠与面板滚动修复.md)；[多语言报告](../reports/2026-10-28-用户文案与多语言验证报告.md)与旧截图保留各自阶段范围。

## Colors

颜色以前置令牌为准：中性底色略带灰绿，主要动作稳健绿；不新增渐变或连续色阶。

| 角色 | 令牌 | 用途 |
| --- | --- | --- |
| 主要强调 | `primary`、`primary-hover`、`primary-deep` | 主动作、焦点、正向结果与添加入口 |
| 表面 | `sidebar`、`surface`、`platform-sidebar` | 全局侧栏、内容区、插件分类 |
| 内容层级 | `ink`、`muted`、`subtle` | 正文、说明、版本、时间 |
| 导航 | `tint`、`global-nav-*`、`platform-nav-*` | 两层导航默认、悬停、选中 |
| 分隔与输入 | `line`、`secondary-*`、`input-*` | 分隔、次按钮、表单轮廓 |
| 只读与状态 | `readonly-*`、`quiet-*`、`status-*` | 只读、已启用禁用按钮、连接状态 |
| 错误与停用 | `field-error`、`field-invalid-border`、`result-error`、`danger*`、`confirmation-*` | 错误与确认停用；入口保持低强调 |
| 提示与概览 | `notice-text`、`welcome-*`、`storage-*`、`toast-*` | 引导、异常与反馈 |
| 插件识别 | `qq-icon`、`feishu-icon`、`wechat-icon` | 既有品牌色令牌，不代表全部平台已实现 |

平台品牌色只用于识别，宿主动作和选中仍为绿色；状态必须配文字，不用绿色虚构在线。

## Typography

系统无衬线字体栈优先适配操作系统和中文，未引入网页字体或展示衬线。字阶使用前置令牌：页面 `headline`、面板 `title`、小节 `section`、正文 `body`、动作／字段 `label`、说明 `supporting`／`hint`。600px 以下页面与面板标题为 22px；概览引导在850px／600px以下为21px／20px，分区17px／窄屏16px，目录19px／窄屏18px，延续已有覆盖。

动作和状态随选定语言显示，技术名、地址、ID 和用户内容保持实际格式；不把英文动作强制全大写或添加装饰字距。计数和时间使用等宽数字特性，各计数之间保持可辨间距并允许换行。

## Layout

桌面为200px全局侧栏与弹性内容；头部最小119px、纵向29px／横向38px。插件分类栏208px，配置区上31px／左右44px／下48px，使用可收缩宽度。表单标签132px、间距24px、容器上限920px、输入上限670px，字段间23px，动作对齐156px。概览上限1400px、目录1100px；保持实际既有间距，不强制统一成单一倍数。

| 条件 | 已有布局 |
| --- | --- |
| 至少1700px | 配置右边距取44px和 `(100vw - 1500px) / 2` 较大值 |
| 不超过1100px | 全局172px／分类175px、横向28px、标签95px／间距16px |
| 不超过850px | 全局72px，文字视觉隐藏但保留可访问名称；分类158px；字段堆叠；概览事实两列、底部单列 |
| 不超过600px | 全局60px、头部最小98px／横向20px，分类移到内容上方横向滚动，配置左右20px，动作换行 |

页面最小340px。分类保持可横向浏览，不能合并全局与插件两层。语言入口使用侧栏底部原生 select，标签、title、aria 随语言更新，选项保持语言自称“简体中文／English”；窄栏仍能操作。跳转主要内容入口在聚焦时显示。

视口滚动规则：外框100dvh，页面头部保留，工作区与左右栏允许收缩并分别滚动。插件根display:contents使页签吸顶范围覆盖完整article和停用区；正文只使用宿主主滚动层。主区overscroll-y:none防边缘回弹，保留真实wheel／末端／键盘／短窗／resize验收。

页签轨道在滚动区上沿吸顶，使用宿主的实际横向边距填满背景，不用插件私有偏移常数。宿主声明--content-inset-block-start和--content-inset-inline-start/end；按钮最小44px，上下各8px留白，轨道含1px下边界为61px，内容聚焦余量由实际轨道高度计算。QQ与DSH保留各自选中样式，但共享这些几何规则；窄屏边距随宿主变为28／25／20px，宽屏右边距按已有规则取值。

看板会话导航在轨道下12px使用原生sticky，列表超高时自身滚动，正文仍在主区。可用高度按真实滚动视口和阅读区底部测量，包含正文末端和宿主页脚约束，不能只写100vh导致列表被推出。ResizeObserver与滚动帧只更新布局尺寸，不请求数据或模拟滚动，离开清理。手机为紧凑顶部会话选择区，最多176px且不超过28dvh；正文控件聚焦同时避开页签和会话区。真实长列表／50条正文、页脚末端及短窗绘制见[当前修复记录](../changes/2026-10-29-平台提示词折叠与面板滚动修复.md)。

平台提示词分组使用原生按钮、aria-expanded／aria-controls和子列表。默认收起，首次选中或深链接打开对应组；手动折叠不改变路由或编辑器，重读和语言切换不强制重开。移动端仍为横向目录，不因展开占满正文。人格目录、草稿、选区和撤销行为保持。

## Elevation & Depth

依靠相邻表面、单像素分隔和留白建立层级。常态按钮、表单、条目没有阴影；引导用淡色填充与边框，停用确认在当前位置展开，目录在头部下展开。沿用动作提示投影 `0 7px 24px #273f2a14`，提示层级10、跳转20；焦点为绿色2px外轮廓和3px偏移，不增加普遍卡片投影。

## Shapes

输入、按钮、面板、状态使用前置圆角令牌；平台符号44px。图标以线条和当前颜色绘制，没有新增随产品发布的摄影、背景纹理或栅格素材。保留既有平面形态。

## Components

主按钮明确下一步，绿色白字；次按钮白底墨字，悬停改变已有底色与边框；危险按钮用于“确认停用”等真实危险动作，“已启用”低强调且禁用。沿用动作最小39px、纵向8px／横向15px、图文间7px，禁用透明度0.55。停用入口保留当前位置确认、取消和配置／数据保留后果，不能把 disable 叫“移除”。

输入和 select 高42px、内边距8px／12px；输入轮廓与聚焦色沿用令牌。字段有可见关联标签，错误和说明通过描述关联；不以placeholder代标签，不仅靠红色表示错误。复选框16px，使用主要绿色。

全局导航最小44px，当前项有页面状态；插件分类读目录，宿主只组织位置和通用状态。连接状态只读，不额外制造焦点点位。保存反馈与连接状态分开：当前资源为“配置已保存。连接状态可在面板中查看。”，校验说明“配置格式正确。校验不会发起连接。”；不再称只存浏览器或虚构本地示例。真实 QQ／DSH 操作以各自状态为准，运行时已安装不等于真实模型认证。

结果用status／alert语义；4200ms动作提示保留本地化关闭名称，单面板失败可重新加载。按钮／输入过渡沿用140ms，减少动态效果时停用过渡；不新增页面入场、位移或缩放动画。[设计扩展数据](../../.impeccable/design.json)为既有示例，本轮不自动修 sidecar 或工具元数据。

## 用户文案与语言

主要文案描述状态、下一步与后果，不复述开发分工、健康核验或交接实现。保留消息可靠接收仍需AI处理、内存退出丢失、清空不可恢复、未知先核对、真实发送／撤回确认等信息。诊断原文、JSON与配置位置通过折叠入口保留，已知错误code映射本地化提示、未知后端原文不做主文案。

普通UI句在app／settings／authoring／qq／dsh各自完整双语资源，走公开UI SDK与精确 `i18next 26.5.11`。完整句使用插值与库复数，覆盖按钮、aria、确认、校验、错误、日期数值及真实Editor诊断／补全。独立插件通过公共全局语言服务共享locale，不依赖宿主私有import或硬编码插件链。

默认zh-CN，`eating.locale`只存语言偏好；刷新保留、跨标签页同步，document lang／title／meta即时更新。语言切换不重挂面板、不丢草稿／selection／undo，不触发POST／重启／消息或增加日志订阅。用户名称、模型名、URL、Key、消息、JSON、canonical中文变量token（如 `{{当前时间}}`）和默认策略正文保持原样；不能把主人内容中的中文当成翻译遗漏。工具标题和参数说明按ID做展示翻译，Host catalog仍是业务来源，未知metadata原文回退。

当前完整构建／严格检查、Vitest561/561和浏览器29/29通过；生产六路线中英桌面／390px共24图已全部读取，独立复核SHIP、material=0。概览计数的间距精修后重建／严格检查、catalog／workspace10项和国际化浏览器6项通过，四张概览补采图与最终阅读结论见[报告](../reports/2026-10-28-用户文案与多语言验证报告.md)，不将限定复核当全套测试重跑。

## Do's and Don'ts

应当：沿用白绿表面和前置令牌；保持两层导航与插件归属；动作与真实后果对应；提供当前语言的可访问名称、焦点与就近错误；长英文允许换行；分开呈现保存、连接、可靠接收与处理完成。

不应：替换视觉方向、加普遍阴影／渐变／装饰动画；用品牌色替代宿主动作色或虚构成功；隐藏风险、标签或键盘焦点；翻译用户内容或canonical协议；切语言触发业务动作；复制第二份英文设计正文或另改技术入口／机器sidecar。
