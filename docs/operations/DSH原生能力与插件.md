适用：DSH插件0.16.0、Eating0.18.0／API4；当前默认与主人配置按[ADR-0035](../decisions/ADR-0035-会话代理自主处理与默认开放可配置.md)。入口：**Harness → DeepSeek Harness → 原生能力与插件**。本轮部署提示按[ADR-0045](../decisions/ADR-0045-官方记忆接口与插件部署提示.md)实现，已完成本地和云端验证并部署更新（DSH0.16.0 connected、ready／nativeWeb ready）；完整证据见[本轮报告](../reports/2026-11-04-官方记忆与插件能力更新验证报告.md)。

## 系统 DSH 安装状态

面板顶部读取运行Eating的服务器实际安装状态，区分“正在检测／尚未确认”“服务器未找到DSH”“已找到命令但未取得版本号”和真实启动／运行错误。`found:true`且`version:null`仍表示找到可执行命令，不能显示为未安装；浏览器所在机器的操作系统不能证明服务器环境。

未找到时按面板链接查看官方安装说明，在运行Eating的机器手动安装官方CLI或桌面应用，再点击“重新检测”。Eating不自动下载、执行安装命令或安装额外运行时；检测期间仍可保存模型配置。重新检测只核对安装，不代替模型连接或真实任务验证。地址与模型未配置时明确提示补齐，Key按服务要求可选。

## 原生功能

点击“读取当前目录”检查运行Eating的服务器上系统 DSH 实际提供的模块。未配置模型时也可以读取和保存原生能力；停止状态使用短生命周期管理进程，不调用模型或创建会话。运行中直接读取当前实例。

功能可搜索，展开目标条目后：

1. 选择功能是否开启及使用它的代理类型；新配置默认只开主子时间上下文；其他原生功能按需开启。
2. 功能型native Profile MCP默认供所有Agent使用，main非reserved全局工具默认开放；逐工具的自动／自定义例外在“插件工具授权”中保存。其他子非MCP选择独立生效，Eating／QQ受控通讯范围不绕过。
3. 根据需要修改原生模块 JSON。每个模块条目下是该模块的完整配置，依赖服务的配置也在同一对象内。`<stored-secret>` 表示保持原秘密；删除字段表示明确清除。保存前系统 DSH 校验模块、平台、依赖与原生配置。
4. 停止 Harness 后点击“保存原生能力与授权”，再启动 Harness。

新配置只启用time，供主／子使用上海时区与600000ms；其他feature默认关闭且代理列表为空。模块采用自身默认参数，不额外开启files.write/edit或web.search。已有配置严格读取而不补写；主人手动保存的time＋web等选择保持，不套用新默认。Bash/PowerShell、文件搜索、工作目录、后台任务、网页、技能、提醒、目标、待办、结构化提问和文件交付都使用官方原生模块。

模块存在不代表远端服务已经配置。网页搜索需要此 Eating 实例自己的原生搜索提供商和鉴权，未配置会返回真实错误；不会借用主 DSH 的账号或环境密钥。网页获取与关键词搜索是不同工具，web feature默认关闭；主人启用时按所选模块参数决定fetch/search；缺搜索提供商或Key明确报告未配置，不能冒充Eating权限拒绝。若网页获取报non-public IP且DNS返回198.18/15，属于原生HTTP公网地址策略与TUN/Fake-IP的冲突；普通网络可通也可能在请求前被拒绝，原生参数没有allowFakeIp开关，详见[现场诊断](../reports/2026-11-01-原生网页Fake-IP拦截与图片声明诊断.md)。Eating专属官方permission默认danger-full-access／approval never，主人仍可通过正式设置显式再配；终端和文件仍使用实际DSH／OS能力，代理范围选择不是OS沙箱，不改主人主DSH或官方Web。

“草稿未保存”“已保存，待启动”“等待代理创建”和“已挂载”是不同状态。页首同时显示已保存版本与运行中应用版本。子代理尚未创建时没有实际挂载记录，不会为了检查状态唤醒模型。运行中修改按钮禁用，请先停止 Harness。

## DSH 插件

“DSH 插件”同时显示真实 Bundle 和 Loader 模块。来源包括系统安装、Eating 专属 Profile，以及官方目录中尚未安装的条目。搜索只过滤目录；“显示基础组件”展开不可移除的内核、Eating 桥和官方 Web 组件，并说明原因。

插件作用于整个 DSH 实例。可以分别启用/停用 Bundle，以及实际可管理的模块。禁用不会卸载，卸载也不会删除插件资料。Bundle 和模块可能受依赖或更高优先级设置影响，读取当前目录可以查看真实结果，不以保存成功代替已运行。

模块配置不回显原值或密钥。配置编辑器初始空白：留空保持；填写 JSON 对象并“保存此模块配置”会完整替换原配置，`{}` 表示明确清空。失败或结果未知时先重新读取目录核对，不重复写入。

## 检查并安装

安装区接受 DSH 原生管理器支持的 npm 包及版本、本机绝对目录、Git 地址或 tarball：

1. 输入“插件来源”，点击“检查来源”，核对返回的包名、版本和接受状态。
2. 勾选信任该来源代码，再点击“确认安装插件”。检查本身不等于安装。
3. 安装由官方 PluginManager 和 pnpm 完成，安装后保持停用。不要把包下载/安装结果当成已挂载成功。
4. 若原生管理器报告依赖需要安装脚本，页面列出确切包名；只有主人再勾选脚本许可才会重试安装。
5. 核对目录后单独启用插件；main及所有Agent功能型native MCP默认自动取得工具。需要限制时可为该工具改“自定义”，选择精确代理类型并保存；其他子非MCP仍可按当前目录选择。

安装、启停、配置、卸载都要求 Harness 完全停止；其他页面也不能在管理进程活动时启动同一实例。安装失败只显示原生结构化原因，不回显 pnpm 原始输出或秘密。结果未知时重新读取目录，不自动重做。卸载需要先停用并再次确认，仅删除插件代码，保留资料。

## 插件工具授权和 MCP

“自动”下，main取得非reserved全局工具，所有Agent取得功能型native Profile MCP及新增工具；其他子非MCP按原有名称／schema指纹／类型选择。目录automaticAccess说明默认行为，主人可以逐项切换“自定义”，选择精确类型并保存，排除main或清空全部类型可禁用工具。

自定义以同名toolAccessOverrides为准，优先于自动行为与toolGrants。schema指纹变化后保留限制且停止授权，不回落为自动开放；先读新目录核对，再确认当前工具或恢复自动。暂时缺失的工具也保留例外，可明确恢复自动。工具目录与最终调用守卫同时执行，tools/change更新native.restrict；reserved／来源／QQ scope不能通过同名覆盖绕过。

原生配置保持schema1，toolAccessOverrides缺省沿用默认、不补写；保存省略保持当前例外，[]恢复全部自动。feature的启用／代理范围／参数保持独立。Host capability／direct来源则到“MCP”页选择all/custom并保存，custom不自动纳入后续新类型／新工具，可恢复all；QQ通讯仍由来源权限页管理。

普通入站委派遇unknown时先核对原任务及Host回执，不换call重放原context；新入站context＋新call可继续使用同child，pending仍拒并发。旧unknown／迟到回调不会撤新scope，动作账本保持。联系额度错误按code及used／resetAt判断，读取activity_state或安排active不会重置主人保存的小时联系额度；409须结合outcome判断，不一律视为unknown。见[ADR-0037](../decisions/ADR-0037-未知委派隔离与受控图片发送预算.md)。当前服务正常connected，前轮清理后保持停止只描述历史状态，该前轮交付以[报告](../reports/2026-11-03-未知委派隔离与受控图片发送验证报告.md)为准。

## 历史会话

入口为 **Harness → DeepSeek Harness → 历史会话**。先完全停止 Harness，确认本实例全部 SDK、子运行时、原生 Web 与管理 helper 真正退出，且 Host 无待交接消息，再点击“扫描历史会话”。按实际 v4 session header 统计总／主／子会话，不凭当前绑定猜数量；预览有效 5 分钟。核对显式确认区、勾选确认复选框，再点击“确认清理 N 个会话”；取消不删除，过期或文件变化后重新扫描。

清理本实例全部原生主／子日志、同 Session generation、对应原生附件与派生缓存、桥接正文和绑定元数据；workspace 混合文件仅过滤 session 关联数组，保留 workspace 实体、路径、标题和其他字段。配置、Key、人格、Host queue／actions、业务图片和外部 OpenViking 数据保持，用户主 DSH 不在范围内；不承诺 OS forensic 抹除。

这是带外文件维护：官方 rc.5 的 SessionController／sessionPersistence 无删除 API；离线计划只操作固定 Eating 专属根，逐项核对目录／stat／hash，拒绝符号链接、越界、过期与变化。POSIX 的 `session.lock` 停止后会保留空文件，应原样保留，不能据此认定会话仍活动。不启动可能由官方 schedule host timer 恢复冷会话的完整 Web helper。若原生定时任务引用目标会话，须先由主人在官方 Web 删除相关提醒，已停用的提醒也须删除，再停止并重扫；仅停用不能解除目标引用阻断，清理不自动删除调度策略。Goal 仅随 Session 日志与 projection 清理，不另造清理文件。

仅主人管理 API `preview-session-history`／`clear-session-history` 可操作，模型没有对应 MCP 工具。执行使用稳定 `requestId` 和持久回执；结果 unknown 或中断时核对原请求，不换号重发。取消未提交的确认不清理，关闭页面也不能撤回已提交操作。本地实现与验证已完成，预览保留3个示例会话供主人查看；隔离测试与示例预览不表示真实历史已清理或已部署。

## 草稿、隐藏和错误

语言切换保留功能 JSON、代理选择和草稿，不触发重新读取或保存。功能配置与连接配置独立保存。切换页签或离开时停止本页读取，清理插件配置输入和安装来源；已向后台提交的写操作不会因关闭页面而伪称未发生。

遇到版本冲突或未知结果，先点“读取当前目录”。草稿仍保留；若已保存版本变化，点击“放弃草稿并载入已保存配置”后重新编辑。原文件损坏或版本不支持时明确报错，不自动转换、补字段或覆盖。

Eating暂停只控制其无输入定时机会及真正自主周期，不冻结main所有能力；原生schedule_create/schedule_update不再被Eating自主周期人工阻断，保持官方语义，Eating agenda仍按其暂停／额度规则执行。

本功能使用Eating自己的数据和系统DSH安装，不修改主人主 DSH、当前 DSH GUI、主 Profile 或凭据。实现决策见[ADR-0021](../decisions/ADR-0021-DSH原生能力与插件管理.md)，当前验证／清理与部署见[本轮报告](../reports/2026-11-02-会话代理自主处理与默认开放可配置验证清理报告.md)，首次原生管理阶段证据保留在[历史报告](../reports/2026-11-01-DSH原生能力与插件管理验证.md)。
