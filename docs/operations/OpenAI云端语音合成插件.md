# OpenAI云端语音合成插件

2026-11-14：当前实现扩展为多协议配置／任务schema2，OpenAI Realtime是其中一个适配器。DeepSeek能力、独立识别插件、旧语音重建及当前配置步骤见[多协议语音与识别](多协议语音与语音识别.md)。下方schema1和旧版本内容为历史阶段记录。

2026-11-10 已随应用0.21.1部署云端，语音插件0.1.2已安装、待主人保存自己的Key／音色后启用。未调用真实合成或向真人QQ发送，部署证据见[本轮报告](../reports/2026-11-10-图片大小配置验证报告.md)。

本插件通过OpenAI云端生成QQ语音条，无需本地模型或GPU。音色由主人配置并保持稳定，会话AI按内容选择临时语气；面板不提供全局语气配置。

## 安装与配置

使用已构建产物plugins/capabilities/text-to-speech/dist，通过正式插件安装入口安装；源码开发可先运行pnpm build。插件独立可停用、卸载，卸载代码不删除数据。

更新已有实例时，新插件保留未启用状态。可以先保存服务地址、模型、音色和自己的 Key，再点击页面底部“启用”；停用时面板只提供配置，不请求任务列表或调用合成。任务列表仅在有运行中任务时定时更新。

在插件→语音合成填写服务地址、模型、音色和API Key并保存。默认使用wss://api.openai.com/v1/realtime与gpt-realtime-2.1-mini，音色可选alloy、ash、ballad、coral、echo、sage、shimmer、verse、marin、cedar。正式服务使用wss；ws仅接受本机回环测试。Key留空保留，显式勾选清除才删除。保存／连接只做本地配置检查，不代表真实模型权限或合成已验证。

默认请求超时120秒，允许10～300秒。没有接入本地模型、旧Speech接口或失败自动回退。官方[语音文档](https://developers.openai.com/api/docs/guides/text-to-speech)说明旧tts模型2027-01-06停服；本插件直接使用Realtime事件。

## 试听与会话语音

面板填写朗读文本，点击生成试听并确认计费提示。试听使用已保存音色、自然口语，不发送QQ。任务成功后加载播放器，可通过原生播放控件试听；删除任务和音频需单独确认，删除后旧引用失效。

会话AI调用speech_generate传text与可选delivery，例如轻柔、平稳、轻快；delivery只作用于这段语音，不修改音色或人格。用speech_job_get查询真实结果，再用speech_get取得sendable，QQ发送工具的message直接传[sendable]或sendable。语音独立发送，配文另发。首次使用向听者说明声音由AI合成，不冒充真人录音。

生成成功不等于发出；以QQ真实成功回执确认。已有语音复用assetId，不为重发再次合成；unknown可能已计费或发送，不能自动换ID重做。模型只见资源引用，后台解析实际音频并核验授权。

## 限制与数据

每段最多1000字符／60秒，WAV为24kHz单声道PCM16。超长、转写被改写或协议异常会失败／未知，不自动付费重试。转写核对不等于已经证明波形内容与音质，真实中文效果仍须试听。

最多200任务、128MiB音频，容量包含中断留下的实际文件；满时拒绝新请求，由主人删旧任务，不自动清资料。配置与索引均schema1，数据位于EATING_HOME/capabilities/text-to-speech。任务元数据含待朗读文本、临时语气、音色、状态与资源引用；它是生成任务库，不是Eating聊天历史库。密钥与音频Base64不进普通执行记录。

隐藏页面或离开会停止轮询并撤销播放器Blob，未保存Key会清空；切语言只改变界面，不丢非秘密草稿或生成第二次。已提交任务继续由插件管理，停用／进程中断保unknown且不重放。

QQ当前使用后台可信音频Base64，不依赖共享目录或公开URL。OneBot报告支持语音不等于已验证实际转码和接收端播放；真实验证须在主人明确授权后进行，不由自动测试向真人发消息。
