# OpenViking 记忆插件

适用：openviking-memory0.1.0、Eating0.14.0、plugin-sdk4.5.0、DSH0.12.0，插件API4。插件管理→OpenViking记忆提供连接配置、记忆范围、活动三个页签。机器人服务用户由主人在OpenViking创建，Eating不创建账号，也不读取主DSH记忆配置。

## 连接

安装构建产物 plugins/capabilities/openviking-memory/dist 后启用。连接页填写服务地址和用户ID，API Key按服务鉴权需要填写；Account可在高级项填写。保存只写当前配置，不提取记忆。点击“保存并连接”明确检查已保存的服务身份，或保存后单独连接。测试连接也只用已保存配置，草稿尚未保存时不可测试。

Key保存后不回显，留空保持；勾选明确清除并保存才删除。高级项包含超时和下次Host启动时是否自动连接。地址/账号/用户改变代表另一套记忆空间，不迁移旧资料。服务需具备当前会话/任务/检索/内容API及已配置的Embedding/记忆提取模型；连接成功不证明提取模型完成过真实任务。

## 全局与会话目录

全局记忆默认开启，保存到 viking://user/<user>/memories；每个会话使用可读Peer：

```text
viking://user/<user>/peers/<platform>-<account>-private-<target>/memories/
viking://user/<user>/peers/<platform>-<account>-group-<target>/memories/
viking://user/<user>/peers/self/memories/
```

例如 qq-100000101-private-100000202 与 qq-100000101-group-100000303。主人与普通联系人都使用其私聊Peer，主人身份不写进目录名。平台使用小写字母/数字/下划线且首位字母；账号/目标/成员使用字母、数字、下划线，避免拼接歧义。OpenViking服务用户ID/Account另外允许点、连字符和至多一个@，上限96字符；不能为单独的点或双点，Account不能以下划线开头。它们不参与会话Peer拼接，不填显示昵称。

开启全局意味着所有会话可以召回全局知识，服务提取可在全局和当前Peer保存内容。全局不是私聊隔离保证；不希望共享时可关闭。统一人格仍由Eating提示词负责，不自动复制或改写人格。

## 范围和名单

私聊默认开启采集和召回；群聊默认关闭采集，可以逐群添加覆盖规则。按平台/机器人账号/类型/目标精确匹配，名字仅供辨识。

规则列表支持搜索、单项展开、删除草稿和撤销。群规则可选择全部成员/白名单/黑名单，一行一个实际成员ID；不按昵称或自称匹配。白名单只采集所选成员，黑名单排除所选成员。混合被排除成员的回合，只提交允许成员的原文，不提交可能引用被排除内容的助手总结或工具摘要。

采集开关控制新内容是否提交；召回开关控制当前会话是否使用历史。名单更改不自动删除已有记忆。规则保存立即撤旧在途请求并让新操作采用新配置；已有未知提交不重放。更改时未提交的内存缓冲会丢弃，界面说明后再保存。连接身份不变且原本已连接时无需重启Harness。

“允许主人跨会话查看”作用于主人私聊的显式全库搜索，群聊内的主人不获跨会话权限。主人由当前通讯插件身份配置复核。原生主人Web会话也可显式查阅；自主活动不能冒充主人。自动召回始终查当前Peer＋全局，不每轮全库查询。本机主人管理页可以搜索/读取已有记忆，不受模型会话权限代替控制。

## 自动采集与提交节奏

启用插件并连接后，自动采集独立于模型是否调用保存工具：DSH主Agent在准入后检索真实输入，回合结束提交真实用户消息、可见助手文字及工具名/结果摘要。原始QQ JSON会解包，保留发送者、角色、时间及消息ID；子代理不重复采集。工具运行期间从原生Web追加的主人输入也会采集：同一自身回合合并消息，混在QQ回合时单独归入self，不把主人补充和助手复述写进该QQ联系人的Peer。工具returned只说明工具函数返回，不表示QQ发送成功；不采集内部推理、工具参数、原始结果、图片、时间提示和记忆注入自身。

默认小批量：8条消息、6000字符或静默300秒；有工具动作和显式memory_save立即提交。也可改为每轮提交或估算token阈值。Token为估算而非账单计量。没有每日/每小时提取上限；面板只统计本地日期成功完成次数。

为了正常内存/网络运行，有2MiB暂存、单任务512KiB、2个并发工作者、有界任务/会话摘要等机械容量限制，满时明确拒绝或记录错误，不为继续运行静默丢弃在途任务。这些不是用户费用额度。长期开启自动提取会使用OpenViking服务自己的模型资源和费用。

## 提取、清理与恢复

每批创建新的OpenViking临时Session，显式禁用服务自动提交，用插件统一提交。types为preferences/entities/events，全局开关决定允许全局self提取，peer提取始终指向本轮会话。

“已接收/提取中”不表示已形成记忆：后台检查任务完成、读取memory_diff实际变化计数，再删除本插件创建的临时Session。长期记忆保留，OpenViking里的本次原始对话归档清理；这不删除DSH自身已有的原生会话历史或用户其他资料。失败/取消的终态任务可清理；任务仍在运行或提交结果未知时不删其原始记录，避免破坏远端提取。结果未知不自动换ID重做。

配置和任务元数据存储在 EATING_HOME/capabilities/openviking-memory，严格schema1/CAS；只有队列正文在RAM，不建立Eating聊天历史。Host重启时未提交缓冲丢失，活动中未知提交不重发；已取得taskId可继续查询并完成清理。服务长时间不返回终态时保留任务/错误，无法保证远端最终完成。正常退出会对已授权缓冲作有界提交；手动断开/停用或修改配置立即撤销，可能丢弃尚未提交的RAM内容。

## MCP工具

在MCP页单独授权代理类型和工具；安装/连接不自动授予工具。当前DSH主会话由Host提供每轮真实范围，不需要模型传Peer或账号。

| 工具 | 用途 |
| --- | --- |
| memory_search | 查询当前会话＋全局；主人可显式all搜索 |
| memory_read | 读取当前范围内的精确记忆文件 |
| memory_save | 稳定request_id提交重要信息，不代表提取完成 |
| memory_scopes | 查看当前Peer和范围状态 |

删除不向模型提供工具。活动页可展开查找与管理记忆，读取后确认精确URI删除，只删除该记忆文件，不递归删除用户或目录。标准记忆文件可含中文名字；显示原文，不跟随界面语言翻译。

其他Harness可以通过已授予MCP工具使用记忆，自动召回/采集需要其适配器采用公开memory服务；当前已实现和实跑DSH，不声称其他引擎自动接入完成。

## 面板交互

切页签/切语言保留非秘密草稿，保存栏跨页签可达；冲突不能直接重存，先显式核对或放弃草稿。保存并连接第二步失败时显示“配置已保存但连接未完成”。隐藏/离页停止读取，清理输入Key和已展开记忆正文，后台已接受提取由插件继续跟踪；前端关页不等于取消提取。

活动页5秒可见轮询，只读任务摘要，没有聊天正文。提取计数、状态、错误代码和精确任务ID可展开核对。搜索/读取/删除走真实服务，不在localStorage保存记忆或鉴权。
