# 图片大小设置

打开“设置 → 图片大小”，填写单张图片上限并保存。默认 10 MiB，可设 1–50 MiB 的整数，1 MiB = 1048576 字节；PNG、JPEG、WebP 和 GIF 使用相同上限。

这份设置同时约束 Eating 自带生图的参考图和结果、表情包上传／收藏、QQ 收图下载、图片预览及受控资源发送。单次最多 4 张，多图原始字节合计不超过单图上限的 2 倍；默认合计 20 MiB。Base64 和传输信封预算自动计算，无需分别配置。提供商和 QQ 可能有更低的实际限制。

保存后后续操作立即使用新限额。已经接受的生图任务沿用提交时的上限并保存结果；调低不会删除原图、清空表情库或改写历史索引。超出当前限额的旧图仍在列表中，可管理元数据或显式删除，调高限额后可继续预览和发送。更改设置会使旧的图片发送 lease 失效，未确认结果的发送不能自动重试。

不同页面同时保存发生冲突时保留当前草稿，重新读取前会提示是否放弃草稿。界面语言切换保留输入，不自动保存。设置只由主人管理，AI 不能扩大自己的图片额度。

调整的是 Eating 自带图片资源的大小限制，不改变每个图片库 256 MiB 总容量、下载超时、账号和会话权限，也不调整通用 direct MCP 的独立 10 MiB 传输信封或第三方服务配置。提高限额会允许更大的内存及网络传输，请按实际需要设置。

持久化位于 Host 的 `host:image-limits`，不需要修改各插件配置。请使用设置页保存，不手工改库或对旧格式自动迁移。新功能须更新至本轮 Host 与对应插件版本；只升级 Host 不能改变旧插件内部实现。完整契约见[ADR-0052](../decisions/ADR-0052-统一可配置图片大小.md)。
