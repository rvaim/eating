# 安卓手机插件

android-control0.1.0提供完整 ADB 命令与自主手机子代理。需要 Eating0.26.0／SDK4.15.0及DSH0.22.0。它不限制 ADB 子命令，不设置娱乐时长、每日额度或强制冷却。

2026-11-15已部署运行源码0b86a1c。云端“插件 → 玩手机”现已可用；当前未启用、待配置执行端。保存实际远程执行端地址／Token后再启用，不把已安装等同已连接手机。

## 本机使用

1. 安装 Android Platform Tools，确认已有 adb 可执行文件。插件不自动下载。
2. 构建后，用既有插件安装入口选择 plugins/capabilities/android-control/dist；开发CLI可运行 `pnpm plugin install plugins/capabilities/android-control/dist`。
3. 在“插件 → 玩手机”配置本机 ADB 路径（空值从PATH检测），工作目录可留空。连接后若需修改配置，先停止连接；执行目录中的路径属于实际执行端。
4. 手机开启USB调试并确认电脑RSA授权，或用无线调试配对。面板命令参数填写 `["devices","-l"]`。配对、connect、tcpip等也可直接执行，不限于固定表单。
5. 既有MCP默认all；主人可在MCP页选择custom。主Agent通过eating_start_execution选择android-control.phone，独立子会话自主使用完整ADB，主继续处理其他输入。

## 远程执行端

Eating在云端、手机在本地时，执行端运行在手机旁电脑。使用构建包中的 `executor.mjs` 与同一包的server.mjs，不从工作区复制私人配置。命令为：

```sh
node /path/to/android-control/dist/executor.mjs /absolute/private/phone-executor.json
```

配置只放项目外，示例字段如下；token替换为自行生成的32–256位URLsafe随机字符串，路径替换为执行端实际值：

```json
{
  "schemaVersion": 1,
  "host": "127.0.0.1",
  "port": 48123,
  "token": "REPLACE_WITH_YOUR_RANDOM_PRIVATE_EXECUTOR_TOKEN",
  "adbPath": "/path/to/adb",
  "workspace": "/path/to/private/phone-workspace"
}
```

云端经已有私有网络或SSH隧道访问该执行端回环MCP；面板选择“远程执行端”，保存可达的完整 `/mcp` 地址和同一Token后连接。USB线接在实际执行端，网络ADB也由它访问手机；配对不会自动解决家庭NAT。执行端配置、ADB私钥及其实际连接信息不放Git或聊天日志。

## 命令、进程和文件

参数是adb后面的字符串数组，模型与面板共用同一执行器。例：`["-s","DEVICE_SERIAL","shell","getprop"]`、`["logcat"]`、`["install","/executor/path/app.apk"]`。设备端脚本按ADB shell语义引用，本机shell不再次解析参数。

首次wait_ms只决定返回进程句柄的等待，不是命令总超时。长进程用process_read/write/stop处理；交互终端在POSIX需要执行端已有Python3标准库，Windows当前仅普通管道模式，缺少能力明确报错。stdout/stderr用字节游标读取，UTF-8完整；单流前16MiB保留并标明截断，后续输出仍被排空，不因输出满而假死。

文件上传／下载按64KiB分块；install/push读取执行端文件，pull/bugreport写执行端文件。截图可以用android_screenshot，或android_adb_exec的output=image。模型返回文字、工具列出图片参数或面板显示路径均不能代替实际图片入模。

每次副作用用稳定request_id；命令已执行但回复丢失时查询原结果，不换号重新执行。输出清理保留墓碑。主可查询、追加、停止手机任务；主人可立即接管执行端。停止本地ADB进程不等于手机端所有后台工作已停止，须核对实际状态，已发生的点击／安装不能撤销。

## 提示词与数据

“提示词管理 → 插件 → 玩手机”是本插件可编辑使用说明，主与手机执行角色都会实际组合该文档。手机类型自身也有独立可编辑提示，和共用人格组合；不让主完整代写回复或逐条审批命令。

配置schema1＋revision/CAS；execution-bindings仅保存无正文任务身份。执行器私有SQLite回执保存HMAC意图、状态和句柄，不保存原始命令／stdin到Host账本；输出和模型会话各自仍可能留存。停用／断开与卸载按既有插件生命周期执行，不清理其他插件或主DSH数据。
