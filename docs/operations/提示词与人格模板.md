# 提示词与人格模板

当前源码应用／Host／Web0.17.3、QQ0.13.6、DSH0.15.3，API4及SDK版本保持；本轮隔离验证及实际Eating部署完成，证据见[本轮报告](../reports/2026-11-03-主Agent核实交接与实际部署验证报告.md)。应用提供人格模板草稿入口和提示词“恢复默认”。提示词决定工作与协作指引，人格决定性格、表达、兴趣与相处方式；账号、工具及数据访问权限仍由后台授权控制。

本轮按[ADR-0040](../decisions/ADR-0040-主Agent核实交接与只读任务阶段.md)，主先理解请求、判断事实是否足够，再显式选择handle的mode：verify只核实回报，reply由原会话子自然组织回复。handle必填context_ref／mode，context_notes可选且≤8000字符，只交可披露事实／来源／未知，不预写全文；contact必填target_id／task／mode，delegate schema保持并内部固定reply。子信封coordination承载mode／context_notes；verify不是一句提示词，后台临时readOnly范围在通讯和功能MCP目录及调用guard仅放tool.readOnly===true，direct未知metadata不放，空工具允许；原生feature／全局工具禁用，本阶段不额外挂time。同canonical UUID后续reply重取原普通授权并撤旧lease，临时scope／policy仅RAM。必需规则继续进入各自唯一complete，自定义正文与人格不reset。是否需核实仍由LLM语义判断，只保证显式verify受控阶段不能发／写，不能保证事实绝对正确。主人已授权的修复及实际部署已完成，新运行桥与源码SHA一致，验证及生效证据见[本轮报告](../reports/2026-11-03-主Agent核实交接与实际部署验证报告.md)；现场12／小时及native revision5 time＋web保持，真实记忆0.1.1不升级。

前轮[统一身份核实与自然短消息](../decisions/ADR-0039-统一身份核实与自然短消息.md)源码实现与隔离验证完成，未部署；证据见[验证报告](../reports/2026-11-03-统一身份核实与自然短消息验证报告.md)。同一 AI 不因当前私聊缺少群记录否认参与，主先核实已有记录／获准记忆／对应会话事实，查询任务只核实回报不向被查询会话发言，原会话子再自然回答。普通聊天一条可以有几句话，一次回复也可以接着发多条，没有固定句数或条数；连贯的话一起说，适合另发的补充实际另发，不用大空行把两句短话排成两段，也不每次都用追问收尾；详细需求、逐字原文、代码和链接保持完整。真实独立气泡须分别调用发送工具，每条不同且稳定 request_id，顺序核对回执，unknown 停止自动续发与重发。模板只更新新增草稿，主人已保存人格／自定义正文保留；无需为收到必需规则先恢复默认，运行时会将共享身份／表达和主子协调规则合入各自唯一 complete。实际实例须获准部署相应应用／插件并加载新规则后生效，脚本回环不保证真实 LLM 必然采用相同行为；不实施前轮自主活动、额度或 sleeping／waiting 修改。

本轮[聊天参与感与人格场景指引](../decisions/ADR-0041-聊天参与感与人格场景指引.md)新增源码实现与隔离验证完成、未部署、未二次提交，最终证据见父代理维护的[报告](../reports/2026-11-03-聊天参与感与人格场景指引验证报告.md)。共享 conversation-policy、Host common 和 QQ group defaults 补充先判断真实 @／引用／说话对象、读完整批后选择回应；有具体态度、新信息、好奇或联想可以自然接话，没被点名也可参与。对方不接、拒绝或翻篇就停，不逐条点评、不当主持／调解／气氛组；适应本群语气不照抄，相关且可披露的记忆才提，旧消息不说成刚发生，不编造刷手机吃饭或故意答错装傻刻薄。多句／多条及 verify／reply／权限契约保持。AI女儿新增草稿补被关心、被误会、玩笑、认真提问四类小例子，仅示范态度，不是固定台词或已发生事实，模板更新不改已存人格。父先完成 `71e20cd` 并成功 push `origin/main`，之后才新增规则；当前不自动二次 commit／push、不部署、不重启，新规则尚未加载到实际实例。主动活动正向动机只补待审方案。

## 从“AI 女儿”模板新建人格

1. 打开“人格管理”，选择“新增人格”。
2. 展开“从模板新建”，点击“使用「AI 女儿」模板”。模板只填入当前未保存草稿的正文，不创建或启用人格。
3. 填写人格名称。名称由主人决定，模板中的 `{{人格名称}}` 会使用当前启用人格的名称；如已经填写名称，套用模板会保留它。
4. 阅读并按需要修改正文。已有非空草稿正文时，页面会先询问是否替换；选择“继续编辑”保留原草稿，选择“替换草稿”才换成模板正文。
5. 点击“保存人格”。保存后它成为普通人格，仍未启用；确认后可手动点击“启用人格”。同一时刻最多使用一份，也可以全部停用。

本轮只有一份本会话批准的“AI 女儿”模板：第一人称女性 AI，自然称主人为“爸爸”，有好奇心和自己的脾气，会亲近也会顶嘴；依据当前上下文与可用记忆延续真实经历，不预设人生或成长阶段，不编造共同经历。称呼不会改变主人身份与工具权限，也不会保证已经安装或授权任何记忆能力。

模板不是固定选项锁定。主人可编辑全部正文；保存后不会因模板更新而自动替换该人格。切换界面语言只改变按钮、提示和诊断，模板正文、人格正文及名称保留原文。模板选择本身不写后端配置；页面草稿应在离开或刷新前显式保存。

名称去除首尾空白后为1至80个字符，正文需非空、变量合法且不超过50000个 UTF-16 代码单元。最多保存100份人格。正在使用的人格可以编辑保存，后续任务使用新内容；删除前需先停用或启用另一份，再确认删除。

## 编辑提示词与默认更新

“提示词管理”按公共、主 Agent 和平台目录选择文档。平台条目内包含来源插件说明和角色提示词，可折叠；各文档分别保存，切换保留当前页面中的草稿。

页面会说明已保存文档的状态：

| 状态 | 后续默认升级时的行为 |
| --- | --- |
| 当前跟随默认提示词 | 使用当前应用或来源插件提供的默认正文 |
| 当前使用自定义提示词 | 保留主人保存的正文，直到明确恢复默认或另行保存 |

从未编辑的基础提示词，即使存储里仍有过去版本的默认副本，也会在读取和已保存组合中使用当前代码默认；这个读取不写库。来源插件的默认更新同样生效。应用更新不会自动覆盖自定义正文；只把自定义正文改成与当前默认相同，也不等于恢复默认的跟随状态。

编辑后点击“保存提示词”才保存；正文完全相同且版本有效时不产生额外写入。保存的配置在 Agent 开始下一项任务时使用，已经执行的任务继续使用开始时快照；正常保存不重建原生会话或改写历史；本轮主人另明确授权清会话，之后创建新UUID，人格身份保持。

## 显式恢复一个文档的默认

1. 在“提示词管理”选择需要恢复的具体文档，先确认当前草稿和已保存状态。
2. 点击“恢复默认”。确认区可展开“查看当前默认内容”，查看这次准备采用的正文。
3. 选择“恢复默认并保存”。此操作恢复当前文档，并放弃该文档未保存的正文修改；其他提示词、人格和草稿保持。
4. 页面显示恢复成功后，该文档重新跟随以后的应用或来源插件默认更新。

已跟随默认且没有未保存修改时，无需再次恢复。有未保存修改时，恢复可用于放弃当前文档草稿并重新显示默认；后端已经处于跟随状态的请求仍只读，不增加版本或写入。

恢复后的文档版本继续递增，不回到0。旧页面或旧请求不能利用恢复操作覆盖新内容，正文恰好相同也不能跳过版本检查。来源插件已停用但仍在目录时可以编辑或恢复，启用后才用于相应任务；来源已卸载或不可用时保留已保存记录，恢复来源并重新读取后再操作。

这项操作只作用于所选提示词，不重置人格、账号、连接、其他设置、投递队列、动作账本或会话。

## 查看已保存组合与处理冲突

“查看已保存的组合”读取当前各层配置和启用人格，不启动模型。主 Agent 顺序为通用前置→主规则→启用插件说明→同一人格；子 Agent 顺序为通用前置→子代理前置→类型规则→同一人格。没有启用人格时明确显示空共享层。

预览使用已保存主人层内容，未保存草稿不会加入组合。DSH运行时把必需主分流／委派／联系／自主规则合入主唯一complete provider，子会话自主规则合入子唯一complete provider；普通section会被complete抑制，不能只检查编辑器预览或工具注册。需核对本地模型实际request.system，并保持owner／persona／子类型隔离。仍支持6种作用域和9个可信变量，编辑器会显示当前范围的合法变量；未知或越范围变量需要修正后才能保存。替换后的变量值不再次解释为模板或规则。

遇到版本冲突时，页面保留原草稿与保存版本，先重新读取核对；有草稿时会确认是否放弃，读取失败仍保留原稿。请求中断或结果未知时也先重读确认，避免反复提交。存储格式不受支持、损坏、容量超限或写入失败时，不会用空配置覆盖原数据。旧 schema 不自动迁移，请按[当前格式边界](../decisions/ADR-0015-默认不兼容旧版.md)处理。

## 人格、记忆与自主安排

人格可以影响兴趣、表达和授权范围内自主活动的选择。真实经历以当前上下文与实际可用记忆为依据；模板不会安装记忆插件，记忆记录也不改写固定人格或授予工具权限。

主 Agent 收到子 Agent 回执后，可以依据真实结果继续当前工作或在有效授权内再次委派，再判断接下来继续、休息或等待。回执未知时先核对，不自动重复发送。当前任务完成不代表已经安排下一次活动。

DSH 通过 `eating_activity_state` 读取当前安排和版本，再用 `eating_plan_activity` 登记 `active`、`sleeping` 或 `waiting`。`waiting` 不产生定时自主机会，收到新消息可以处理，但处理后不会自动变成 `active`；AI 希望继续自主活动时需通过现有工具重新安排。正文说“稍后继续”或把计划记入记忆，都不会实际安排唤醒；主人对定时机会的暂停、联系策略和限额仍须执行。

主Agent负责整体安排、轻量分流与必要协调。当前普通聊天／问答／生图优先eating_handle_conversation，主先理解请求和事实充分性，再传context_ref、显式mode及必要context_notes；verify只读核实回报，reply子结合原话、历史、可披露事实与同一人格自主组织回复、选工具并执行，main不预写完整文案或未经核对的能力事实。eating_delegate_task用于明确执行任务或用户明确逐字内容，固定reply。跨私／群先eating_list_contact_targets，再以返回id作为target_id，连同task／mode调用eating_contact_target，自动启动／恢复对应受限子，无需新入站。群context不授权私聊或跨目标旧资源；子scope不足交回main选执行者，真实目标回执分别核对。名单不扩大工具权限。

已启用且connected的功能型capability／direct MCP新来源默认all，全部当前及未来工具／类型开放；主人可保存custom来源例外或原生toolAccessOverrides并恢复自动，默认开放不删除配置功能。按[ADR-0036](../decisions/ADR-0036-功能插件与Harness原生功能默认边界.md)，新Harness原生feature仅time默认开启，既存主人选择保持；verify子阶段原生工具完全不挂。Eating专属官方permission默认danger-full-access／approval never；升级不自动reset主人自定义提示词或人格。

`enabled`／`ownerPaused`控制Eating无输入时的定时机会，不冻结main其他能力；原生Schedule不再受Eating自主周期人工阻断。普通有输入轮次仍可联系获准目标；真正自主机会取消则撤销该轮许可。当前 turn 结束、abort、销毁、运行时停止或联系策略保存后，旧许可失效；所有联系任务共用 `maxContactsPerHour`，未知不重放。当前边界见[ADR-0033](../decisions/ADR-0033-主Agent当前轮次联系权限.md)，配置见[自主运行配置与查看](自主运行配置与查看.md)。

人格模板与默认生命周期见[ADR-0027](../decisions/ADR-0027-人格模板与默认提示词生命周期.md)，当时验证保留在[历史报告](../reports/2026-11-02-人格模板与默认提示词验证.md)。当前会话自主与可配置默认见[ADR-0035](../decisions/ADR-0035-会话代理自主处理与默认开放可配置.md)，实际验证／清理与部署见[本轮报告](../reports/2026-11-02-会话代理自主处理与默认开放可配置验证清理报告.md)。脚本模型回环只证明预设调用链可执行，不证明真实LLM必定自主选同一路径。旧联系阶段证据保留在[历史报告](../reports/2026-11-02-主Agent当前轮次联系权限验证.md)。
