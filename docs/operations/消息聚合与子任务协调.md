# 消息聚合与子任务协调

设置 → 消息投递：聚合窗口默认10秒，可设置0–300秒；第一条消息开始计时，后续到达不重置。设0立即交接。窗口到期时各会话按接收顺序整批交接，账号/目标/图片权限保持隔离。

“忙碌时追加消息”默认开启。主Agent执行中也能可靠接收新批次，在下一步读取后判断处理方式；已有模型请求和外部工具不会被自动中断。关闭则在队列等待空闲，原消息仍保留。队列达到配置容量时按主人选择的溢出策略处理。

委派返回running和taskId表示已启动，完成后主Agent收到结构化结果通知。它可用eating_task_control的list/status查看任务，message给对应子Agent补充当前会话消息或说明，interrupt停止后续执行。Eating不自动判断两批话是否属于同一个任务。中断不能撤销已经发出的消息或已完成的工具动作；unknown必须先核对真实结果，不能直接重发。

配置、入站记录及接收状态由Host管理；聊天历史仍由原生Harness持久化。当前格式不接受旧quietWindowMs/maxWaitMs/maxBatchMessages/batchTargetBytes。已有实例更新见[ADR-0058](../decisions/ADR-0058-固定聚合窗口与主Agent异步协调.md)，需显式停机备份和转换，不要清空会话或重新初始化插件。
