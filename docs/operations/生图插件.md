# 生图插件使用说明

生图插件是独立的 capability 插件，ID为 image-generation，使用 OpenAI Images API 文生图请求。它有自己的配置、任务和图片资源，不读取QQ、表情包或Harness的私有配置。

## 配置服务

在“插件”找到“生图”并打开面板，配置以下项目：

| 字段 | 含义 |
| --- | --- |
| Base URL | 服务的API根地址，例如 https://api.openai.com/v1。插件保留路径前缀，再追加 /images/generations |
| API Key | 生图服务自己的凭据，单独私有保存；留空保持旧值，明确清除才移除，不回显 |
| 模型 | 填服务实际支持的生图模型名，不依据聊天模型列表猜测 |
| 超时 | 一次生成及结果读取允许等待的时间，默认180秒，可设1～600秒 |
| 尺寸、质量 | 可选。空值让服务自行决定，填写后按原值发送，不保证所有模型支持相同值 |
| 返回格式 | 可留空，或明确选择 b64_json／url，需符合提供商与模型的实际支持 |

固定每次生成一张图。仅兼容聊天接口的服务不一定支持Images API；此插件不会自动切换到Chat Completions、Responses或其他生图协议。服务返回Base64图片或图片URL均可处理，下载图片时不传API Key或Cookie，不跟随重定向。

保存或连接只检查本地配置，不会偷偷生成图片，也不能据此判断服务认证、模型或余额已经验证。点击明确标注可能计费的生成按钮，才会实际请求提供商。

## 手动生成

填写画面描述后点击“开始生成”。任务被接受后显示任务编号和状态，后台处理，页面仅在可见且有活动任务时更新状态。可以离开面板，回来后查询任务和结果；这不会自动再生成。

- queued／running：已提交或正在执行，尚无成功图片。
- succeeded：图片已取得并保存到本插件资源库。
- failed：服务明确拒绝或任务确定失败。
- unknown：超时、断网、取消或重启后无法确认提供商结果，可能已经计费，不能自动重试。

重复同一个request_id及相同参数会返回原任务，不会再次扣费；改参数不能复用原ID。每次只运行一个任务，超容量时在生成前拒绝。结果未知时先去提供商核对，不能把重新生成当成无成本刷新。

图片资源列表只读元数据，单项点击才取图片预览。预览在页面隐藏、离开或取消时撤销临时Blob。语言切换保留描述和配置草稿，不重新提交生成。图片归档保存在插件数据目录，卸载插件保留配置、任务及资源。

## MCP工具

在“MCP”中选择生图服务，再选择允许使用的代理类型和工具。安装本身不自动给任何Agent生图权限；生成可能计费，应由主人选择授权。

| 工具 | 用途 |
| --- | --- |
| image_generate | 用稳定请求ID提交一次文生图任务，返回jobId，尚不代表生成成功 |
| image_job_get | 查询任务，可有限等待状态变化 |
| image_jobs | 分页查看任务状态 |
| image_list | 分页查看已生成图片的元数据 |
| image_get | 读取一张图片预览及可发送的资源引用 |

AI应提交后用image_job_get核对最终状态，成功后再image_get获取实际图片。已接受的后台任务不会因子Agent正常回合结束而被取消，后续可由获准的主Agent或主人查询；撤销工具权限后旧Agent不能继续查询/取图。停用插件会中止其等待并报告未知，不代表提供商已撤销计费。图片返回MCP标准image块，模型若要看图还需Harness启用并实际支持图片输入；纯文本模型也可读取任务状态与资源元数据。

资源引用形如 eating-asset://image-generation/<assetId>，通过宿主公开资源服务交接。生图不会自动发QQ，也不会自动收藏到表情库。本轮按用户要求不处理OneBot部署和发送链路，生成成功与通讯发送成功分别核对。

## 当前边界

第一版只文生图，不提供图生图、蒙版、批量生成或在线模型市场。当前公开图片资源接口每张最多5MiB，插件依此校验；任务最多500个、图片最多500张、总图片256MiB，列表默认20条、最多50条，提示词最多12000字符。容量不是提供商的计费配额，图片原始大小限制也不是OpenAI官方协议的统一限制。

配置及库采用各自严格schema1，版本冲突拒绝覆盖。未确认的任务不跨重启重发。用户自己的生图Base URL、Key和模型需自行填写，自动测试使用独立本地夹具，不使用真实付费凭据。
