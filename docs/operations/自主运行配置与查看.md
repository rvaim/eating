# 自主运行配置与查看

打开设置→自主运行。应用0.16.0提供“概览／运行设置／主动联系”；当前源码DSH0.14.0提供同一主会话的原生活动机会、AI一次性定时任务与当前轮次联系许可，QQ0.13.3提供精确主动联系范围和受信已加入群目录。其他Harness未提供服务时会显示不支持。当前默认能力与目标选择按[ADR-0034](../decisions/ADR-0034-主Agent自主决策与功能能力默认开放.md)，实际验证和部署见[本轮报告](../reports/2026-11-02-主Agent自主与默认能力验证部署报告.md)。

## 开始使用

1. 在概览点击“开始设置”，进入运行设置并定位“允许自主运行”。未开启时不再显示一组无法操作的运行按钮。
2. 勾选允许自主运行，先设置常用的活动间隔和每小时轮次。连续时长、单轮时长、失败阈值、联系任务额度和重启恢复在“高级设置”中展开修改。单次连续活动上限只累计实际自主活动时间；AI 进入休息或等待后开启新的活动段，睡眠和等待不会消耗该额度。
3. 有修改时，底部保存栏在三个页签都可用。Harness就绪且允许自主活动时，可选“保存并开始”或“保存并继续”；它依次保存配置和恢复活动，可能产生模型费用。选择“仅保存”只保存并暂停。Harness未启动或正在关闭自主模式时，显示“保存更改”，保存后不发起模型任务。
4. 如果Harness未就绪，页面给出“打开Harness”入口。先在原连接页启动它，再按保存的安排运行；界面不会通过查看或刷新启动模型。
5. 只调整已有运行状态时，按当前状态显示暂停、开始或提前唤醒。存在未保存更改时先处理草稿，避免把旧配置误当成新配置运行。

`enabled`（允许自主运行）和 `ownerPaused`（主人暂停）只控制没有输入时的定时活动机会。关闭或暂停后，主 Agent 仍可处理QQ群／私聊、原生输入或目标续行，并在当前普通轮次联系获准对象；真正的定时自主机会取消时，该轮联系许可一同撤销。

配置保存、恢复仍是独立的后台操作，组合按钮只是明确串行调用原有接口。保存成功但恢复失败时，会明确显示“设置已保存，但尚未成功恢复”，并要求刷新核对；不会假装全部失败或自动重复保存/启动。

## AI 定时任务

AI 在自主运行开启且未暂停时，可以给自己安排未来的一次性任务消息：先读取概览中的 `agenda.revision`，再调用 `eating_schedule_task`，填写带时区的 `due_at` 和任务内容。到点后任务作为同一个主 Agent 的自主机会出现，不是主人指令，也不会绕过主人暂停、自主额度、运行时和周期限制。Eating agenda只支持一次性任务，不支持每日／每周重复。main的原生DSH Schedule保持官方语义，不再被Eating自主周期人工阻断；此处暂停只管Eating机会／agenda，不承诺停止全部原生提醒或目标。

“概览”会列出待执行的 AI 定时任务及时间，可逐项“取消任务”。取消只阻止尚未到点的任务，不会撤回已经进入会话的自主机会。任务到期并进入会话后从列表移除；进程在投递和模型读取之间崩溃属于 unknown，不保证恰好一次。

## 主动联系模式和对象

主 Agent 在QQ群／私聊、原生主输入、目标续行或定时唤醒的当前轮次，都可自主选择联系获准对象，无需对方先发私聊。它先判断实际行动目标：当前会话查询／回复使用eating_delegate_task及真实context_ref；跨私聊／群聊先list当前对象再contact，自动启动／恢复目标受限子，不要求新入站。群context不能当作私聊授权；某子scope不足由主选择其他执行者，群成功不等于私聊成功。见[ADR-0033](../decisions/ADR-0033-主Agent当前轮次联系权限.md)。

“主动联系”只选择一种模式，同时作用于私聊和群聊：

- 全部放行：允许当前连接账号的好友和已加入群，收起名单选择区。
- 白名单模式：只允许所选私聊对象和群聊；空白名单禁止全部对象。
- 黑名单模式：禁止所选私聊对象和群聊，其余好友和已加入群允许；空黑名单等于全部放行。

在私聊／群聊分类中搜索名称或号码并勾选对象，两个分类共用一份策略。切分类、关键词、模式和语言不丢已选项；全部放行下暂时收起名单，切回后仍保留选择。多个账号时先选账号，单账号直接显示身份。列表可滚动，已选对象集中显示，可逐项移除或清空。

“手动添加号码”支持每行一个号码，也可逗号/空格分隔。白名单私聊可明确指定精确账号；群聊必须是当前账号已加入的群。目录通过真实OneBot好友/群列表读取，只读查询不会暂停或修改自主活动，也不调用模型；较慢的私聊读取不阻止切换群聊。

工具权限在原机器人→代理与权限中管理，此页只决定联系对象。全部放行或名单模式不授予新的工具；具体类型可用工具由后台原权限检查决定。

“保存联系策略”单独保存，先核对策略和活动revision，再暂停定时活动并撤销旧联系任务许可。存在名单草稿时先保存或撤销，再开始/唤醒；未知结果先刷新核对，不重复提交。后台列出/发起任务均按当前账号、目录、模式和工具权限解析；旧轮次许可与MCP不能继续发送，后续任务须重新准入。现有文件不迁移，不改连接、Key、人格或历史。对象模式见[统一策略决策](../decisions/ADR-0025-统一主动联系名单策略.md)，当前许可边界见[ADR-0033](../decisions/ADR-0033-主Agent当前轮次联系权限.md)。

## 信息与控制

概览优先显示实际运行状态、可执行的下一步、AI的安排/说明、下一时间、本小时自主轮次与联系任务用量、最近结果。历史按时间倒序；诊断代码、连续失败、周期编号/截止和其他运行细节在“更多运行详情”展开。工作内容、工具输出和完整会话仍在官方“打开DSH Web”入口查看。

- 暂停运行：阻止新的无输入定时机会，中断当前真正的自主轮次并撤销该轮许可；普通有输入轮次仍可按联系策略工作，不删除安排或会话。
- 开始运行：恢复当前已保存安排。错误时先核对最近结果，AI原先安排的休息/等待仍保留。
- 立即唤醒：仅在休息/等待时显示，把安排改为active并提供机会，仍受忙闲、外部消息/原生目标优先和额度约束。
- 重启后恢复：主人选项，仍保AI休息/等待。中断周期结果未知时仍须核对，不自动重放。

可见页面每5秒读取状态，也可手动刷新；页签、语言切换和字段编辑不触发模型调用。未保存草稿不被状态轮询覆盖。键盘焦点在窗口旋转/缩短、吸顶页签和保存栏出现时保持可见；保存、撤销或收起编辑后有明确的焦点落点。

## 输入错误与配置冲突

字段失焦时就近显示具体错误并与输入关联。保存有误时，错误摘要获得焦点，每项链接可定位到对应字段；高级项和联系人会按需展开。错误随语言即时更新，不要求凭页顶泛泛错误猜字段。

另一个位置更新配置时，当前草稿保留，页面展示最新设置。先核对最新值，再明确保留草稿继续编辑，或撤销草稿载入最新配置。操作结果未知时，先刷新核对，不重复点击。

## 未知联系任务和实际边界

联系许可因轮次结束／取消或策略变更撤销时，OneBot可能已经接受动作，结果不明的任务保留unknown；新runtime也把遗留pending转unknown，不恢复旧许可或重发。概览显示待核对任务；检查官方会话、真实动作回执或实际目标后，再点击“已核对此任务，解除阻塞”。确认不重发、不删除动作防重账本。

小时联系上限 maxContactsPerHour 统计所有联系任务，普通输入、目标续行和定时来源共用额度；一个任务内可调用获准工具多次，当前没有账单级金额预算。后台停止、关机或休眠期间不能按时活动，恢复只合并当前需要的机会，不补跑每个错过时间。

AI通过eating_activity_state读取revision，再用eating_plan_activity登记active、sleeping或waiting；需要未来一次性任务消息时用eating_schedule_task，取消用eating_cancel_scheduled_task。文字“我要休息了”不直接改变调度。功能型capability／direct MCP在启用且connected时全部当前及新增工具默认对所有Agent开放，无授权勾选。新main原生feature按平台默认开，含文件写／编辑和网页搜索；time保主子、其他子原生默认保持。网页Fake-IP获取问题仍是独立未修事项。缺provider／Key报告真实未配置；Eating暂停不冻结main其他能力。长期自主内容质量与费用需主人后续观察，实际request.system断言证明规则送达，脚本模型回环只证明预设执行路径，不证明真实LLM必定自主选择。
