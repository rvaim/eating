# 配置 SSH 别名

本次交付的是供用户自行运行的[本机配置脚本](../../scripts/配置SSH别名.py)，仅依赖 Python 标准库；尚未运行真实 setup、未读取或修改用户 SSH 配置、未连接服务器，也未 commit／push。隔离验证证据见[验证报告](../reports/2026-11-03-项目外SSH别名脚本验证报告.md)，隐私决策见[ADR-0042](../decisions/ADR-0042-项目外SSH配置与部署隐私.md)。

## 运行与输入

在项目根目录的本机交互式终端执行：

```bash
python3 scripts/配置SSH别名.py
```

脚本不接受管道输入；终端无法提供隐藏输入时会停止。依次填写：

1. SSH 别名：普通可见输入，字母开头，后续可含字母、数字、横线、下划线，最多64字符；请选择未使用、且不携带真实服务器信息的名称。
2. 服务器 IP 或主机名：通过 `getpass` 隐藏输入，只填地址，不含协议、用户名或端口。
3. 登录用户名：通过 `getpass` 隐藏输入。
4. SSH 端口：通过 `getpass` 隐藏输入，回车使用22。
5. 已有私钥路径：通过 `getpass` 隐藏输入，可留空；填写时使用绝对路径或以 `~/.ssh/` 开头的路径，文件及其解析后的目标必须在项目外。脚本只检查和引用文件，不读取私钥内容。
6. 写入确认：输入 `yes` 才写入，其他输入取消；确认前取消不会写入配置。

私钥路径留空时，后续由 SSH 使用 Agent、现有默认配置或登录时的密码提示。脚本不询问或保存登录密码，不生成、上传或替换密钥。隐藏输入只避免终端回显，地址、用户名、端口和可选密钥路径仍会保存在项目外的 SSH 配置中。

## 写入位置与保护

确认后，脚本新增 `~/.ssh/config.d/eating-<alias>.conf`，在 `~/.ssh/config` 开头加入指向该独立文件的 `Include`，原主配置正文按原字节保留。主配置和新增配置权限为 `600`，`~/.ssh` 与 `~/.ssh/config.d` 目录权限设为 `700`，已有目录权限也会相应收紧。

脚本拒绝项目内的配置目标或私钥目标，拒绝 SSH 目录、主配置和目标配置本身为符号链接；私钥引用可以是符号链接，但解析后的目标仍须在项目外。独立配置已存在或主配置已有同名别名时拒绝覆盖。填写期间主配置发生变化时停止并保留该变化；主配置替换失败时清理本次新增配置和临时文件。

已有 Include 文件里的同名或通配规则仍可能影响 SSH 行为，脚本不会全面扫描或改写这些文件。遇到重复、符号链接或并发修改提示时，先在项目外自行核对，勿通过把真实配置复制到项目中排查。

## 给已有别名导入PEM私钥

已有别名但需要使用下载的PEM／OpenSSH私钥时，在本机终端运行：

```bash
python3 scripts/导入SSH私钥.py
```

依次填写已有别名、私钥完整路径（隐藏输入，可拖入文件），输入 `yes` 确认。脚本把文件原字节复制到项目外的 `~/.ssh/eating-<alias>.pem` 并设为600，不删除下载原文件；只替换对应Host段的IdentityFile／IdentitiesOnly，保留地址、用户名、端口及其他Host，修改前在原配置同目录留600权限备份。它支持SSH主配置中单独的Host段，或别名配置脚本创建且已被全局Include引用的独立文件；共享多别名Host段、重复或未接入的独立配置不自动处理。

导入只为本机复制而读取密钥内容，在内存检查匹配的私钥头尾，不把内容、文件路径或真实连接值输出／写进项目，不上传或自动连接。目标已存在不同密钥、项目内路径、配置符号链接或填写期间并发改动均拒绝。目标密钥完全相同时可复用。复制成功不代表私钥已由服务器授权；若有私钥口令，在本机用ssh-add加载后再测试。

## 用户自行测试与隐私边界

脚本成功后只提示用户自行执行连接命令；例如以下 `example-alias` 仅为示例占位符，应替换为本机选择的别名：

```bash
ssh example-alias
```

首次连接时自行核对服务器主机指纹；需要登录密码时只在 SSH 提示中输入。配置写入成功不代表网络、认证或部署成功，脚本不会自动连接、安装、部署或重启服务。

真实 host、端口、登录用户、主机指纹、密钥内容或位置、密码／Token、跳板机、部署目录及别名到目标的映射均不得进入项目，Git 已忽略的文件也不例外；文档、报告、测试、截图和提交说明同样只能使用明显的示例占位符。真实值只在项目外的本机 SSH 配置、凭据存储或私有部署配置保存，不在聊天或项目中粘贴完整 SSH 配置。后续服务器操作仍以用户当时明确授权为准，本脚本不替代部署。
