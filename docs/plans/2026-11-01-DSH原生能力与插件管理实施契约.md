# DSH 原生能力与插件管理实施契约

日期：2026-11-01，Asia/Shanghai。授权：用户要求把 DSH 原生能力和插件管理一次完成，不分阶段交付。

## 目标与边界

在 Eating 的 DSH 独立面板管理原生能力、代理范围、配置和 DSH 插件，复用系统 DSH 的 Cordis 插件、Agent 作用域、PluginManager 与 ConfigEditor。原生 Web 保持官方页面与正常操作；数据仍只使用 Eating 的 DSH_HOME、DSH_AGENTS_HOME、runtime-home 和工作区。不得读取或修改主人主 DSH 的 Profile、密钥和会话，不部署真实数据、不替用户安装或启用实际外部插件。

原生工具按当前主代理和目录中的子代理类型分别授权，时间上下文保留当前默认行为。实例级插件与代理工具授权是两件事：启用插件不会把它的全部工具自动授给所有代理。插件贡献的工具以精确名称和 schema 指纹授权；新增或变化的工具须重新选择。Eating 的通讯 MCP 授权继续来自 Host，插件页不能绕过 QQ 会话范围。

## 实施接口

- 新增独立 schema1、revision/CAS 的 native-capabilities.json；连接、图片能力、会话和绑定文件保持各自当前格式。新文件缺失时采用当前完整默认配置；损坏或旧格式拒绝并保留原文件。
- 原生能力按独立 Agent scope 加载官方模块。检查实际可解析模块、依赖、配置与激活结果，区分已保存、待启动、预设就绪、实际挂载和加载失败。
- 系统 DSH 内的管理桥只监听随机 loopback 端口，以本次随机 nonce 和令牌鉴权，严格限制请求形状、大小、超时。URL 与令牌不进入普通公开状态、日志或模型上下文。
- 已运行实例直接提供目录与观察状态。停止状态按需启动无模型回合、无会话创建的短生命周期 SDK 管理进程；和正式运行互斥，同一目录不允许并发写入。读取目录不连接真实模型或 QQ。
- 配置、启停、安装和卸载要求完全停止 Harness。通过官方 PluginManager 列出真实模块和 bundle，inspect/install/remove/enable 均调用原生实现；基础内核、Eating 桥和官方 Web 必需组件受保护。卸载只移除插件代码，保留资料。
- 任意插件的配置不回显保存的秘密；替换配置由主人显式提交，配置写入使用官方 ConfigEditor。安装预览与确认、冲突、失败和未知结果单独报告，禁止把保存或安装回执说成已经生效。

## 界面契约

沿用白绿主题和语义令牌，在现有 DSH 面板增加可切换的原生能力管理区。功能目录可搜索，展开后选择主/子代理范围并编辑配置；插件目录显示来源、版本、启用与实际激活状态，提供配置、启停、检查并安装、卸载。基础组件展示锁定原因。MCP 只展示现有挂载事实，不建立第二份授权。

### Direction contract

THESIS：主人能够把选择与实际生效逐项对照，目录、授权范围和状态在同一管理区完成。

OWN-WORLD：继承现有白绿界面、系统字体、语义令牌、轻分隔线和普通表单控件，沿用宿主固定视口与独立滚动。

STORY：读取真实目录 → 搜索并展开目标 → 选择作用范围/配置 → 独立保存 → 启动后检查实际生效；插件安装先检查再由主人确认。

FIRST VIEWPORT：原有连接配置和状态入口保持；管理区以标题、运行状态、搜索/分类和紧凑目录构成，展开区域承载配置，保存动作与草稿状态相邻。390px 下控件换行且不产生横向页面滚动。

FORM：既有设置面板的局部扩展；seed: none (unavailable)。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance。当前为既有界面扩展，不另建视觉系统或修改原生 Web。
