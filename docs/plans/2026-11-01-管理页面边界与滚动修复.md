# 管理页面边界与滚动修复

用户以截图明确指出原生能力二级分类不吸顶、右侧边界、基础组件显示开关随滚动、禁用动作无原因、批量授权缺失、插件详情返回位置、MCP宽屏边界及DSH双分隔线。范围涵盖DSH管理面板、自主联系人、插件和MCP，不更换白绿系统或修改官方DSH Web；保真实配置/权限/自主安排，不触发模型或真人消息，不提交/push。

## 已核对根因

1920×1080实测：主滚动区1512px、内容1258px，DSH轨道被`.dsh-panel > *`晚出现的1050px上限覆盖，轨道右端比1050px正文右端还少一个44px左边距。二级native-toolbar为static，列表底部滚出视口。runtime顶部边框与页签底边形成重复分隔。插件/MCP没有一致正文宽度上限，行内文字与操作被拉到宽屏两端；授权编辑又放在MCP三等分末列，形成额外狭窄列。

## 当前实现选择

- 主滚动区提供1200px正文边界和可用于全出血轨道的容器宽度；正文/列表/工具栏动作共用边界。导航表面可以铺满滚动区，内侧内容对齐正文，不对子元素无差别限宽。
- DSH一级轨道固定；原生二级分类/搜索/刷新及基础组件显示筛选成为一条固定工具栏，checkbox仅属于插件目录筛选。搜索/刷新/筛选不会随目录长列表离开。删除runtime紧邻的顶部边框，保有意义的组间分隔。
- 公共ui-sdk增加ActionButton：保原生disabled，悬停/键盘聚焦可读具体原因，Escape关闭；提示使用原生popover顶层，不被轨道/滚动裁剪。各页按真实条件给出未连接/未启用/无修改/需先停止/需读取/正在处理等原因，不给无关通用占位。
- 联系人、MCP和原生代理范围提供允许全部当前可用项及清空；操作只改草稿，保存仍是精确列表，不自动授权未来新工具。联系人0工具仍需选择至少一项或移除该联系人，不假装能保存无效授权。
- 插件详情返回列表放到页面顶部右侧，随全局页头保持可达；详情内容受正文边界约束。MCP授权用足整行，代理/工具编辑可比较，工具目录保持折叠。

## 方向与验证

THESIS：在宽屏和滚动中保持导航、正文、动作的稳定位置，禁用动作能解释，批量授权无需逐项重复。
OWN-WORLD：沿用现有语义令牌/字体/普通表单和轻分隔，不新建视觉世界。
STORY：选择分类→固定工具栏筛选→编辑当前范围→保存；禁用时得到具体下一步，返回列表始终在顶部右侧。
FIRST VIEWPORT：管理导航与读取/筛选在一致边界，宽屏动作不会远离所属数据，原生外层/内层轨道不重叠。
FORM：现有Operate界面修复，seed none (unavailable)。
FINISH：按ui-ux-pro-max与impeccable核验真实2560/1920宽屏、1440桌面、390窄屏及短横屏；鼠标/键盘提示、基础筛选固定、底部分类可切、批量授权只改草稿、保存条件不被绕过，重新构建并更新原5180/5181。无普通独立审阅代理，明确内联降级评审。
