# Eating 测试计划

首版前端已实际执行生产构建、65项业务单元、5项 Chromium 浏览器流程及截图检查；结果见[PoC账本](../research/PoC验证结果.md)。下列后台/Harness/安全和跨平台部分仍为未来计划，不因前端通过而宣称完成。

## 验证层级

| 层级 | 目标 | 典型场景 |
| --- | --- | --- |
| 文档 | 链接/中文命名、ADR 替代、阶段与证据一致 | 旧 DSH 唯一条款只出现在明确历史中 |
| 模块契约（未来） | 注册与依赖边界 | 重复 ID/版本冲突、两个平台独立增删、全部移除 |
| 生命周期（未来） | 真插件上下文的清理和恢复 | 缺依赖、重复启停、晚到响应、部分失败与资源释放 |
| 页面贡献（未来） | 前后端注册关联 | 自有面板加载/撤销、当前页被移除、后台失败、权限/版本不匹配 |
| Harness 适配（未来） | 真实能力、错误/证据与原生会话 | 模拟能力差异、DSH SDK 实测、后续第二真实实现 |
| 持久桥/恢复（未来） | 事务、确认与幂等 | 保存/准入/消费/平台回执丢失、模块停用积压 |
| 安全/故障（未来） | 审批旁路、进程/OS 边界 | Shell/文件/安装/页面执行、单模块崩溃/阻塞 |
| 自主性（未来） | 意义、自然停止和成本 | 行动/休息/记忆/唤醒/暂停；区分选择与异常 |
| 三平台（未来） | 真实分发与生命周期 | 干净环境、ABI、签名、托盘、退出、升级 |

不为文档改动新增应用测试；mock 通过不扩大成真实 QQ/飞书或 Harness 支持。不只在 root Context 测试后声称普通插件注入有效。Cordis 生命周期测试不能代替 React 页面实际加载，逻辑隔离不能代替进程或 OS 安全测试。

## 必须保留的验收

删除飞书模块时无需修改 QQ 或通用管理页，QQ 连接与公共服务保留；移除期间在途动作可核对，迟到响应不复活注册；重复启停无重复菜单/监听/定时器；共享依赖不被误删。若仍需全局重启，记录实际影响，不称无中断通过。

替换 Harness 适配器不修改通讯实现；支持状态（有支持证据/明确不支持/未知）与本次探测/调用失败分开，错误不能反推能力不支持。缺记忆/恢复/暂停等必需能力不伪造产品可用。

## 证据模板

实验 ID、日期/时区、执行者、关联需求/ADR；OS/架构、Host/模块契约版本、实际 Cordis 包/版本（若用）、Harness/适配器/SDK/模型与源码 SHA；配置/隔离路径；命令、输入、预期/实际、关键关联日志；失败/限制、重跑、清理、设计影响。

状态：未开始、执行中、通过、失败、结论不足。未执行不算失败，故障注入观察到预期错误也不算功能失败。只覆盖实际输入/版本。

## 确认与故障窗口

分别核对 Eating 保存、运行时受理、磁盘耐久、模型接纳/消费、终止/idle、业务动作和平台确认。无法观察写未知。DSH messageId/run/idle 只按其源码语义判定，其他运行时不复用名称假设。

注入点包括事件持久前后、回执丢失、模型/工具前后、平台完成未回、模块停用或清理失败、前端入口撤销、Host/连接器/Harness 分别退出、存储/模型/记忆离线、休眠/时区、多主控竞争。DSH Schedule flush 后 task put 前是 DSH 专属窗口。

## 安全与数据

独立测试账号/根目录/受限能力，不向真实联系人发实验消息、不执行真实付款或重要删除、不读改用户已有 Harness 凭据/配置。新增可执行能力不能借测试绕过批准。停用/卸载不默认删历史或其他模块数据。

本轮已安装前端/验证依赖并运行本地网页，未启动模型、Harness 或真实连接器。细目见[路线图](路线图与PoC计划.md)，实际结果见[账本](../research/PoC验证结果.md)；未来后台测试不继承前端结论。
