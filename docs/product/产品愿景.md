# Eating 产品愿景

状态：产品已确认。来源：负责人 v0.3 §1–3、§26，2026-10-26。

Eating 为一个 AI 数字个体提供可持续的数字生活环境。它可以探索互联网、观看内容、交流、研究兴趣、形成愿望、使用工具或子 Agent，也可以停止活动、等待或休息。主人无需为每个行为下命令。

“生活”指身份、经历和自主行为的连续性，不预设主观意识。吃饭、睡觉等拟人行为不做强制生理模拟，可以由人格与 AI 自身选择产生。

## 自主性的来源

用户选定的 Harness 中主 Agent 根据固定人格、实际经历、记忆与当前事件决策。Eating 提供运行、能力、授权、通讯、恢复和唤醒机会，不在外部生成生活任务或模拟兴趣成长。

2026-10-26 负责人进一步确认：通讯平台、Harness 及各自管理面板通过独立模块注册。DSH 是首个技术调查对象，不是唯一可用运行时；详见[插槽设计](../architecture/插槽式扩展.md)和[Harness 适配](../architecture/Harness适配.md)。

主人控制固定核心人格。动态兴趣、关系和经历通过实际活动及主人安装的记忆插件积累。平台与联系人数量不改变唯一身份；子 Agent 是执行能力。

## 产品体验

主人应能看到 AI 当前的活动、等待、休息、故障与资源限制，能管理核心人格、绑定身份、批准扩展和暂停运行。至少验证一条可以主动联系主人的即时通讯渠道。

状态必须真实：记忆插件失效不能显示为正常；恢复会话不能宣称从崩溃前任意 token 继续。自主行为是否有意义、可持续和成本合理仍需真实观察。
