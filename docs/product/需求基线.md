## 确认范围与限制

可安装多个适配器并允许用户选择；初期同一 AI 数据集一个活跃主认知控制者。具体单主 Session 实现仍待验证。跨 Harness 会话/记忆无损迁移、运行中热切换、多运行时并行和全部能力相同尚未承诺。

管理 UI 仍计划包括状态/时间线、交互、核心人格、主人绑定、通讯、扩展/授权、运行时诊断、模型与记忆配置。专属面板由模块贡献，通用导航不枚举全部实现；具体交互未设计。

## 技术建议不是产品事实

Cordis 仅优先验证候选，Tauri/Node/SQLite/React 等未最终锁定。DSH 是首个技术调查对象；Codex/Claude Code 等实际接口未核对。面板自注册要求真实模块，填写平台名称不能自动实现协议。

详见[插槽设计](../architecture/插槽式扩展.md)、[Harness 适配](../architecture/Harness适配.md)、[技术选型](../technical/技术选型.md)。
