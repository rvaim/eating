## 确认范围与限制

可安装多个适配器并允许用户选择；初期同一 AI 数据集一个活跃主认知控制者。DSH 已用一个稳定主会话和按账号／会话／类型绑定的原生子会话落实此边界，并完成本地重启恢复验证；其他 Harness 需独立验证。跨 Harness 会话／记忆无损迁移、运行中热切换、多运行时并行和全部能力相同尚未承诺。

管理 UI 已包括核心人格、动态分层提示词与预览、QQ 主人／管理员与按类型工具配置、模型获取／测试，以及手动原生会话父子树。会话读取不建设 Eating 历史存档，不启动模型或为看板增加轮询；应用既有 workspace 状态轮询不在此承诺内。专属面板由模块贡献，通用导航不枚举全部实现；长期记忆配置、桌面生命周期等未完成范围继续分别设计。

## 技术建议不是产品事实

Node／TypeScript、SQLite 与 React／Vite 已用于当前实现；Cordis 作为 Host 最终底座及 Tauri 桌面仍未选定／接入。DSH 已是首个真实适配器，采用独立官方运行时并完成本地原生验证；Codex／Claude Code 等实际接口仍需分别核对。面板自注册要求真实模块，填写平台名称不能自动实现协议。

详见[插槽设计](../architecture/插槽式扩展.md)、[Harness 适配](../architecture/Harness适配.md)、[技术选型](../technical/技术选型.md)。
