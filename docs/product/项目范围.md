# Eating 项目范围

更新：2026-10-26。负责人已明确开始首个验证版本，并选择 React + TypeScript + Vite 本地网页。**原“只写文档”限制在本轮前端 PoC 范围内解除。**

## 当前实现范围

全局侧栏第一“概览”、第二“机器人”；机器人页内平台分类来自注册表，平台插件自行提供配置面板。QQ/飞书默认示例与可登记微信，支持中文表单、格式校验、本地保存、移除/重新注册与空/错状态。

可以安装当前前端工程和验证所需依赖、启动独立本地服务、执行构建/单元/浏览器/视觉检查，并维护文档。负责人已通过中文方案页选择“浅色标签”。使用与限制见[首版说明](../research/首版平台验证说明.md)。

## 不在本轮范围

真实平台登录/收发、模型或 Harness、长期记忆、Cordis Host/动态第三方包安装、可信主人后台审批、可靠消息队列、OS/进程隔离与 Tauri 桌面打包。用户主 DSH 和当前 GUI 不修改、不替换。

浏览器中已存在的示例注册不代表安装新的网络代码，不保证模块权限隔离；保存配置不代表平台连接成功。全前端 PoC 通过不提升其他阶段为通过。

## 保留的产品方向

唯一 AI 身份，由用户选择 Harness 负责认知，模块独立增删/注册面板，可信新增能力批准，至少一个未来真实主人渠道，独立 UI 与后台生命周期。单主 Session/记忆迁移/热切换仍待验证或未承诺。

第一版不要求多设备并发、自动切换、所有通讯平台、插件市场或生理模拟。最终桌面框架、Host/插件底座/存储尚未因此冻结。
