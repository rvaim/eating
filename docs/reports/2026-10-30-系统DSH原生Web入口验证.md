# 系统 DSH 原生 Web 入口验证

日期：2026-10-30，Asia/Shanghai。插件：DSH 0.7.0。决策：[ADR-0018](../decisions/ADR-0018-系统DSH原生Web与看板移除.md)。

## 本次交付

用户要求删除 DSH Harness 插件内的会话看板，改成按钮打开官方 Web；在确认复用系统安装、无需另外安装运行时或 Web 包后授权继续。

- 删除自有 SessionDashboard、SessionRecord、专用 CSS、session-view 和 list-sessions／read-session 管理入口；不保留兼容入口或备用看板。
- 配置页去掉页签，在状态栏提供“打开 DSH Web”。仅插件启用、进程连接、SDK 与 Web 均就绪时可用；操作中、隐藏或状态不确定时禁用。
- SDK 和官方 Web 共用同一个 Eating 专属系统 DSH 进程及原生会话。Web 配置保留于自身 Profile 可写层，旧设置不覆盖；现有主子权限、MCP 图片、时间上下文和持久 ACK 保持。
- 复用系统已有官方模块与前端，不下载 DSH 或 Web。构建时的 YAML 库来自已存在的本地缓存（离线链接，下载数为 0），编译进插件，不要求用户另装工具。
- 官方界面、主题、侧栏、输入框和正常操作保持原样，无 Eating 客户端注入或自定义只读访问层。
- 普通状态仅返回 nativeWeb.ready；用户点击时按需返回鉴权 URL 与原生根 ID。URL 不进入普通状态、模型上下文、React state 或浏览器本地存储；新标签关闭 opener、禁发送 referrer，迟到请求和空窗口会清理。
