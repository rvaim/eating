# 生图单图编辑验证

日期：2026-11-01，Asia/Shanghai。范围：image-generation@0.2.0 的单图编辑、受控图片来源、面板上传及任务展示。用户确认使用 Magpie 中转的生图模型，并会通过 QQ 或其他平台会话插件发图给 AI 修改。

## 实现

- `image_generate` 新增可选 `source`：`{kind:"received",messageId,imageId}` 读取当前会话已授权消息图片；`{kind:"asset",assetId}` 读取本插件已有生成图。没有 source 时保持原文生图。
- owner 面板新增“参考图（可选）”上传、预览和移除；`manage.generate` 新增 `source={kind:"upload",data,mimeType}`。
- provider 在有 source 时以 multipart 调用 `<baseUrl>/images/edits`，字段含 `model`、`prompt`、`n=1`、`image`；无 source 仍调用 `/images/generations`。
- 任务保存 `source` 摘要（来源类型、媒体类型、字节数、assetId 可选）和内部 `sourceHash`；幂等哈希包含参考图 SHA-256，任务、提交账本和 UI 不保存图片 payload、原始消息引用或签名 URL。
- 任务 schema 仍为 schemaVersion 1，新增可选字段；旧文生图任务没有 source 仍可读取，不迁移、不重写、不删除。

## 边界与未验证

- 只支持单张参考图、无蒙版、无多图参考、无批量编辑。
- 只实现 OpenAI Images `/images/edits` 兼容路径；其他提供商的自定义 JSON 参考图协议未适配。
- 真实 Magpie 验证走面板上传来源；QQ 收到图片的路径由 plugin/Host 回环测试覆盖，未用真实 QQ 消息做本次验证，未向真人发送任何消息。
