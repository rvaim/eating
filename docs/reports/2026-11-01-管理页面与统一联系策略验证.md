⚠️ DEGRADED: single-context。当前没有普通独立审阅代理入口，本轮按impeccable做内联收尾评审，不冒充独立双代理审核。

2026-11-01，Asia/Shanghai。用户先以截图指出二级分类/内容边界/禁用反馈/MCP长面板问题，随后明确要求检查其他页面，并两次纠正主动联系对象策略：工具全选不是对象黑白名单，群聊独立规则也不符合要求。最终交付以一个“全部放行／白名单模式／黑名单模式”同时作用于私聊和群聊。

应用/Host/Web **0.13.2**，plugin-sdk **4.4.0**、ui-sdk **4.1.0**、plugin-core4.0.0，QQ **0.13.1**、DSH **0.11.2**、表情包0.1.1。仓库同时有独立生图单图编辑0.2.0工作，本轮保留其源码/测试/文档；原实例生图仍0.1.1，没有擅自替换该独立功能的安装版本。

## 最终行为

| 用户指出的问题 | 当前结果 |
| --- | --- |
| MCP每个服务展开后把页面拉得很长，没有二级目录 | 左侧固定服务列表，右侧一次只显示当前服务；授权草稿切服务保留，工具目录折叠/搜索/限高独立滚动 |
| 插件面板没有固定目录，返回位置不稳定 | 固定已安装插件列表，右侧当前插件面板；返回在全局页头右侧，滚动后仍可达 |
| 原生能力二级分类和基础筛选随滚动丢失 | 一级页签下固定二级分类、搜索、刷新和基础组件显示筛选，长目录底部可继续切换 |
| 右侧正文/轨道边界不一致，重复线 | 1200px正文边界；轨道铺满主区但控件对齐正文；移除DSH连接区贴页签的额外顶线 |
| 禁用按钮没有原因 | 原生disabled保持，悬停或键盘聚焦可读具体原因，Escape关闭，popover不被滚动裁剪 |
| 权限需要逐个勾选 | 联系权限之外的QQ/MCP/原生代理范围补明确全选/清空，仍只保存当前精确集合，不自动授权新工具 |
| 私聊与群聊分别建规则，名单和工具混在一起 | 一个统一模式，私聊/群聊仅为对象分类；从实际目录搜索/选择或手动号码，工具权限链接原代理页 |
| 切分类偶发PLUGIN_BUSY | 联系人目录作为独立只读接口，不进入修改锁，旧请求未结束也能读取另一分类；读后仍核对账号和插件身份 |

没有把上一轮“仅改宽度”的结果当成固定二级侧栏已经实现；没有保留群聊独立规则作为现行功能。最终契约是[统一策略ADR](../decisions/ADR-0025-统一主动联系名单策略.md)。

## 实现与权限

- [MCP页面](../../apps/web/src/pages/Mcp.tsx)及[样式](../../apps/web/src/pages/Mcp.css)：固定二级目录/单项详情；保留各项授权草稿、原revision与显式核对，不让刷新隐式推进CAS；工具目录搜索和内部滚动。
- [插件页面](../../apps/web/src/pages/Plugins.tsx)、[应用页头](../../apps/web/src/App.tsx)及[共享样式](../../apps/web/src/styles.css)：二级目录/顶部返回/一致边界；QQ、DSH、作者、设置及已安装能力面板共同核验。
- [公共禁用动作组件](../../packages/ui-sdk/src/action-button.tsx)：普通可用按钮直接返回原生button，避免新增包装破坏导航；禁用时提供有名/有关联说明的可聚焦包装和原生popover。
- [统一联系编辑器](../../apps/web/src/pages/AutonomyContacts.tsx)及[样式](../../apps/web/src/pages/AutonomyContacts.css)：单一模式、私聊/群聊分类、真实目录搜索、手动号码、已选对象、清空、冲突核对与单独保存。radio不受文本输入框100%宽/44px高规则影响，390px模式选项在一行。
- [DSH策略服务](../../plugins/harness/dsh/src/backend/proactive-policy.ts)：独立proactive-contact-policy.json/schema1，严格校验与CAS。新文件缺省为空白名单；不迁移或覆盖原autonomy/QQ/旧联系人或被否定的group-rules文件。
- [公开SDK](../../packages/plugin-sdk/src/autonomy.ts)、[Host](../../apps/host/src/app.ts)与[QQ](../../plugins/communication/qq/src/server.ts)：真实好友/已加入群目录，查询前后核对账号/实例/类型；只读查询不暂停、不保存、不请求模型。
- [DSH活动服务](../../plugins/harness/dsh/src/backend/autonomy.ts)与[任务准入](../../plugins/harness/dsh/src/backend/agent-control.ts)：列出/发起时重新解析统一策略；保存先暂停/撤权再提交，旧周期/MCP许可不能继续动作。工具集合沿用当前通讯代理权限，模型不能追加scope或改目标。

全部放行允许当前好友与已加入群；白名单只允许选中对象、空名单全拒绝；黑名单排除选中对象、空名单全放行。白名单手动私聊可明确指定精确号码，群聊必须已加入。同号私聊/群聊以及不同账号分别绑定，不能混用授权。

主要回归：

- [统一策略单元](../../plugins/harness/dsh/src/backend/proactive-policy.test.ts)：三种模式共同作用于两类对象、两种空名单、同号不同类型、手动私聊/已加入群、当前工具、账号离线/变化、非法/重复对象、CAS/损坏文件、异步名单变化与保存撤权。
- [实际Host/MCP回环](../../apps/host/src/agent-access.test.ts)：读真实协议夹具群/好友目录，签精确目标、拒绝别的群、保存后旧许可不再发动作；真实副作用只到本地OneBot夹具。
- [自主页面浏览器](../../tests/browser/autonomy-settings.spec.ts)：同一模式选私聊和群、切模式保选择、搜索/手动校验、双语/390px、冲突先核对，以及故意阻塞私聊读取时立即切群聊。
- [MCP回归](../../tests/browser/mcp-management.spec.ts)与[插件回归](../../tests/browser/plugin-management.spec.ts)：单项可见、二级栏固定、工具内部滚动/搜索、草稿保留、刷新不暗改CAS、顶部返回、窄屏轨道与禁用原因。

实图发现并修正了两处自动布局/行为断言不足的问题：文本输入框通用选择器错误覆盖radio，导致单选控件放大挤字；MCP窄屏样式优先级不足，添加按钮文字竖排。已修正根选择器/具体布局规则并补尺寸断言。真实目录读取先前经过修改锁，慢请求切分类出现PLUGIN_BUSY；已拆成SDK独立只读方法并用悬挂私聊请求验证群目录并行读取，而非自动重试掩盖。

ui-ux-pro-max的禁用状态/键盘导航/紧凑控件语义检索与impeccable craft-floor用于本轮核验；自动detect对最终联系编辑器、MCP、插件和公共动作组件返回 `[]`、exit0。OpenViking经验查询返回402，未取得经验内容，不把该不可用检索当验证证据。
