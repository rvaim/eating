## 已确认问题及修改

| 问题 | 当前行为 |
| --- | --- |
| 首次进入同时出现多项无法操作的运行按钮 | 未启用时给明确“开始设置”入口并聚焦允许模式；未就绪时链接原Harness连接页，休息/等待才提供提前唤醒 |
| 单一Harness仍占整行大选择框，状态/安排重复 | 单一实例紧凑显示身份；概览突出真实状态、AI安排与下一时间，诊断细节折叠 |
| 常用节奏与全部高级限制平铺，保存沉底 | 常用间隔/小时轮次优先，高级项折叠；有脏稿时保存栏跨页签可达 |
| 保存与开启需要用户记忆两组状态 | 明确“仅保存”和“保存并开始/继续”，仍顺序调用原configure/resume；第二步失败准确显示已保存但未恢复并先核对 |
| 联系人全部展开，常驻工具标识过密 | 摘要列表、一次编辑一项、添加聚焦名称、工具搜索/已选数量、按需显示技术标识，删除可撤销且保存后生效 |
| 错误只在页顶，键盘找不到具体输入 | 失焦内联校验，提交失败才聚焦错误摘要，链接打开相应高级项/联系人并定位字段；错误随语言更新 |
| 旋转/短窗口时聚焦输入可能被固定区域遮住 | 按真实页签/保存栏边界，在focus、ResizeObserver和窗口resize时调整主区滚动，375px与1280×420已测 |
