# 公网HTTP面板修复与保留数据更新验证报告

日期：2026-11-03。状态：源码修复及真实非安全HTTP隔离回归完成，最终全量与实际云端保留数据更新验证中。本报告不记录真实服务器地址、端口、目录、别名、Token或凭据。

## 已确认根因

用户重装QQ后，页面已识别插件及其版本，但进入机器人配置页显示“这个面板暂时无法打开”。对真实公网HTTP入口的只读浏览器检查确认：`isSecureContext=false`、`crypto.randomUUID`为undefined、`crypto.getRandomValues`仍为function；插件资源无加载失败、workspace返回200且QQ已启用。浏览器console明确为`crypto.randomUUID is not a function`。

QQ所有页签以hidden切换而不是卸载组件，尚未打开的工具测试组件也在初次渲染生成请求ID，异常因此使整个面板进入错误边界。前轮只用localhost隧道验收，localhost为安全上下文，且未覆盖真正公网HTTP下进入QQ面板；该检查没有覆盖用户现场条件。重装插件不能解决此平台API问题。

## 根因修复与范围

公开UI SDK新增`createRequestId()`，始终调用`globalThis.crypto.getRandomValues`填充16字节，设置RFC UUIDv4版本／variant位，生成36字符小写UUID，保留122随机位。没有randomUUID分支、Math.random、时间或计数器；安全随机源缺失或异常直接失败，不产生弱请求ID。

替换实际前端5文件共12处调用：Host Web活动记录、QQ工具测试、生图提交、DSH原生能力操作、记忆范围规则。保留每处原来生成时机，特别是QQ unknown不换号／不自动重发、生图同一意图重试复用ID，编辑为新意图才换号。Node后台的node:crypto UUID保持，未新增依赖或改变通讯授权、额度、配置schema、模型规则、会话或官方DSH Web。

应用／Host／Web0.17.5、UI SDK4.2.1；QQ0.13.7、DSH0.15.4、生图0.2.1、记忆0.2.1。表情包没有新随机ID调用，但共享SDK导出改变压缩UI产物ui/index.js字节，因此按严格封存不可变规则升0.1.2，功能保持，未覆盖旧版本产物。锁文件无变化，与前次已批准的依赖摘要相同；不安装额外软件，不配置HTTPS／网关／防火墙。

## 本地验证

公开helper11项测试覆盖真实16字节随机源、this绑定、UUID格式、version／variant及122随机位保留、不读取randomUUID、安全源缺失失败和源异常传播。SDK／工作区定向4文件33项通过。

新增`tests/browser/http-frontend.spec.ts`，Chromium将保留测试域名eating-http.test映射到127.0.0.1，禁系统代理及外流，使用真实HTTP、Token303入口Cookie和临时Host／数据／插件产物。每例实际验证非安全上下文、randomUUID不存在、getRandomValues可用；没有伪造浏览器API。

旧构建QQ与生图两例均复现TypeError，2项失败。修复后QQ／记忆范围／生图三例通过；QQ只连接本地协议夹具，不调用发送工具；生图提交在浏览器拦截、返回本地not-sent错误，确认三次提交中同草稿复用ID、修改草稿换ID，没有付费生成或发到Host/provider；记忆只创建未保存草稿，不连接服务。最终构建后三例再次通过，6.1秒；已实际读取QQ配置最终截图。

完整构建包含严格类型检查通过。两轮全量分别暴露QQ升级夹具和表情包HTTP管理测试硬编码旧版本，生产权限守卫未失败；已让测试读取当前真实产物清单、明确核对预览／安装前端版本，再构造下一补丁版本检验升级保数据，不放宽生产版本或完整性校验。表情包真实安装浏览器预览也同步读取真实清单版本。

最终明确设置系统DSH的全量回归：88文件通过、2文件跳过，**1743项通过、8项条件跳过，114.58秒**。另严格类型与真实非安全HTTP三例／表情包安装卸载重装保库一例联合浏览器回归 **4项通过，8.2秒**。前述旧版本夹具失败轮次保留，不将其写为全绿。
