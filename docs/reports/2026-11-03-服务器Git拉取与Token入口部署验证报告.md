## Token入口

新增显式EATING_LISTEN_HOST／PUBLIC_ORIGIN／OWNER_TOKEN配置：默认回环模式不变，外网监听必须同时提供规范Origin及高熵URL安全Token。根GET单token兑换独立随机入口Cookie，303清除URL中token，Cookie为Path=/、HttpOnly、SameSite=Strict，https Origin才添加Secure；不增加Basic、用户名、密码表单或额外依赖。

所有管理API、bootstrap、静态页面与插件资产都受入口Cookie保护；原API ownerSession及CSRF仍保留。两条MCP通道继续使用专属Bearer，URLToken或管理Cookie不能代替代理scope。重复／错误／非根Token拒绝，入口不能站外重定向；错误、workspace和普通日志不回显Token。

HTTP由用户明确选择，本应用不自行配置HTTPS。原生DSH Web保留其正式回环服务及鉴权方式，不把Eating公网入口可达等同为原生DSH Web已对公网开放。
