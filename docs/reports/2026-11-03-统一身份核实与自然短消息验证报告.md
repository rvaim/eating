# 统一身份核实与自然短消息验证报告

日期：2026-11-03，Asia/Shanghai。状态：源码实现、完整构建与隔离验证完成；未部署、未提交或推送。

## 需求与根因

主人要求修改提示词：所有群聊、私聊与主／子 Agent 都是同一个 AI 身份；私聊执行者缺少群记录时，不能据此否认自己在群中发过言。普通聊天要像正常人发消息，用自然短句，按意思分成少量独立消息，避免一大段报告。

已读源码确认：通用默认强调“共享人格不等于共享记忆”“我不在的时候，就是不在”，子层只说当前绑定会话和scope，缺少“局部未知不代表整体未参与”的直接约束。主层普通问答优先轻量交接，但未明确跨会话事实问题需要先核实再向原会话回答。现有“AI 女儿”模板虽说“平时说话不长”，没有覆盖主子运行时必要规则，也没有说明独立消息气泡与单条换行／消息段的区别。DSH 的 complete provider 会抑制普通section，仅改默认正文或另加普通section不足以证明真实模型收到规则。

截图中的具体回复来源与实际现场模型行为未读取，不能仅凭静态代码断定每条消息由哪个原生会话发出。本文记录代码根因、修改与隔离证据，不复制真实私聊正文、账号或历史。

## 实现

- 通用／主／子默认明确同一身份、局部记录缺口先核实、真实参与才是经历，保留真实来源与隐私授权。跨会话事实由主协调；只核实任务明确不向被查询会话发言；取回可披露的事实与证据范围后，由原会话子自然组织回复。
- 新增 DSH conversation-policy：共享身份与聊天表达规则、主协调规则、子核实规则。它们分别合入主／子唯一 complete provider；即使主人把基础／主／子／类型正文全部保存为自定义，必需规则也进入实际 system，同时保留主人正文、人格和角色隔离，不reset保存内容。
- QQ 私聊／群聊默认和插件主使用说明同步；AI女儿模板草稿增加按意思短消息指引，只影响以后套用模板的草稿，不覆盖已保存人格。
- 普通聊天先接眼前的话，一条一个意思，一条够就一条，确有几个意思时少量分发；不固定条数、不按字数或每句硬切、不刷屏。详细说明、逐字原文、代码和链接保持完整。
- 独立气泡由对应子 Agent 分别调用真实发送工具，每条使用不同且稳定的 request_id，顺序核对回执；未知时停止自动续发并交回核对。没有新增自动截字／切段发送器，也不把内部任务摘要当聊天原文。

本轮不实施前轮自主活动行为方案，不改自主节奏、waiting／sleeping、额度或当前主人联系名单；不放宽跨会话读取、记忆成员策略或披露权限。不修改官方原生Web或主人主DSH，不写真实配置／人格／历史，不部署或重启真实实例。
