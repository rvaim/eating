# 自主调度边界与可行性验证报告

日期：2026-11-09，Asia/Shanghai。主人要求修改调度边界，并先完成实现再展示可行性。本轮沿用会话内已有Git发布与服务器部署授权，实际部署结果完成后记录。

## 实现结果

按[ADR-0050](../decisions/ADR-0050-自主思考休息上限.md)增加主人可配置的maxRestMinutes，默认15分钟；sleeping与waiting都有有界重新考虑时间。超长sleeping请求按上限缩短，waiting不再无限关闭普通机会。更早任务及小时配额一并进入nextWakeAt计算，暂停、错误、忙碌和运行额度仍优先。没有新增模型循环、聊天库、固定回复或强制联系。

设置页显示新字段，校验与最短续行间隔的关系；中英文切换保留值，390px布局没有横向溢出。现有CSS未修改，沿用现有白绿令牌。设计检测对修改TSX／i18n无新问题；hook提示的既有CSS字号／圆角与设计sidecar漂移属于本轮未改样式的规范匹配问题，已按现有界面上下文复核，不修改或屏蔽规则。

自主存储为严格schema2；旧文件由独立离线转换工具在已授权部署中显式处理，不在生产读取中增加旧版兼容。转换保主人原有开关、暂停、自动恢复、额度、联系人、计数、错误和历史，并为当前长休息记录不超过上限的真实时间。

## 本地验证

完整构建和严格类型通过。启用独立系统DSH0.2.1-rc.5的全量回归98文件通过／3文件条件跳过，1881项通过／11项条件跳过，114.75秒。条件未提供的独立运行时路径不冒充实跑。

新增单元与离线转换验证覆盖：12小时休息与waiting均在2分钟测试上限到期重新准入，无需外部新消息；短休息保留，更早任务优先；小时配额、主人暂停和运行时未就绪均不能绕过；主人缩短上限仍保存为暂停；跨重启保持期限；旧schema／缺字段／冲突与非法范围拒绝且保原字节；转换前Host锁／原SHA校验、精确备份、重复转换拒绝、原会话日志保持。真实DSH回环另外验证模型请求12小时休息时收到不超过1分钟测试上限的正式工具回执，零QQ发送。

相关浏览器首轮17项通过／4项失败；失败均为既有滚动用例将只读POST media-transport误算写入。已按精确operation＋空input修正，其他POST继续计为变更；原4项失败用例重跑全部通过（6.189秒），合计21项相关浏览器验证通过。新字段真实保存与双语／390px检查已通过，桌面及移动截图已实际读图确认可读，未仅凭DOM坐标判断。

其他四插件（QQ、表情、生图、记忆）构建产物完整性哈希与前轮一致；仅DSH产物升级，SDK新增类型字段未改其他插件功能。

## 可行性结论

| 场景 | 已实现的结果 | 证据 |
| --- | --- | --- |
| AI要求睡到明天 | 实际wakeAt缩短到主人上限 | 假时钟状态测试、真实DSH工具回执 |
| AI选择waiting | 到边界仍重新获得思考机会 | waiting到期与跨重启测试 |
| 有更早AI任务 | nextWakeAt显示更早时点，到期仍按同一机会执行 | agenda优先与一次消费测试 |
| 小时轮次用完／主人暂停／运行时离线 | 不越过限制调用模型 | 准入与状态测试 |
| 保存较短上限 | 旧休息时间缩短，仍需主人恢复 | 配置CAS与暂停测试 |
| 旧云端数据 | 停机、摘要核对与备份后的显式schema2转换 | 离线文件与损坏拒绝测试 |

实现可行，能够从代码层阻止AI通过普通休息／等待安排无限期停止重新考虑。它提供持续思考机会，不能保证持续对外发言或聊天质量。15分钟为默认可调整值；忙碌、暂停、错误、小时配额仍可使实际执行更晚，真正执行重新思考会调用模型。
