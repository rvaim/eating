# 图片JSON文字误发强制修复报告

日期：2026-11-13，Asia/Shanghai。

## 范围与当前状态

用户再次提供图片JSON文字消息截图并明确要求立即修复。上一轮仅部署预览优化，没有实现发送约束；本轮按[ADR-0055](../decisions/ADR-0055-图片消息发送前强制校验.md)完成实际发送入口强制校验，正在按本会话授权提交、push和保留数据部署。

QQ0.16.1，manifest／package／后台／前端四处版本一致。生图0.4.1、应用0.22.0、其他插件、SDK、依赖及锁文件保持；没有变更真实提示词存储、人格或发送目标，没有清理会话或数据。

## 修复

新增QQ内部图片消息校验，接入统一prepareOneBotCall，在登记动作与OneBot调用之前拒绝图片JSON字符串、文字中的内部图片引用及错误字段位置。覆盖私聊、群聊、通用发送、快速操作reply、text段和嵌套node.content；入站context保持数据语义，不受此发送规则误拦。

返回明确QQ_IMAGE_MESSAGE_REQUIRED／not-sent和纠正指引，复用原图和本次被拒绝的request_id。原成功／unknown幂等及变参冲突保持。正确图片仍由授权lease转换为实际媒体；不自动转换字符串，不重新生图或盲重发。

同时更新QQ默认主／子规则和工具message描述，说明该错误及纠正方法；主人自定义正文和人格不覆盖。面板以中英文显示具体的“未发送，修正图片消息格式”错误。
