日期：2026-11-17。范围：按已批准实施方案完成 `@eating/ui-sdk@4.4.0`、Host／Web `0.27.0` 及全部 8 个内置插件（`qq@0.19.0`、`dsh@0.23.0`、`stickers@0.4.0`、`image-generation@0.7.0`、`openviking-memory@0.4.0`、`text-to-speech@0.3.0`、`speech-to-text@0.2.0`、`android-control@0.2.0`）重构后的全量构建、类型检查、单元／组件测试、多视口多主题多语言视觉核查与完整浏览器端到端验证。本轮仅完成本地实现、文档同步及仓库 `commit`／`push`，**未部署到云服务器，未操作真实手机硬件，未调用真实付费 AI 服务或向真人试发 QQ 消息**。

## 实现摘要

- **共享组件与样式规范**：`@eating/ui-sdk` `4.4.0` 新增并导出 `PluginLifecycleBar`、`Switch`、`PasswordInput`、`DurationInput`、`TagChipsInput`、`KeyValuePairsEditor`、`StringListEditor`、`SegmentedTabs`、`InlineConfirm`、`FormSaveBar`、`UnknownOutcomeCard`，扩展 `PluginPanelProps` 并在 `ActionButton` 支持触屏点击解释 `popover="manual"`。[`apps/web/src/styles.css`](../../apps/web/src/styles.css) 同步维护 69 个浅色与 69 个暗色 CSS 语义令牌，全局组件及插件 CSS 无颜色字面量。
- **宿主工作区与导航安全**：修复 `hasConfiguration` 就绪判断；`Overview` 增补关键能力状态卡片；`Plugins`、`Robots` 与 `Harness` 统一通过 `PluginLifecycleBar` 控制启用与连接；新增搜索／状态过滤、单一“打开设置”动作与跨导航未保存草稿拦截确认条（`host-dirty-guard`）。
- **八插件重构与最小探测端点**：
  - `text-to-speech@0.3.0` 与 `speech-to-text@0.2.0` 仅新增零计费只读 `manage('test-connection')` 鉴权探针（`GET /models`，不发起语音合成或识别计费调用，支持 `AbortSignal` 与插件断连即时取消）。
  - `qq@0.19.0` 修复子分区保存锁互斥问题（`mediaSaving`／`audioSaving` 解耦），将 `LiveLogs` 升级为可暂停／多维过滤／内嵌快捷测试抽屉且严守隐藏／离页即清的双行日志流，并新增消息段构建器与 MCP 凭据抽屉。
  - `dsh@0.23.0`、`openviking-memory@0.4.0`、`image-generation@0.7.0`（含 `asset` 续编辑闭环与受控并发懒加载缩略图）、`android-control@0.2.0`（含 `disconnect`→`save`→`connect` 两步安全重连）、`stickers@0.4.0`（多选标签云、标签芯片与移动端视图切换）全部同步新版组件与零跳跃交互。
  - 原生 DSH Web 页面与 `.impeccable/design.json` 保持未改；无新增外部依赖（`pnpm-lock.yaml`、`@eating/plugin-sdk@4.15.0` 与 `@eating/plugin-core@4.0.0` 保持不变）。
