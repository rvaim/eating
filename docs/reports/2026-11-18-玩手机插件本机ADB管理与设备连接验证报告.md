# 玩手机插件本机 ADB 管理与设备连接本地验证报告

日期：2026-11-18。范围：按已批准方案将 `android-control` 升级至 `0.3.0`（插件管理本机 ADB、直接连接 USB／网络设备，移除远程 MCP 执行端），完成实现、构建、单元测试、Host 边界测试、浏览器端到端检查与文档更新。**未部署至云服务器，未连接真实安卓物理手机，未向真实互联网下载 Google 压缩包（下载验证采用本地签名回环 HTTP 仓库完成）。**

## 1. 变更摘要

- **配置契约（[config.ts](../../plugins/capabilities/android-control/src/backend/config.ts)）**：严格 `schemaVersion: 2`，字段 `connectionMode`／`networkAddress`／`defaultDevice`／`adbPath`／`workspace`；全面验证 `IPv4:port`、域名与 `[IPv6]:port`；发现 `v1` 或损坏配置时保留磁盘原文件不动，仅经显式 `rebuild-configuration({ confirmed: true })` 重建。
- **ADB 检测、内置安装与设备管理（[adb.ts](../../plugins/capabilities/android-control/src/backend/adb.ts)）**：实现 `手动路径 → 系统 PATH／SDK → 插件私有目录` 严格检测顺序（手动无效直接报错、禁止静默回退）；支持单任务防重、SHA-256 核对、纯 Node ZIP 防穿越／防符号链接解压与 `adb version` 实测的官方安装包安装器；仅允许 `darwin (arm64/x64)`、`linux x64`、`win32 x64`，异常架构明确报错；`remove-installed-adb` 停止运行时后只删 `tools/`，保留配置、工作文件及回执；`adb pair` 配对码一次性传参且绝不留盘或入日志。
- **统一设备选择与防串设备核对（[engine.ts](../../plugins/capabilities/android-control/src/backend/engine.ts)、[tools.ts](../../plugins/capabilities/android-control/src/backend/tools.ts)、[server.ts](../../plugins/capabilities/android-control/src/server.ts)）**：移除远程 MCP `executor.ts` 与 `executor.mjs` 打包资产；全量命令与截图复用默认设备／显式 `serial`／`-s` 解析与多设备保护，将解析后的目标设备绑定入 HMAC `intent` 摘要；[app.ts](../../apps/host/src/app.ts) 仅针对插件显式声明的 `configurationManageOperations` 放开停用态配置操作，同时保持其余接口、插件与工具调用的启用／连接校验不变。
- **双状态分离 UI（[panel.tsx](../../plugins/capabilities/android-control/src/web/panel.tsx)、[ConnectionTab.tsx](../../plugins/capabilities/android-control/src/web/ConnectionTab.tsx)、[i18n.ts](../../plugins/capabilities/android-control/src/web/i18n.ts)）**：重组为“控制台与进程”“屏幕与文件传输”“ADB 与设备连接”三页签及独立顶部 **ADB 环境**／**手机设备状态** 双指标卡；重构连接页为“ADB 环境”“设备连接（含网络 `127.0.0.1` 提示与无线配对）”“高级配置”，补齐双语（`zh-CN`／`en-US`）与 `visibilitychange` 隐藏自动清配对码／截图内存保护。
- **未修改范围**：`pnpm-lock.yaml` 零改动；其余 7 个内置插件代码与版本号均未变化。
