# Eating 威胁模型

状态：文档分析，未安全验证。资产：核心人格、长期记忆、会话/聊天隐私、凭据、主人批准、安装/执行权、账号、队列/动作账本和运行预算。

| 威胁 | 影响 | 设计要求 | 待验证 |
| --- | --- | --- | --- |
| 外部文本冒充系统/主人 | 越权或泄漏 | Host 验来源，内容不提权 | 各适配输入/来源语义 |
| 歧义批准、重放、目标/版本变化 | 未批准执行扩展 | 请求/身份/目标/版本绑定 | 并发、过期、撤销、重启 |
| Shell/文件/子 Agent/原生安装旁路 | 新代码执行或窃密 | 真实执行权限和受控入口 | 每个 Harness 及三平台分别测 |
| 模块/build 脚本恶意 | Host 权限副作用 | 来源固定、批准、最小凭据 | 失败残留、动态更新与模块进程 |
| 声明解析时执行插件 | 未批准先执行 | 静态发现与运行激活分开 | loader/依赖脚本路径 |
| 页面贡献冒用身份/访问其他模块 | 配置越权、凭据泄漏 | 注册归属、受控方法、独立权限 | 实际前端代码/DOM/RPC 边界 |
| 停用后迟到响应或请求 | 入口复活、重复动作 | 撤销后失效、在途核对 | 前后端不同时退出/清理失败 |
| 移除平台误删共享服务/数据 | QQ 等无关模块停止或丢数据 | 依赖/资源归属、数据与程序卸载分开 | 全部移除、重复启停、共享依赖 |
| 同进程插件阻塞/崩溃 | 整个 Host 受影响 | 按风险进程隔离、超时/有限恢复 | Cordis scope 不能代替故障测试 |
| 本地控制接口未认证 | 改人格/权限 | IPC/本地服务认证和输入校验 | 具体协议未定 |
| 主运行脉络混合私人内容 | 联系人间泄漏 | 历史/输出权限和记忆披露范围 | 每个运行时的上下文使用 |
| 回执丢失/恢复重投 | 重复发送/发布/付款 | 持久证据、幂等、真实状态查询 | SDK/队列/平台交界窗口 |
| 无界续行/调度/并行 | 成本和资源耗尽 | 预算、有限重试、暂停 | 原生停止能力及故障时边界 |
| 运行时数据根/凭据共用 | 污染用户环境/混用记忆 | 每适配器独立根与命名空间 | DSH 双 home 和各运行时实际位置 |
| 原生 Session ID 跨 Harness 混用 | 错误恢复/历史丢失 | 运行时/配置身份参与映射 | 不兼容恢复不能静默新建 |
| 切换后旧主控仍活跃 | 分叉、重复工具动作 | 停旧/在途核对/排他主控 | 不承诺热切换或无损迁移 |
| 把未知/错误能力显示为可用 | 错误授权/数据丢失 | 支持证据和调用结果分开 | 不支持、未知、故障路径 |

## 信任边界

主人 → Host；平台 → 通讯模块 → 队列；Host → 选定 Harness 适配器 → 实际运行时/工具/记忆；扩展包 → 加载/安装执行者；前端模块 → 页面注册/受控 Host 接口。

同设备、同进程、Cordis scope 或签入目录都不自动代表可信。逻辑模块、故障进程和 OS 权限边界分别验证。产品目前没有代码或安全测试结果，详见[权限](权限与授权.md)及[问题清单](../待确认问题.md)。
