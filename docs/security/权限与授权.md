# Eating 权限与主人授权

状态：2026-10-29。当前应用 0.9.0、三个共享包 2.0.0、QQ 0.9.0、DSH 0.4.0，仅接受 API2。分层提示词和子代理权限继续按 [ADR-0014](../decisions/ADR-0014-分层提示词与受控子代理.md)执行；旧格式、缺字段推断和旧权限入口按 [ADR-0015](../decisions/ADR-0015-默认不兼容旧版.md)删除，只有用户明确要求才设计兼容例外。当前验证见[本轮报告](../reports/2026-10-29-删除旧版兼容验证报告.md)。实现是源码与服务端逻辑授权，不等于 OS 沙箱、任意恶意插件隔离或三平台完整验证。新增适配器、Cordis 或动态面板不会自动满足权限要求。

## 目标与主体

已授权普通操作允许自主使用；新增可执行扩展需可信主人明确批准；付款、重要删除等动作按实际风险保护，不默认每步人工确认。固定人格和审批数据由可信 Host/主人入口控制。

| 主体 | 允许 | 必须限制 |
| --- | --- | --- |
| UI/模块页面 | 通过受控 Host 接口提交配置/操作 | 直接持有运行时内部或其他模块权限 |
| 主 Agent/子 Agent | 使用已授权工具、申请扩展 | 改核心人格、伪造批准、绕过安装入口 |
| 通讯模块 | 接收/发送并标明平台真实身份 | 用正文声明获得主人权 |
| Harness 适配器 | 在授权范围管理选定运行时 | 把运行时 native 权限直接授给通用页面 |
| 插件底座/注册表 | 核对身份/版本/归属、装配/撤销 | 将注册成功等同可信授权 |
| 安装执行者/脚本 | 执行批准绑定的来源/版本/操作 | 任意扩大权限、访问 Host 授权凭据 |

## 当前正式实现

QQ／Host 首版已建立回环绑定、Host／Origin／跨站校验、本地会话＋CSRF、每插件 MCP 专用 Bearer、QQ 令牌只写不回显、POSIX 受限配置、稳定 request_id 和账号作用域 unknown 保护。主人手动功能测试仍使用 39 项标准目录，所有副作用经显式确认；缺少稳定动作键时返回 not-sent，不随机补键后发送。

本轮受控子代理使用独立的权限路径，见 [ADR-0014](../decisions/ADR-0014-分层提示词与受控子代理.md)：

- QQ 主人／管理员只从当前完整配置读取并由本地受控入口保存，每类最多 100 个规范化、安全整数范围的 QQ 号码，并以 policyRevision 执行 CAS。更改身份和类型权限使用完整字段与 CAS，不补缺失权限默认值，不重连 OneBot；owner 优先于 administrator。接收时核对真实登录账号与实际 sender，正文、昵称或平台 sender.role 不能改变主人配置，信封 source 仍为 external。
- 通用、主／子独有、插件说明和统一人格只从受信主人配置／已注册来源装配。作者仅有 6 种作用域、9 个受信变量，scope／source 必填并与文档 ID 和插件来源匹配，无旧群私输入模板或外部正文变量。模型和 MCP 不提供固定人格、核心提示词或批准数据的写入口；消息正文、附件、引用与任务留 user 数据。主人／管理员变量只由 Host 本地配置生成，不接受任务参数中自称的号码。
- 主 Agent 只有列类型和受控委派两个原生工具，不挂全权 QQ MCP；子代理不再委派，仅获得本类型 availableTools 中当前勾选项。默认是适用的只读能力加本类型明确发送；凭据查询、无关全局维护、难以固定目标的通用 send_msg 和 quick 操作不向子代理开放。主人手动 39 项目录不因子代理收敛而删除。
- Harness 只实现 deliverBatch；getMcpConnection 必须带完整 scope，readAgentActions 与 revokeAgentAccess 为必需服务，缺失即拒绝，不能回退主人全权令牌或将缺能力当作成功。委派只收类型、真实 context_ref 与任务。Host 用接收时核验的来源建立不可由模型提交的 scope；MCP 服务端目录和 invokeScoped 共同核对启用状态、当前账号、会话、目标以及消息／资源引用，防止仅隐藏目录却仍可直接调用。引用保留最近 256 个集合、每集合最多 2048 项，不能任意遍历其他会话。
- 每任务轮换内存中的子代理 MCP 令牌，finish、断开和停用撤销；新任务的 action 集合不混入旧任务。每次调用重读动态权限，旧令牌或迟到调用不能恢复权限。代理身份与稳定 request_id 组合经 SHA 命名空间隔离发送账本；同请求同参数复用已知结果，参数变化拒绝，unknown 保留并不盲目重发。
- 子结果向主返回摘要与 Host 本任务实际动作回执，摘要不冒充执行成功；普通 finalResponse 不自动发送 QQ。flush＋匹配 ACK 只表示可靠入箱接管，不能当作任务、模型消费或平台动作成功。

DSH 已通过官方 SDK 源码组合、独立产物及原生多代理的本地验证；这些不是付费模型认证、所有 OneBot 实现或真人动作验证。当前来源分类、scope 与令牌是受控后台逻辑，仍不是远程主人认证或 OS 沙箱。存储与凭据归属见[数据规范](../technical/数据目录与账号实例.md)。

## 格式拒绝与真实数据保护

插件清单、后台入口与实际实例的 kind 必填且一致；旧 API、缺 kind 或旧单条消息交接接口不再接纳。作者 schema2、QQ 配置 wrapper schema2、DSH agent-bindings schema2 及各自当前严格 schema1／Host 数据库形状在写入前验证；不自动补字段、推断旧权限或升级版本号。坏配置局部显示错误，不渲染可写空表单。

默认不兼容也适用于未来发布。旧格式明确报错，原数据不被转换或覆盖；删除兼容代码不授权删除、重置真实 `~/.eating`。本轮仅在临时 home 验证，未部署；没有用户明确指令不得自动迁移或清空真实目录。新的 EATING_HOME 是新实例与新会话。当前 PATCH、空 Key 保持、正常重连、同版恢复、ACK 重建和幂等是当前业务语义；OneBot v11 正式协议别名及 OpenAI 接口继续保留。

## 模型和会话读取权限

模型获取／测试只由受控管理入口使用已保存的 endpoint／key；选择模型只改草稿，不允许任意工具调用借此读取密钥。测试请求最小 Ping、max_tokens=1，超时最多 15 秒，禁止重定向并限制响应 1 MiB，成功只证明该次 API 请求连通，不等同运行时就绪。

会话看板手动调用原生 Cordis／persistence 的公开只读接口，只读取当前专属 rootParentSession 树，不启动模型／会话，也不复制 Eating archive。默认 50 条、会话列表最多 100 条，响应与文本分别受 1 MiB／32K 上限约束，并过滤敏感字段和 reasoning。隐藏、离开即清内容，不为看板后台轮询；运行中缓冲可能未落盘，缺状态／时间证据按 unknown／空值表示。原生会话仍可能保存正常工具结果，不能承诺整条链路无敏感留存。

## 真正的执行边界

Preset/工具过滤/prompt、Cordis scope 和 Eating 注册表都是配置或逻辑机制，不是完整 OS 沙箱。同用户任意 Shell/文件权限可能直接改安装目录和批准配置，不用提示词修补。

研究低权限身份、平台沙箱、只读配置、受控工作区/网络/安装入口、独立执行者与凭据。进程独立本身也不等于权限隔离。DSH 两个 home、Profile/Preset 和插件路径属于 DSH 适配细节；其他 Harness 逐项核查。

## 扩展与页面注册

新增 Harness/通讯模块、可执行前端入口、MCP 服务、未授权预装模块激活或动态代码/远端执行都纳入能力范围。静态元数据校验不能先执行插件代码再申请批准。

模块和贡献项有明确所有者/版本/权限，不能冒用其他模块 ID 注册或撤销。前端页面只获得自身允许的 Host 方法；撤销后迟到请求不能继续授权操作或复活入口。凭据不因自注册页面而暴露到通用目录。

同进程第三方 JS 和共享页面环境的实际可访问范围需单独验证；不因使用依赖注入或前端 Error Boundary 声称能隔离任意恶意代码。

## 审批与卸载

绑定可信主人、请求、精确来源/版本/commit、操作、副作用、数据身份和有效状态。拒绝重放、歧义“可以”、目标变更。安装／启用／卸载与删除数据分别授权；默认不兼容已确认，只有用户明确要求才设计旧版兼容或迁移。更广的执行边界仍见[待确认问题](../待确认问题.md)。

停用/卸载不能默认删其他模块、共享依赖、本模块未确认动作或历史。暂停新请求、处理在途和撤销贡献的顺序需验证，删除重要数据仍受独立保护。

DSH plugin-manager 的 build/版本风险参数不验证 Eating 主人批准，见[专属源码证据](../research/DSH源码核对.md)；不把此 API 语义推广到其他 Harness，也不假设它们安全。

## 验收

本轮完整构建／严格类型通过，41 文件 983/983（37.03 秒）含 5 项实际 SDK 验证，浏览器 53/53（18.5 秒）；均为回环模型／OneBot 和临时目录。实际 SDK 测试需显式设置独立 EATING_DSH_TEST_RUNTIME，默认跳过 5 项不能冒充实跑，不再要求旧插件迁移夹具。付费提供商、真人动作、OS 隔离及其他 Harness 不在该结论内。
