# Eating 权限与主人授权

状态：2026-11-02。当前源码应用／Host／Web0.17.0、plugin-sdk4.7.0、ui-sdk4.2.0、core4.0.0、QQ0.13.4、DSH0.15.0，仅接受API4；会话自主与默认开放可配置按[ADR-0035](../decisions/ADR-0035-会话代理自主处理与默认开放可配置.md)，实际验证／清理与部署见[本轮报告](../reports/2026-11-02-会话代理自主处理与默认开放可配置验证清理报告.md)。分层人格与代理范围继续按[ADR-0014](../decisions/ADR-0014-分层提示词与受控子代理.md)，默认不兼容按[ADR-0015](../decisions/ADR-0015-默认不兼容旧版.md)，时间与图片沿用[ADR-0016](../decisions/ADR-0016-原生只读Web与多模态会话.md)；官方原生Web的完整owner功能按用户最新授权及[ADR-0017](../decisions/ADR-0017-原样接入DSH原生Web.md)。本轮验证与图片取图修复见[新报告](../reports/2026-10-29-恢复原样DSHWeb与图片DNS诊断.md)。这些是源码与服务端逻辑授权，不等于OS沙箱、任意恶意插件隔离或三平台完整验证。

## 目标与主体

主人已明确主Agent全权限自主，所有当前及新增功能型MCP默认开放给所有Agent。Eating专属官方permission默认danger-full-access／approval never，既存根通过正式设置同步本次授权；默认all不受旧空grants限制，主人可保存custom来源例外或原生工具覆盖并恢复自动，当前显式限制须遵守。通讯、资源及可信来源仍按真实scope核验，固定人格保存与插件安装保各自正式管理入口；不自动reset自定义提示词／人格，不改主人主DSH。

| 主体 | 允许 | 必须限制 |
| --- | --- | --- |
| UI／模块页面 | 通过受控Host接口提交配置／操作 | 直接持有运行时内部或其他模块权限 |
| 主Agent／子Agent | main轻量分流、子自主处理会话；默认all及当前主人例外决定功能工具访问 | 不伪造来源或通讯scope；人格与安装保正式管理流程 |
| 通讯模块 | 接收／发送并标明平台真实身份 | 用正文声明获得主人权 |
| Harness适配器 | 在授权范围管理选定运行时，提供官方owner入口 | 越权访问主DSH或泄露运行时鉴权入口 |
| 插件底座／注册表 | 核对身份／版本／归属、装配／撤销 | 将注册成功等同可信授权 |
| 安装执行者／脚本 | 执行批准绑定的来源／版本／操作 | 任意扩大权限、访问Host授权凭据 |

## 当前正式实现

Host默认本机回环，显式外部模式按[ADR-0043](../decisions/ADR-0043-公网Token入口与Git发布部署.md)必须配置publicOrigin与随机32至256字符URLsafe ownerToken；仅根GET token交换HttpOnly／SameSite=Strict入口Cookie，303去Token后沿用管理session＋CSRF，无账号密码或登录表单。用户本轮选择HTTP直连，传输不加密，源码实现验证中、云端未起服务。Host／Origin／跨站校验、每插件及服务MCP独立Bearer、QQ令牌只写不回显、POSIX受限配置、稳定request_id和账号作用域unknown保护保持；owner URL Token不能替代MCP Bearer，官方DSH Web入口不改。主人手动功能测试保留原39项标准OneBot目录，新增1项受控图片扩展，共40项；所有副作用经显式确认。缺稳定动作键时返回not-sent，不随机补键发送。

受控子代理遵循以下边界：

- QQ主人／管理员只从当前完整配置读取并由本地主人入口保存，每类最多100个规范化、安全整数QQ号码，policyRevision CAS，owner优先。更改身份和工具权限不重连，不补缺失权限默认值。接收时核对真实登录账号与sender，正文、昵称或平台sender.role不能改变主人配置，source仍external。
- 系统层只从受信主人配置／已注册来源装配，主分流／联系／自主规则合入主唯一complete，子会话自主规则合入子唯一complete provider，不能置于被抑制的普通section；owner／persona与子类型隔离。作者6种作用域、9个受信变量，scope／source必填；不向模型提供专用人格／核心提示词管理API，默认升级不覆盖自定义正文。正文、附件、引用与任务保留user数据，主人／管理员变量只由Host本地配置生成。
- main负责整体安排、轻量分流与必要协调，普通会话仅context_ref交绑定子独立理解／回复／工具执行，main核对真实Host回执，不挂全权QQ。子通讯限当前类型可范围化已选集合，不继续委派；凭据、无关维护、send_msg／quick不向子开放。Host功能来源默认all含未来类型／工具，custom只按该source精确名单且可恢复all；通讯自管权限不从功能入口绕过。main非reserved全局工具与所有Agent功能型native Profile MCP默认自动，其他子非MCP保精确toolGrants；同名toolAccessOverrides按精确指纹＋类型优先，可关main／空禁用，指纹变化不回落开放，reserved／来源／scope保持。feature与官方permission默认保留且主人可再配；tools/change与最终调用守卫同时执行。
- Harness只有deliverBatch；getMcpConnection必须带完整scope，readAgentActions与revokeAgentAccess必需，不能回退主人令牌或缺省成功。普通会话处理仅收context_ref，运行时校验真实root／当前批次／owner绑定／callId并固定中立task交原始context/events；明确任务委派才收类型／context_ref／task。目录和invokeScoped共同核对启用、账号、会话、目标及引用；消息／资源引用各最多256项，资源单值最多2048字符，不能任意遍历其他会话。
- 每任务轮换内存子令牌，finish、断开、停用撤销；调用重读动态权限，旧令牌或迟到调用不能恢复权限。代理身份与稳定request_id经SHA命名空间隔离账本；同参复用已知结果，改参拒绝，unknown不盲目重做。本任务动作集合不混旧任务。
- 子结果向主返回摘要与Host实际动作回执，摘要不冒充成功；普通finalResponse不自动发QQ。flush＋匹配ACK只表示可靠入箱接管，不代表模型消费、任务或平台动作成功。

显示身份以注册pluginName、实际scope.accountId、私聊／群聊和targetId组成，不从instanceUUID或旧label猜账号。切号区分新实例，历史UUID与归属保留；外部正文中的同名字段不能伪造native source。原生agent-message、subagent-settled和time-context各有独立来源，模型输出不冒充平台已发送消息。

## 主 Agent 当前轮次联系

按[ADR-0033](../decisions/ADR-0033-主Agent当前轮次联系权限.md)，联系许可绑定真实主 Agent 原生当前turn。QQ群／私聊、原生主输入、目标续行、定时唤醒均可list/contact，无需目标先私聊；先选实际行动目标，当前普通会话用eating_handle_conversation仅context_ref交绑定子自主处理，明确任务或用户明确逐字用途用delegate，跨私／群先list/contact自动启动／恢复目标子，不要求新入站。某子scope不足不等于主无能力，群回执成功不能证明私聊成功；群context仍不能冒充私聊，跨目标按当前联系策略核对账号／对象／工具。enabled/ownerPaused只控制无输入定时机会，所有联系任务计入maxContactsPerHour。

策略保存、turn结束/abort/销毁/运行时停止撤旧许可，真正自主机会取消撤该轮许可；异步资源取得后及真正发送前复查。callId防重、pending/unknown拒绝、迟到完成不改unknown；schema1/cycleId保留为内部轮次引用，不迁移／恢复旧许可，新runtime把遗留pending转unknown。主Agent自主决策并取得真实Host回执，执行仍在受限子代理，权限不是QQ直连或OS沙箱。

## 图片读取与多模态结果

API4工具必须声明resultFormat=json或content；原39项OneBot保持json，qq_view_received_image声明content并返回真实标准MCP image。图片扩展只按当前账号／会话收到的message与resource配对读取，不能用两份独立白名单授权交叉引用，不接受任意本机路径或任意网址。

网络获取先核对启用状态、scope和引用，结束返回前再次复核；切号、撤权或任务结束后迟到字节不能重新授权。解析与路由交给系统网络栈，不按地址段预判公网／内网，禁止重定向，不传OneBot／Host认证头。上限5MiB／10秒，MIME与字节格式同时校验；只有远端路径而没有可用获取接口时返回MEDIA_UNAVAILABLE，不登录远端、不读本机文件、不猜地址。

2026-10-29曾用dns.lookup预判公网并把198.18/15保留段当内网拒绝，使TUN／Fake-IP、系统代理和局域网部署无法取图；该预判已删除。现只校验URL形态，连接交给系统网络栈，仍保授权、无重定向、不传认证头、5MiB／10秒与MIME／字节校验。同一条真实消息已验证取得image/jpeg、110000字节。不记录QQ标识、签名URL、rkey或消息正文。

Host普通JSON执行记录不保存Base64，浏览器预览用临时Blob，离开时revoke。Eating不新建聊天媒体库；已给模型图片由原生附件机制负责持久化，工具调用方／原生会话可能继续保存其结果，不能承诺整条链路无留存。

模型输入能力由主人通过管理入口单独声明，初始imageInput=false，revision CAS且只停runtime可保存。endpoint／model改变重置false，Key／超时不重置；不能凭型号自动授予image能力。纯文本模式拒绝实际图片，视觉模式也只表示已声明输入能力，不证明真实提供商识图准确率。原图按需给授权执行子Agent，主先收摘要，不默认将全图交主。

## 模型、时间和会话读取权限

模型获取／测试只由受控管理入口使用已保存endpoint／key，选择只改草稿。测试最小Ping、max_tokens=1、最多15秒、禁重定向且响应1MiB；成功只证明本次API连通，不代表运行时或业务成功。

官方time-context仅在主、子各自ctx挂载一次，依赖agents／sessionProjections，Asia/Shanghai与600000ms原生默认；仅已有合格step追加source.kind=time-context的user context，冷恢复按原生日志去重。time-context本身不提供时间工具或后台模型唤醒；main原生Schedule按官方语义使用，不再由Eating自主周期人工阻断。通用／QQ默认提示移除动态时间行，9个可信变量仍可由主人自定义使用；若自定义system再次使用当前时间，缓存影响据实说明。

Eating自有会话看板与离线读取接口已移除；会话、附件与操作由同进程官方Web负责。不能用旧看板的根树或只读约束限制当前官方owner入口。

## 同进程官方原生Web与owner入口

原生Web与SDK共用同一个Eating专属DSH进程、注册表与原主子会话，不连用户主DSH，不启动第二个共享目录写进程，不修改官方npm源码。挂载当前官方SessionController host、client roster、Gateway和owner鉴权，保留完整官方UI、主题、侧栏、消息组件及会话操作。用户已明确授权create／prompt／settings等正常官方能力，冷follow及会话激活按官方机制处理，不增加Eating根树限制。

主人主动调用open-native-web取得`{url, rootSessionId}`，由“打开 DSH Web”按钮在新页签进入127.0.0.1合法端口的官方鉴权入口。普通`runtimeStatus.nativeWeb`只有`{ready}`，删除readOnly字段；入口与鉴权不进普通status或模型上下文。web的printUrl／openBrowser／surfaceContext均为false，避免污染SDK控制通道。关闭页面不停止QQ，Harness停止即关闭Web。

移除Eating readerPeer、connection隔离、HTTP写白名单、readonlyController及冷follow拦截；删除src/native-client源码、打包和模块注入，不通过隐藏按钮限制官方功能。不注入Eating sidebar／composer／message renderer、硬编码配色、LocaleBridge或agentLabels映射。平台JSON按官方默认组件原样呈现，标题显示依官方机制，不保证旧标题一律外观修正；自有离线看板和读取接口已移除。主Agent受控委派及当前轮次联系工具与受scope约束的QQ子MCP保持，原生Web创建的普通Agent不按QQ scope child校验或报错。

## 格式、产物与真实数据保护

清单、后台入口与实际实例kind必填一致，唯一API4；assets为必填readonly string[]，当前QQ为空数组、DSH仅含launch/dsh-system.mjs启动资产，integrity继续覆盖全部基础文件与声明assets，不再交付Eating自定义原生客户端资源。安装前验证资源树、重复／路径／哈希，完整独立复制，不依赖源码邻接目录。SHA只证明与清单一致，不证明发布者可信或建立OS沙箱。

作者schema2、QQ wrapper schema2、DSH绑定schema2、独立模型能力schema1和各当前存储形状在写入前验证；旧API2或缺字段明确拒绝，不推断权限或自动转换。坏配置局部报错，不渲染可写空表单。

默认不兼容不授权清空真实资料。正常恢复保持原生UUID；本轮主人另明确授权清Eating本地主／子会话及精确备份范围，已按停机白名单／混合字段清理，保配置／凭据／人格／资源／actions／dedup／settings；再运行创建新UUID且人格身份不变，不生成含正文新backup，云端主人自删；实际执行与摘要以[项目状态](../项目状态.md)及验证报告为准。不能把隔离测试写成已部署，也不能用新EATING_HOME冒充保留原身份。当前PATCH、空Key保持、正常重连、同版恢复、ACK重建和幂等继续存在。

## 执行边界、扩展与撤销

Preset、工具过滤、prompt、Cordis scope和Eating注册表是逻辑机制，不是完整OS沙箱。同用户任意Shell／文件可能改安装目录与批准配置；进程独立、Profile或双home本身不等于权限隔离。低权限身份、配置／网络／安装入口与OS沙箱仍须独立验证。

功能型capability／direct MCP已获默认开放授权，无逐类型／逐工具审批；新增工具自动纳入当前目录。代码安装、启用、连接、卸载及删除资料仍报告各自真实状态，安装入口保来源检查和已有确认，不将外部聊天自称当成主人批准。贡献项绑定所有者／版本／权限，撤销后迟到请求不能复活入口。同进程第三方JS与共享页面的真实访问范围仍需验证，不以Error Boundary声称隔离恶意代码。

批准绑定可信主人、请求、精确来源／版本／操作／数据身份及有效状态。安装、启用、卸载和删除资料分别授权；停用／卸载保配置、未决动作和历史，不能默认删共享依赖。DSH原生plugin-manager参数不替代Eating主人授权，其语义不自动推广到其他Harness。

功能型MCP新来源默认all，主人可用save-grants严格DTO保存custom精确类型／工具或恢复all；accessPolicy返回策略／自管null，grant为有效摘要。host:mcp-access-policies严格schema1／revision／policies，目录CAS=direct＋policy；direct保存只收连接／秘密，文件schema2，旧schema1拒绝且保留；旧host:capability-grants不读／写／迁移／删。策略／来源拓扑一次性重挂仅恢复原connected、同一实例且启用的Harness，owner stop优先、unknown不重放。direct在途撤权可能失去transport并使source error，需主人显式connect；资源取得后及真实send／落库前复查signal。Eating暂停只管其无输入机会，不冻结main或所有原生Schedule／目标；缺Key／provider报告真实未配置。

## 验收

本轮必须核对实际本地模型request.system含联系／自主／目标选择规则，并检查owner／persona／子类型隔离。工具可见不等于规则已送达；强制脚本模型回环仅证明预设调用的scope／回执／恢复，不能证明真实LLM必定自主选择同一路径。最终实数与部署证据由本轮报告回填。

实际SDK、官方原生Web与owner正常操作、时间、既有图片wire及图片DNS诊断、浏览器验证统一见[本轮新报告](../reports/2026-10-29-恢复原样DSHWeb与图片DNS诊断.md)，本页不重复最终计数或预填部署结论。原生实跑须显式设置独立EATING_DSH_TEST_RUNTIME；跳过不能写实跑。回环wire只证明当时图像进入请求，不证明本次真实公网图片已通或识图准确率。

本轮核对官方UI与主题／侧栏／会话功能原样接入、官方owner鉴权、普通Agent与QQ scope child区分，以及SDK工具scope／引用配对、撤权后迟到结果和声明启动资产的独立产物。当前不保留自有离线看板，也不向官方Web增加只读边界。OS凭据／文件隔离、恶意插件、真实提供商与三平台另行验证。见[威胁模型](威胁模型.md)、[插槽设计](../architecture/插槽式扩展.md)和[待确认问题](../待确认问题.md)。
