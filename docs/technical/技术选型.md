## Cordis 相关边界

[评估](Cordis选型评估.md)记录上游 cordis 4.0.0-rc.12 的 API 未稳定说明，以及 DSH vendor @deepseek-ai/cordis 4.0.5 的不同身份；不据名称/版本推断兼容。现成 WebUI 是 Vue 生态，不默认与 React 通用，也没有决定引入两套前端框架。

Cordis 负责候选后台装配，不自动承担业务契约、前端注册、安装批准或 OS/进程隔离。选定 Harness 可以独立进程运行，不要求采用 Cordis。

## 已核对的 DSH 上游要求

[源码证据](../research/DSH源码核对.md)固定 SHA 22ddee3792402c3e70ec5f86a63c3e3e895a2f60，根声明 Node >=24.9.0、pnpm 11.28.5、MIT。这只适用于该 DSH 源码工作区，不是 Eating/其他 Harness 的统一要求或精确捆绑值。

未来发行包、Node、原生模块与第三方许可分别核查；Codex/Claude Code 接口/许可/分发均未验证。

## 选择原则

简单、复用、可验证，不提前增加大型框架。业务模块依赖稳定契约，通用界面不枚举具体实现。React 页面不承担后台存活。Cordis 不能迫使 Host 永远选 Node，若条件改变通过新 ADR 评估。

当前实现选择见[ADR-0010](../decisions/ADR-0010-正式Host与QQ能力服务.md)，目录/实例见[ADR-0011](../decisions/ADR-0011-统一数据目录与账号实例.md)。ws8.22.0、MCP SDK1.32.2、zod4.6.7、tsx4.23.15和其他精确依赖由[package.json](../../package.json)/[锁文件](../../pnpm-lock.yaml)记录；运行结果见[账本](../research/PoC验证结果.md)。后台是真实实现，尚未验证的Cordis/Harness/桌面/OS边界仍明确保留。
