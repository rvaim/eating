# Eating 当前接口契约

更新：2026-10-29。公开plugin-sdk／ui-sdk／plugin-core均2.0.0，插件唯一API2；默认不兼容旧API、旧数据或旧功能，见[ADR-0015](../decisions/ADR-0015-默认不兼容旧版.md)。当前外层业务信封protocolVersion仍为1，存储schema各自独立，不能据数字推断旧形状可接受。

## 包与插件

[后台SDK](../../packages/plugin-sdk/src/index.ts)定义BackendPlugin、BackendPluginEntry、Host上下文、来源、工具、批次与回执；[代理契约](../../packages/plugin-sdk/src/agents.ts)定义类型、范围与回执／会话摘要；[作者契约](../../packages/plugin-sdk/src/authoring.ts)定义当前提示词和确定性组合。界面经[公开契约](../../packages/ui-sdk/src/contract.ts)与[受控API](../../packages/ui-sdk/src/api.ts)接入。

插件只导入公开SDK，不引用Host／Web内部或兄弟插件。BackendPlugin与Entry必须声明kind，且与已安装清单一致；不默认communication。清单schema1、API2，包含身份／版本／种类／声明目录／后台／前端与每资源SHA256，旧API1拒绝。加载只用验证后的安装产物；[发现器](../../apps/host/src/discovery.ts)和[安装器](../../apps/host/src/plugin-installation.ts)落实核对。

OneBotConfig属于QQ插件，普通连接PATCH与持久完整配置是不同输入，不把专有字段塞通用SDK。当前共享类型在configuration.ts，无旧prototype持久化API或转发入口。

## 管理与MCP

- GET /api/bootstrap建立会话与CSRF；GET /api/workspace返回当前目录、真实状态及贡献。
- POST /api/plugins/:id/configuration、connect、disconnect、enable、disable、invoke、mcp-registration是主人受控入口；manage只路由明确operation与input，不进入模型工具目录。
- 作者GET /api/authoring、当前文档CAS保存、人格管理与已保存组合预览由[Host](../../apps/host/src/app.ts)验证；旧提示词ID／字段不接受。
- /mcp/:pluginId使用官方StreamableHTTP初始化／list／call及Bearer，不是伪REST。主人手动令牌与子代理任务scope令牌分开，Harness不能请求全权令牌。

Session、CSRF、Host／Origin、体积及结构均校验，本地地址不等于可信。副作用要求调用方预先提供稳定8至128位request_id；缺失／非法not-sent，服务端不补随机副作用键。相同账号范围的HTTP／MCP共用幂等账本，超时不等于外部未发生。

## 来源和交接

HarnessEvent标明插件／实例／真实账号／会话／发送者、接收时间、结构化content/text及source.external。可按插件声明提供角色／目标／消息与资源引用；这不使正文成为系统指令。QQ按真实连接账号和已保存身份核验，Host规范化队列保这些字段，不凭文本授权。

HarnessMessageSink只有必填deliverBatch(batch, signal)，批次含稳定ID、同会话事件和触发原因；可选isReady负责忙碌就绪，不存在逐条deliver。只有accepted＋durable＋receiptId并本地确认才转移正文所有权，不表示模型消费或外部动作完成。明确拒收有限重试，未知保留；本地确认失败只重试本地。

同一数据集只允许一个主要接收者。当前故障恢复、原生flush／ACK核对与unknown防重保留；旧接口、旧schema自动转换删除。数据版本、队列和幂等细节见[数据规范](数据目录与账号实例.md)。

## Harness私有服务与代理

HarnessOwnerConfiguration必须提供当前prompts、activePersona、agentTypes、pluginInstructions和bindings。PromptDocument.scope/source必填，source仅owner／plugin，旧legacy集合与外部模板变量拒绝。

getMcpConnection(pluginId, scope)必需完整可信范围；readAgentActions与revokeAgentAccess必需，不缺省空成功。Host只向已批准Harness暴露服务，通讯插件不能取得这些私有接口。

主原生工具参数只含类型／真实context_ref／任务，不允许模型任意提供system／tools／persona／scope。平台预绑定真实来源，构建固定层；工具目录过滤与逐次执行校验并用。TaskID来自公开原生callId，当前索引必需taskId／taskRefs；同一批可查询后再委派，但重复／pending／unknown与迟到回调受保护。

成功／失败／未知和本次实际动作分开；子摘要不充当回执，主final不自动发送。工具scope／Preset只是逻辑边界，不是OS沙箱。

## 管理操作

QQ save-agent-policy使用完整身份／两类型工具字段与expectedRevision，CAS冲突保原配置，不重连；持久化只收完整wrapper schema2，UI不可补默认空表单假装可编辑。

DSH list-models／test-connection只用已保存连接；list-sessions／read-session仅显式只读当前原生树，不启模型、不建档案。运行中的最近内容可能未落盘，unknown状态或空更新时间不伪造。操作参数和错误见[实际适配器](../../plugins/harness/dsh/src/backend/adapter.ts)。

## 变更规则与证据

接口变化同步类型、调用方、负向拒绝测试、README、ADR、规范与交接。默认不设计旧版迁移／回退；任何例外或真实数据处置须用户明确要求。不静默忽略未知字段或以旧私有方法补齐必要能力。

当前完整构建／严格检查、983项测试（5实际SDK）和53浏览器通过，证据见[本轮报告](../reports/2026-10-29-删除旧版兼容验证报告.md)。自动对端是回环，不证明真实提供商、所有OneBot实现或OS隔离。其他Harness的能力、记忆、跨引擎转换与热切换仍须独立核对。
