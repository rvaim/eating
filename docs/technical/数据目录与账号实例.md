# Eating 数据目录与账号实例规范

更新：2026-10-30。只实现当前格式，默认不兼容旧版；不自动迁移、补字段、改版本标记或覆盖原数据。用户未明确要求时不删除／重置真实资料，规则见[ADR-0015](../decisions/ADR-0015-默认不兼容旧版.md)。DSH0.5.1按[ADR-0017](../decisions/ADR-0017-原样接入DSH原生Web.md)原样接入官方Web；应用／Host／Web与QQ0.10.0、共享包3.0.0、API4及数据schema保持。

## 数据根与归属

EATING_HOME指定数据根，默认用户目录下.eating，支持~展开。首次安装可显式选择未使用的新目录，见[README](../../README.md)；新根产生新实例和会话，不等同迁移旧身份／历史。已存在资料按当前格式核对，旧格式明确拒绝且原文件保留。本轮已批准的真实实例更新需停机、备份并保配置／人格／原生UUID／Key；不因开发清空重建，实际部署见[项目状态](../项目状态.md)。

```text
EATING_HOME/
├── plugins/
│   ├── installed.json
│   └── <pluginId>/versions/<version>/
├── host/
│   ├── host.lock
│   ├── Eating.sqlite
│   └── mcp/connections.json
├── bot/qq-bot/
│   ├── accounts.json
│   └── accounts/<instanceId>/config.json
└── harness/dsh/
    ├── config.json
    ├── model-capabilities.json
    ├── session.json
    ├── agent-bindings.json
    ├── dsh-home/
    ├── agents-home/
    ├── workspace/
    ├── runtime-home/
    └── bridge/
```

代码版本、运行依赖和稳定业务数据分离。CLI安装／升级／卸载先停Host；管理页可由持锁Host执行验证后的事务，卸载撤执行入口不删除数据。SQLite运行可有WAL／SHM，队列容量不是整个数据库、工作区或磁盘配额。主DSH的Profile／会话／Key不在本数据根中，也不能借来运行测试。

## 当前唯一格式

| 位置 | 当前格式与限制 |
| --- | --- |
| Host数据库 | PRAGMA user_version=1，完整settings／delivery_queue／event_dedup／actions结构与索引 |
| host:authoring | schema2，三基础层、实际主人插件覆盖、候选人格及启用ID；不含legacy集合 |
| QQ账号索引 | schema1，defaultInstanceId和instances完整且一致 |
| QQ实例配置 | wrapper schema2，updatedAt及完整11字段configuration，权限四字段及两类型必需 |
| 插件安装索引／清单 | 当前schema1，清单只接受API4，assets必填（QQ与DSH均为[]），integrity覆盖基础文件和全部声明assets，kind等字段完整 |
| DSH配置／主会话 | 各自当前严格schema1，原7字段连接配置与密钥保持，不接受缺字段、未知字段或错误版本 |
| DSH模型输入能力 | model-capabilities.json，schemaVersion1、revision、imageInput，初始false；独立于连接配置，主人CAS且仅停runtime可保存 |
| DSH代理绑定 | schema2，task存在时taskId必填，taskRefs必填，不转换旧索引 |

不同文档版本独立，不统一改成一个编号。全新不存在的数据库才创建当前表。既有数据库只读预检版本、表、列、主键与索引，不支持则在写入／权限调整／DDL前拒绝；不会把旧库标成新版本。不存在incoming_events转换、ALTER回填、旧迁移压缩标记或完整VACUUM迁移步骤。

同版异常恢复保留：运行中断的actions.running转unknown、队列delivering转uncertain，防止盲目重复。当前ACK后使用增量回收和checkpoint，不将当前回收误删为旧兼容。

## 账号、配置与写入

pluginId为插件种类，instanceId为初建稳定UUID，accountId为协议端核验的实际账号；不以显示名或QQ号替代本地实例ID。当前只运行一个默认账号，索引结构不代表已有多账号并行功能。

QQ持久字段为displayName、endpoint、accessToken、autoConnect、forwardToHarness、receiveGroups、timeoutMs、owners、administrators、agentTools、policyRevision。旧缺字段配置不补默认；只有文件不存在的新实例使用完整默认工厂。读取错误不覆盖文件，界面不渲染可补默认的空写表单。账号索引不存在时创建当前新索引，不读取旧根单文件猜归属。

连接配置PATCH省字段保当前、空token保已存值、显式clearAccessToken才清除；这是当前接口语义。身份与工具权限通过完整字段＋policyRevision CAS保存，不重连OneBot。每类身份最多100个安全正整数十进制号码，重叠按owner识别。

配置使用同目录临时文件、同步与原子替换，失败保此前完整文件并清本次临时文件。POSIX目录0700／敏感文件0600，公共响应不回显Key。Windows ACL和全盘加密尚未验证，不把忽略规则当权限控制。

## 作者配置与浏览器数据

作者只收当前schema2，scope/source必填，9可信变量／6作用域；无group／private旧输入或外部正文变量。最多100人格、单正文50000 UTF-16字符、总5MiB，注册贡献和保存覆盖各最多256。当前无变化保存不增加版本；非法格式／CAS冲突／容量或写失败保持原数据。

未改插件默认使用当前声明，主人覆盖优先；停用保编辑撤执行，卸载保覆盖只读。localizedTitles只展示、不写覆盖、不改system。所有Agent引用同一启用人格，可全部停用显示空层，不复制人格正文。

Eating管理界面的浏览器只持久化eating.locale语言偏好，不含密钥或业务正文。旧prototype工作区localStorage公共API及模块已删除。Eating面板动作／日志／会话内容仅有界内存，离开或隐藏按各面板规则清除。图片预览只使用临时Blob，离开相关页面时revoke；Host普通JSON执行记录不保存图片Base64。DSH官方Web的界面与持久化行为保持官方机制，不套用Eating面板的显示／存储实现。

model-capabilities.json不修改原7字段连接配置或Key，初始imageInput=false；主人管理入口读取／保存，以revision CAS防覆盖，仅runtime停止时可保存。endpoint／model变化重置false，Key／超时不重置。不凭模型名猜视觉能力。Eating不新建聊天或媒体库；已交给模型的图片由Harness原生附件机制负责持久化，不能把浏览器清理描述成全链路删除。

## 未交接队列、容量与动作

delivery_queue仅持一份规范化Harness信封及序号、状态、尝试／下次时间、UTF-8字节等元数据，不保存原OneBot包或额外正文列。source.senderRole／target／messageId／resourceIds在白名单内严格校验，外部消息始终external。

默认persistent、1000条、10MiB、reject-new。memory正文只在RAM，退出丢失；当前模式切换事务转移存活队列，失败保原模式、正文和版本。全部pending／delivering／uncertain计入容量，不包含settings／去重／账本或WAL页。

只在accepted=true、durable=true、非空receiptId及Host确认后删正文；不是任务或动作完成。短期去重仅哈希／短状态／receipt_hash，24小时常态合计最多10000，磁盘清理全面失败时含内存后备最多20000；尚在队列的事件仍防重。drop-oldest只移pending，保护在途／未知；缩容整次原子，清空须确认且有delivering时拒绝，保留账号与动作账本。

动作账本按plugin＋instance＋account＋request_id隔离。子代理把agentId与原request_id组合为SHA命名空间；同键同参数复用结果，改参数拒，unknown不重做。当前源码可提供插件级非账号动作范围，不等于旧动作表兼容。

## 原生子代理与会话

DSH代理绑定只存插件、实例、账号、会话、类型、目标、原生UUID及短任务状态，不存正文。最多100实例、文件1MiB；消息和资源引用各保最近256项，资源单值最多2048字符。先校容量，原子保存成功后才更新内存，不写出自己无法再读的格式。

taskId来自公开原生callId，当前context保全最多32调用；pending／unknown／重放拒绝，迟到回调必须匹配任务。MCP令牌和Host本任务回执集合不写进该索引，任务结束／断开／停用撤权。正常同版UUID恢复继续支持，不提供旧无taskId读取分支。

原生 sessions 归 Eating 专属 DSH_HOME，是 Harness 自身上下文。自有会话看板及离线 reader 已删除，列表、分页、有效投影、附件和会话操作统一由同进程官方 Web 处理；移除看板不删除任何原生日志或附件，也不建立 Eating archive。

四段实例名用于原生创建标签，内容为平台、绑定实际accountId、中文私聊／群聊和targetId；平台名来自注册pluginName，无元数据用canonical pluginId，不以instanceUUID代账号。切号区分绑定，历史账号归属／UUID保留，不解析旧label猜身份。原生Web显示依官方机制，无agentLabels前端映射，不承诺旧标题一律外观修正；平台JSON按官方默认渲染，Eating的summary／source展示不注入DSH。

原生Web与SDK在同一Eating专属进程及注册表共用原会话，挂当前官方SessionController host、client roster、Gateway与owner鉴权，保留完整官方UI、主题、侧栏和会话功能，create／prompt／settings与冷激活按官方机制运行。删除Eating readerPeer、connection隔离、HTTP写白名单、readonlyController与冷follow拦截，不给官方Web施加Eating根树边界。主人按需open-native-web取得`{url, rootSessionId}`，按钮为“打开 DSH Web”，普通`runtimeStatus.nativeWeb`仅`{ready}`；删除readOnly字段，入口不进普通status或模型。web的printUrl／openBrowser／surfaceContext均为false。关闭网页不影响QQ，Harness停止即结束Web，不启动第二进程共享写会话目录，不改主DSH或官方npm源码。SDK两工具、QQ子MCP和time-context保持，原生Web普通Agent不套QQ scope child校验。

主子各一次官方time-context，Asia/Shanghai与600000ms原生默认，读取原生日志恢复注入状态，合格step才追加user runtime context。没有新时钟工具／scheduler；默认system移除动态时间行，但9个可信变量继续注册，主人自定义再引用当前时间仍会改变system。

DSH清单assets=["launch/dsh-system.mjs"]，保留API4对全部基础文件与声明assets的完整校验；删除Eating src/native-client源码、打包及模块注入，不再交付3个自定义原生客户端资源。不注入sidebar／composer／message renderer、硬编码配色或LocaleBridge。代码产物和专属原生会话／附件仍属不同目录；资源发布不授权删除账号数据。

清空Host队列不删除Harness原生会话。未授权旧数据转换、设备／跨Harness迁移或删除，均不自动实施；停用／卸载同样不等于擦数据。

实现入口：[存储](../../apps/host/src/store.ts)、[当前格式拒绝回归](../../apps/host/src/queue-settings.test.ts)、[QQ配置](../../plugins/communication/qq/src/backend/config-file.ts)、[代理绑定](../../plugins/harness/dsh/src/backend/agent-control.ts)。本轮官方Web恢复、图片DNS诊断、实际验证与资料保持见[新报告](../reports/2026-10-29-恢复原样DSHWeb与图片DNS诊断.md)，不预填最终计数或部署结论。当前真实imageInput=true，图片失败为保留段DNS解析遭HTTP GET前SSRF拒绝，策略本轮不改，详见[QQ架构](../architecture/QQ与平台能力.md)；旧报告回环成功不代表此次真实公网图片已通。当前各schema编号独立，插件API4不授权自动改写用户旧数据。

## 能力插件与MCP数据（0.11.0）

能力插件资料位于 `capabilities/<storageDirectory>`。表情包使用 `capabilities/stickers/library.json`（schema1/revision/items）及哈希命名的图片文件；卸载保留此目录。它是主动收藏的资源库，不是通讯聊天历史库。

直接MCP配置在 `host/mcp/connections.json`（schema1/revision/connections），敏感字段文件0600；连接状态与短期Agent lease不持久化。插件来源的MCP授权存SQLite settings的独立key `host:capability-grants`（schema1/revision/grants），不修改既有Host表结构。

表情分页只返回描述/标签元数据，图片单项按需读取；公开资源不接受任意路径。AI来源为Host核验的当前scope，AbortSignal仅内存不写入代理绑定。跨插件发送在真正调用OneBot前转换为标准图片数据，动作账本只保存有界元数据/参数摘要，不存原始图片Base64。

既有QQ/DSH/作者数据schema保持；API4升级只替换代码包激活索引，不自动转换配置或重建会话。详见[ADR-0019](../decisions/ADR-0019-统一插件与MCP能力管理.md)。
