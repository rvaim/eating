## 文案和国际化维护入口

公开 [UI SDK](../packages/ui-sdk/src/i18n.ts)精确依赖 `i18next 26.5.11`，提供 `registerTranslations`、`useI18n`、`translate`、`getLocale`、`setLocale`、`formatNumber`、`formatDateTime`、`getErrorMessage` 等公共入口。`Symbol.for('eating.ui.i18n.v1')` 让独立已安装插件各自 bundle 中的 SDK 共享语言服务；不能改成应用内部 import 或宿主枚举插件语言资源。

资源分别在 [app](../apps/web/src/i18n/app.ts)、[settings](../apps/web/src/i18n/settings.ts)、[authoring](../apps/web/src/i18n/authoring.ts)、[QQ](../plugins/communication/qq/src/web/i18n.ts)、[DSH](../plugins/harness/dsh/src/web/i18n.ts)及 [common](../packages/ui-sdk/src/locales/common.ts)。使用完整 flat semantic keys 与双语完整句，插值、复数交给库；按钮、状态、确认、空态、校验、错误、aria、编辑器诊断／补全、日期和数值都须覆盖。

全局侧栏底部原生 select 提供“简体中文 / English”，默认 `zh-CN`。`eating.locale` 仅为语言偏好，刷新保留、跨标签页 storage event 同步，无凭据。切换即时更新 document lang、标题和说明；locale 不加入网络 effect、不作为重挂 key，不丢草稿／选区／undo，不触发 POST／重启／额外日志订阅。

UI 说明面向使用者：描述当前状态、下一步和真实后果。“添加插件／启用插件”“停用插件／确认停用”对应实际动作；中文“机器人”保留，英文“Connections”；“通用提示词”替代主 Agent 标题。设置保留可靠送达仍需 AI 处理、内存退出丢失、清空不可恢复和未知先核对的提示。诊断数据与配置位置保留折叠入口；结构化错误 code 映射用户提示，未知后端原文不做主要错误文案，可在诊断详情查看。

用户名称、模型名、URL、Key、消息、JSON、协议 canonical 中文 token（如 `{{当前时间}}`）一律不翻译或改写。三份 defaultPrompt 正文是主人内容／AI 策略，保持原文，不能误判为 UI 翻译遗漏。QQ 工具名称和参数描述按稳定 ID 进行 presentation 本地化，Host 单 catalog 仍是工具和参数业务来源；未知未来 metadata 按原文回退。

## 最小使用与数据边界

1. QQ 保存 OneBot 配置后连接，开启“将收到的消息交给 AI”；群消息另需开启对应开关。
2. 在“Harness → DeepSeek Harness”填写主人独立模型地址、精确模型名和 Key，点击“保存配置”。Key 不回显，留空保留，勾选保存才清除；保存停止旧运行时。
3. 当前专属运行时已预装，可跳安装；新安装须等实际完成，提交请求不等于安装完成。
4. 点击“启动 Harness”，核对固定主会话和忙闲。ready 不是服务商认证或本轮处理成功，未知先刷新核对。

DSH 在 `EATING_HOME/harness/dsh` 使用独立双 home、工作区与固定会话，不借主 DSH、Profile、凭据或当前 GUI。通用提示词／当前人格为可信 system，外部完整批次为 user；下一请求读取更新但不换 session。普通文本和 `finalResponse` 不由 Host 代发；模型自行决定调用已批准的 9 项 QQ MCP，无原生文件／Shell／安装／人格写工具，不等于 OS 沙箱。

仅在 `sessions.flush(session) === true` 并原子写匹配 ACK 后可靠交接、删 Host 正文；ready 和 SDK 入箱不等于 fsync。忙时暂停不耗重试，恢复扫描原生持久记录，不重发未知批次、不承诺 exactly-once。QQ 四页签为“连接配置 / 实时日志 / 功能测试 / MCP 能力”；日志仅可见页签订阅、内存有界、离开清空，不建聊天历史或后台日志缓存。

Host 仅给 Harness 私有服务、只读 owner 配置与批准通讯 MCP，通讯插件不能取用。安装为 owner session／CSRF 管理 API，校验固定三包／lockfile、禁脚本、不经 Shell，超时／取消终止进程。停用先保存 disabled 并撤入口，即使 disconnect 抛错也不得恢复注册；跨 kind 升级不隐式迁移，停用保留数据、删除另需授权。
