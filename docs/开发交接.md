## 关键实现

- DSH adapter、runtime-bridge、runtime-agents管理SDK和原生Web同一进程／UUID、受控主子工具及原生clock。不能整体加载standard恢复文件／Shell权限，不传Web CLI flags污染SDK stdio。
- native-web／native-web-runtime采用公有服务，Web浏览器映射eating-reader，处理官方owner跳过policy；HTTP精确读取白名单、WS remoteAccess和真实会话树限制。冷follow只观察原生记录，不promote。
- 官方session-controller的空types模块不会形成浏览器client row：私有bridge生成同版官方client roster的no-op host，保留受限controller；不能改回会唤醒冷Agent的原版follow。
- 原生客户端三个asset随独立包安装；官方shell和chat assembly复用，自定义slot展示来源、四段标题和上下文。历史agentLabels来自原scope账号，不解析旧label。默认中文LocaleBridge只影响Eating专属页面，不写主DSH／浏览器全局设置。390px使用44px会话菜单和可关闭列表。
- agent-label辅助只管呈现，绑定键／原生UUID不变。session-view通过公开Session.fromRestore和当前message projections重放有效surface，保source／turn／step／callId／替换关系，过滤推理和密钥，不将当前binding revision当历史版本。
- Host默认common与QQ默认角色移除动态时间行；官方time-context主子scope各一次，600000ms、Asia/Shanghai，冷恢复去重，拒绝／空闲不注入。没有新增调度／时间工具。
- QQ保39标准工具，新增qq_view_received_image。message_id与image_id配对、逐次scope与await后复查；当前OneBot一次get_msg找真实图片段，公网DNS固定、禁redirect／auth、5MiB／10秒、类型校验。仅远端路径明确不可用。
- Host tool-results依据声明投影标准MCP image；普通JSON长得像MCP也不提升为图片。原生模型图片admission有独立能力gate。QQ临时Blob预览不进普通记录，取消／隐藏等撤销并拒迟到。CSP仅img-src增加blob，未放宽脚本／eval。
