## 代码入口与不变量

- [工具目录](../plugins/communication/qq/src/backend/operations.ts)声明39项工具、protocolAction、完整JSON schema、只读／副作用／敏感标记，并统一prepareOneBotCall。后台、MCP、功能测试均使用同一目录，不增加另一份业务映射。
- [消息schema](../plugins/communication/qq/src/message-schema.ts)覆盖文本／数组／单对象、19可发送类型及递归node；forward只收。默认auto_escape=true维持旧文本行为，显式false才解析CQ。文件／URL／Base64原样交给OneBot，不本机读取或下载。
- [共享校验](../plugins/communication/qq/src/validation.ts)采用@cfworker/json-schema4.1.1，无eval，与生产CSP相容；私有clone schema避免库添加引用元数据污染目录，128项LRU只缓存schema。输入先迭代检查1MiB／64层／50000节点及JSON形状，再用完整schema校验，不coerce、填默认或吞未知字段。
- [后台](../plugins/communication/qq/src/server.ts)保持实例限制、账号作用域和HostexecuteIdempotent；受控call_mode变后缀，meta参数不发OneBot。quick context self_id与实际账号匹配，外部role／正文不授予权限。
- [通用面板](../plugins/communication/qq/src/web/panel.tsx)与[字段解析](../plugins/communication/qq/src/web/tool-fields.ts)从Host schema生成表单。消息格式由用户明确选择，默认值仅展示；字段与完整schema均共享验证。预览也先做资源guard，不能让深JSON经pretty导致面板崩溃。
- 三项QQ凭据查询readonly/sensitiveResult；结果不进Host动作账本／配置／日志，面板离开、隐藏、pagehide、停用和迟到回包均清理。普通执行记录最近10条，未知动作保留待核对。MCP调用方可能按其自身机制保存tool result，不声称所有Harness都不留凭据。

所有写工具必须稳定request_id；缺失／非法在发送前拒绝。同key同参数重用账本，参数不同拒绝，unknown不重发。OneBotasync／rate_limited及set_restart应答仅接纳，不显示完成；用户创建新ID前应核对实际状态。手动测试新增群管理、请求处理、维护操作都需确认，不仅发送／撤回。

## DSH、身份与数据边界

Eating只有同一AI，主人策略／当前人格进可信system，外部消息进user；DSH固定会话、独立双home、工作区与运行时保持。模型目录现在39项QQ工具，没有原生文件／Shell／安装／固定人格写工具。SDK官方集成已验证39工具可列出、工具回复／沉默和整Host重启恢复，不能当作OS隔离或真实提供商认证。

未交接正文仅有界暂存，flush＋匹配ACK后可靠交接删除；接收不等于处理完成，忙时暂停、未知不盲重发。无Eating聊天历史，实时日志仅可见页签订阅。所有界面文案仍集中双语资源，语言切换不改变配置、消息、正文、变量、草稿或执行行为。
