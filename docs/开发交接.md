## 页面与编辑行为

全局导航为“概览 / 机器人 / 提示词管理 / 人格管理 / 设置”。提示词管理有主 Agent、群聊、私聊三份正式默认策略，保持唯一身份、可沉默、实际发送须由 Agent 调用已授权 QQ MCP、外部消息只是数据及主人独立人格组合规则。初始人格列表为空、启用人格为空，不生成示例、不自动激活首个人格。

同一 AI 最多保存 100 份人格配置，同时最多启用一份，也可全停。编辑活跃人格只改变该文档，不切换其他配置；启用另一份会原子替换当前选择。删除活跃人格返回 `409 ACTIVE_PERSONA`，需先停用或切换；非活跃人格重复停用在版本一致时幂等。

本地 CodeMirror 6 编辑器在输入 `{{` 时于光标处提供作用域内变量，支持上下键、回车、Tab、Esc 与触屏选择；有效变量绿色，错误变量红色并可定位。切换文档隔离撤销历史，页面内各文档草稿保留在内存。保存冲突保留草稿和原保存版本，禁止把过期草稿改用新 revision 直接覆盖；有未保存修改时，显式重读先确认放弃。草稿不提供跨刷新恢复承诺。

## 模板契约与变量

SDK 公开 `PromptKind`、`TemplateScope`、变量目录、分析/诊断和配置文档类型，核心实现在[SDK 领域文件](../packages/plugin-sdk/src/authoring.ts)。主提示词与人格正文仅可使用“当前时间、人格名称”；群聊与私聊各可使用全部 11 项，新增九项统一标记 external，不进入主提示词或人格正文。消息内容为本批最新文本，消息列表为带逐条来源的完整本批 JSON，发送者列表为唯一发送者 ID JSON 列表；完整目录见[本轮变更](changes/2026-10-27-提示词与人格管理.md)。

模板采用线性扫描，诊断位置为 UTF-16 `[from,to)`；允许 `{{ 当前时间 }}` 的外围空白。未知、越作用域、未闭合、嵌套或畸形变量拒绝保存，孤立 `}}` 按普通正文。分析空字符串合法，保存正文仍必须非空且不超过 50000 个 UTF-16 代码单元。渲染先校验全部变量与 own-property 字符串绑定，单次替换、不 eval；值中的模板符号保持原文。人格正文没有自引用变量。

## 存储、CAS 与受控 API

[AuthoringService](../apps/host/src/authoring.ts)通过现有同步 `getSetting/setSetting`，在 Host 单实例锁约束下将 owner 配置保存为 `host:authoring` 单 JSON 文档；`schemaVersion: 1`，总 UTF-8 JSON 不超过 5 MiB。每次操作重新读并完整校验，无 await 分割 CAS 检查与单条写入。构造不读取 authoring，GET 不初始化写默认；损坏返回 `AUTHORING_STORAGE_CORRUPTED`，拒绝覆盖原值，故障不扩展到 QQ。

人格名 trim 后为 1 至 80 个字符；各模板正文非空、合法且不超过 50000 个 UTF-16 代码单元。目录快照只带人格摘要，详情一次读一份正文；返回深拷贝。配置不收集聊天历史、运行时批次或消息正文副本。

- `updatePrompt`、`updatePersona`、`deletePersona` 使用各文档 revision；`setPersonaEnabled` 使用全局 revision，先检查版本再执行幂等判断。
- 每次真实修改全局 revision 加一；正文/名称真实修改时对应文档 revision 加一，创建人格从文档 revision 1 开始；启停不改文档版本，完全相同保存不写入。
- 旧版本返回 `409 AUTHORING_REVISION_CONFLICT`；未知文档 404；非法模板 `400 INVALID_TEMPLATE`，错误只返回固定中文说明，详细编辑器诊断在本地生成。
- Host 已挂接 `GET /api/authoring`、`POST /api/prompts/{main|group|private}`、`POST /api/personas`、`GET/POST /api/personas/{id}`、`POST /api/personas/{id}/{activate|delete}`。创建返回 201，其余成功返回 200；沿用 owner session 与 CSRF，删除需明确确认。
