# Eating 待确认问题

更新：2026-10-26。先记录已确认方向，再列尚需证据的细节；不要求负责人现在逐项回答。解决后记日期/结论/证据并同步 ADR，不删历史。

## 本轮已确认

用户选择 Harness，不永久绑定 DSH；唯一身份与 Host 不重写认知保持。模块/面板自注册已确认，Cordis 仍候选。负责人已开启首版 React + TypeScript + Vite 本地网页并选“浅色标签”，全局概览/机器人、页内插件分类与插件自有配置已实现；本轮不接真实后台/账号/Harness。依据见 [ADR-0006](decisions/ADR-0006-可替换Harness与认知边界.md)、[ADR-0007](decisions/ADR-0007-插槽式模块与界面注册.md)、[ADR-0008](decisions/ADR-0008-Cordis候选底座.md)、[ADR-0009](decisions/ADR-0009-首版React网页验证.md)。

## Q-01：DSH 适配器怎样绑定人格/能力

- 问题/重要性：DSH 的核心人格和工具需真实生效；不是要求全部 Harness 支持 Preset。
- 已知：DSH SDK 不做 Preset composition，Profile/patch 会加载。备选：外层组合或正确 agent scope/roster 扩展点；能否满足仍假设。
- 建议：P1-04 测最小路径，确有缺口再薄桥。决定者/期限：技术 Agent 提证据，重大方向负责人确认；P1-04 前。

## Q-02：各适配器的确认与断线补查

- 问题/重要性：准入不是耐久/消费/平台成功。
- 已知：DSH 无 SDK history replay/cursor，其他运行时接口未核。备选：薄持久回执、官方查询/扩展、必要时上游；内部日志解析维护成本高。
- 建议：先测窗口与最小证据，缺失明确未知，不承诺精确一次。决定者/期限：技术 Agent；重大上游改动负责人确认，Phase 2 前。

## Q-03：Host 语言和本地协议

- 问题/重要性：影响多运行时适配、Cordis 与分发。
- 已知：Node.js/TypeScript 优先，Rust 备选；无工程。IPC/stdio/socket/HTTP 均候选，可行性未验证。
- 建议：最小实验比较，不为 Cordis 强建双 Host。决定者/期限：负责人结合证据，正式工程前。

## Q-04：通用执行能力与新增能力审批

- 问题/重要性：同用户任意 Shell/文件可能绕过安装入口。
- 已知：Preset/Cordis scope 不是沙箱；DSH 原生安装参数不验主人。备选：低权限进程/OS 沙箱、受控配置/执行/网络/安装者，边界未证实。
- 建议：明确脚本、页面、MCP、远端执行、激活/升级范围并验证。决定者/期限：负责人确认权限取舍，技术 Agent 实现证据；广泛执行开放前。

## Q-05：首个记忆插件/机制与失效策略

- 问题/重要性：成长和连续性需真实可用记忆。
- 已知：由主人选择与所选 Harness 兼容者，Eating 不建第二库；未选提供方。备选本地/远端，隔离/导出/迁移/失效策略未测。
- 建议：先测实际读写与故障可见；不默认跨 Harness 通用。决定者/期限：负责人，Phase 3 前。

## Q-06：首个真实主人通讯渠道

- 问题/重要性：需真实身份验证、接收与主动联系。
- 已知：多平台插槽已确认，首个平台未选。QQ/飞书/微信等真实协议、补收和账号限制仍未核。
- 建议：先模拟注册/持久桥，再按可靠性与维护成本选择。决定者/期限：负责人，真实平台接入前。

## Q-07：唤醒/休息与资源阈值

- 问题/重要性：避免永久停摆/无界推理并尊重休息。
- 已知：各 Harness 能力不同，DSH Schedule 有漏发/重复窗口。备选自主调度/外部事件、可选兜底；阈值和意外结束判定未验证。
- 建议：受限观察后定策略，不能 Host 生成新生活任务补缺。决定者/期限：负责人确认体验/预算，技术 Agent 提数据；实验前定上限，长运行前定策略。

## Q-08：托盘还是独立后台服务

- 问题/重要性：关窗与 UI 进程退出不同。
- 已知：不靠 React 页面保活；第一版可先托盘。备选独立后台/系统服务，各平台未验证。
- 建议：先确认实际生命周期期望。决定者/期限：负责人，Phase 5 前。

## Q-09：运行存储、保留与单实例

- 问题/重要性：队列/审批/动作账本和模块归属需事务、锁与隐私策略。
- 已知：SQLite 推荐未定，同数据单主实例。驱动/迁移/锁、卸载数据保留与删除期限均未定。
- 建议：按 Phase 2 故障窗口选型，程序卸载与历史清理分开。决定者/期限：技术 Agent 提证据，负责人确认数据策略；持久队列实现前。

## Q-10：每个运行时的发行与许可证

- 问题/重要性：源码 SHA 不等于可安装制品，不应把所有 Harness 自动捆绑。
- 已知：DSH 固定源码 Node 下限/MIT 有证据；其他运行时、精确 Node/原生 ABI/notices 未核。
- 建议：分别评估内置/外接、固定版本与许可，干净系统验证。决定者/期限：技术 Agent 提证据，重大分发负责人决定；每适配器测试前定包，Phase 5 前锁清单。

## Q-11：独立 UI 组织与最终框架

- 问题/重要性：首版已确定并实现两层导航与浅色界面，最终桌面/更多管理功能仍需确认。
- 已知：负责人选择 React + TypeScript + Vite 本地网页和 labels 方案，全中文概览/机器人及插件自有面板已验证；Tauri、Cordis WebUI/Vue 和真实后台未引入。
- 建议：当前先审阅运行版，再评估桌面/后台交互，不默认引入双 UI 框架。决定者/期限：负责人确认体验，后续阶段按证据扩展。

## Q-12：主运行脉络和联系人隐私

- 问题/重要性：唯一身份不等于单个 native Session 已可行。
- 已知：eating-main 为原候选别名，未持久化；各 Harness ID/恢复语义不同。
- 建议：映射包含运行时/配置身份，测混合事件/披露；单会话方案不满足时再提替代。决定者/期限：技术 Agent，涉及产品语义由负责人决定；首次映射前、Phase 2/3 复核。

## Q-13：Cordis 最终包、版本与维护方式

- 问题/重要性：上游与 DSH vendor 名称/版本/API 不可默认兼容。
- 已知：所核上游 4.0.0-rc.12 明示未稳定，DSH vendor 为 @deepseek-ai/cordis 4.0.5；尚未安装。
- 备选：上游、DSH 维护版、必要时其他底座；建议依真实依赖/清理/发布和维护成本选，不提前 Fork。
- 决定者/期限：技术 Agent 提 P0B 结果，负责人确认最终选型；业务插件 API 冻结前。

## Q-14：前后端注册与热装卸范围

- 问题/重要性：后台/面板一侧失败不能留下越权或僵尸入口。
- 已知：模块自行贡献已确认；首版已验证随构建示例的目录/分类/组件注册与移除、配置保留，前端契约已有实现但不是外部稳定 API。manifest、后台/前端握手、外部资源加载与热装卸仍未验证。
- 备选：静态打包首期或受控动态加载、schema/自有页面；建议用 P0B 实测再定契约与重启限制。
- 决定者/期限：技术 Agent，需负责人确认体验/权限影响；模块契约和真实第三方扩展前。

## Q-15：Harness 选择/切换和历史兼容

- 问题/重要性：不能因可选运行时就悄悄丢会话/记忆或启动第二主控。
- 已知：可选择已确认，热切换/无损迁移未承诺；第二种真实 Harness 未选/未核。
- 备选：停止后选择、显式导入/迁移或保留原生历史；建议先验证排他与不兼容提示，不承诺通用转换。
- 决定者/期限：负责人定需要的切换体验，技术 Agent 提能力事实；开放选择切换前。

## Q-16：运行时最小能力集与差异展示

- 问题/重要性：可适配不等于满足持续生活所有需求。
- 已知：能力证据和调用结果需分开，不支持/未知不伪造成功；具体最小项未冻结。
- 备选：按功能依赖禁用/降级，或关键缺失时拒绝用作主控；建议逐项映射需求，记忆/恢复/权限缺口明确报告。
- 决定者/期限：技术 Agent 给可行性，负责人确认可接受产品限制；适配器对用户开放前。
