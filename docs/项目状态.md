## 本轮工程边界

- Host 迁到 [apps/host](../apps/host/)，Web 保留 [apps/web](../apps/web/)，应用分别维护包配置，根 pnpm workspace 聚合开发、构建和测试。
- [后台 SDK](../packages/plugin-sdk/src/index.ts)和[界面 SDK](../packages/ui-sdk/src/index.ts)以 `@eating/plugin-sdk`、`@eating/ui-sdk` 独立成包，当前版本 `1.0.0`，契约 `apiVersion` 为 `1`。保留 [plugin-core](../packages/plugin-core/) 的纯注册与旧持久化测试。
- [QQ](../plugins/communication/qq/)为独立 `@eating/plugin-qq` `0.2.0` 包；后台、界面和 OneBot 配置归插件所有。插件只经公开 SDK 使用 Eating 能力，不导入应用私有源码；主程序不静态捆入 QQ。
- Host 安装 CLI 从本地产物目录读取版本化后台、界面与清单，检查 SDK/API 兼容和哈希，通过暂存发布后更新激活索引；Web 动态加载 Host 提供的界面资源，共享公开界面 SDK 与 React 宿主实例。
- 安装、升级、卸载要求 Host 停止后重启；升级只改变目标插件，卸载撤销入口并保留账号数据。本轮不提供热更新、任意第三方市场下载或真实 npm 发布，已确定的 CLI 用法见[操作说明](operations/QQ配置与功能测试.md)。

## 正式 QQ 功能基线

- React/TypeScript/Vite、普通 CSS、lucide-react 与中文“概览 / 机器人”导航保留；平台分类和面板从注册目录生成。飞书、微信占位已移除，协议夹具仅在测试目录。
- QQ“连接配置”：正向统一 OneBot WebSocket，Bearer header；令牌仅写入，留空保留、显式清除。原子保存配置后断开旧连接，手动连接并取得真实登录及 `online/good` 状态后才显示已连接，有限重连；不支持反向或 API/event 分离。
- QQ“功能测试”：从后台工具 schema 动态生成，与 MCP 共用 10 项工具目录。UI 手测发送/撤回逐次确认，保留稳定请求 ID；未知结果不自动重试。
- QQ“消息记录”：展示 Host SQLite 实际收到并持久化的消息，按实例去重，面板最近 50 条，工具接口提供 before 游标；不是 QQ 全平台历史。
- QQ“MCP 能力”：专属 Streamable HTTP `/mcp/qq` 与独立 Bearer；仅显式查看配置时显示 MCP 令牌，尚未自动注册到 Harness。
- `HarnessGateway` 有唯一主 sink 注册契约及持久 inbox，区分 `pending / accepted / uncertain`；没有实际 sink，消息等待投递，`accepted` 不表示 Agent 已读。
- Host 有回环与 Host/Origin 校验、HttpOnly session、CSRF、MCP 专用 Bearer、插件 scope、进程锁和损坏配置局部报错；不构成完整 OS 恶意插件沙箱。

`EATING_HOME` 默认 `~/.eating`。QQ 账号仍为 `bot/qq-bot/accounts.json` 与 `bot/qq-bot/accounts/<稳定本地实例 UUID>/config.json`，真实 QQ 号不作目录名。本版仅一个默认实例，没有第二账号添加、切换或并行 UI。共享锁、SQLite 与 MCP 令牌仍在 `host`，本次不迁移这些数据。

新增 `plugins/installed.json` 为插件安装/激活索引，代码位于 `plugins/<pluginId>/versions/<version>`；它与 `bot` 账号数据分开。停用、卸载代码与删除账号数据是不同操作。目录、令牌权限、损坏保护与恢复约束见[数据目录与账号实例](technical/数据目录与账号实例.md)。

## 架构与 ADR

唯一身份、可替换 Harness、Host 不重写认知或人生记忆、模块独立注册与主人批准原则保持。MCP 日常工具调用不要求每次人工审批，UI 手测发送/撤回仍需逐次确认。

当前 12 份 ADR：0001/0002 Superseded；0003/0004/0005/0008 Proposed；0006/0007/0009/0010/0011/0012 Accepted。新增 [ADR-0012](decisions/ADR-0012-单仓独立包与插件加载.md)记录本轮原则，其他见[ADR 索引](decisions/项目说明.md)。Cordis 仍为候选，尚未成为实际底座。
