## 用户文案与界面语言

全局侧栏底部原生语言选择框替代“我的工作区”，提供“简体中文 / English”，默认延续简体中文。`eating.locale` 只保存浏览器语言偏好、不含凭据；刷新保留，跨标签页通过 storage event 同步。切换即时更新文档语言、页面标题与说明，以及导航、表单、状态、确认、错误、无障碍名称和日期／数值。

通用页面与独立已安装插件共用公开 UI SDK 语言服务；app、settings、authoring、qq、dsh 自带完整双语资源，不依赖应用私有 import 或宿主硬编码插件文案。UI SDK 精确依赖 `i18next 26.5.11`，用库处理插值与复数；`Symbol.for('eating.ui.i18n.v1')` 让分开 bundle 的 SDK 共享 locale。

文案围绕当前状态、下一步和操作后果。“注册插件”改为“添加插件／启用插件”，实际 disable 的“移除”改为“停用插件／确认停用”；中文“机器人”导航保留，英文为“Connections”。主提示词标题改为“通用提示词”，设置采用“消息保存方式”“合并等待时间”“暂存容量上限”。诊断详情与配置路径保留折叠入口；内存退出丢失、清空不可恢复、未知结果先核对等风险继续显示。

切换语言不重挂面板、不丢草稿、选区或撤销记录，不触发 POST、运行时重启、发送消息或增加日志订阅。用户名称、模型名、URL、Key、消息、JSON、canonical 变量（如 `{{当前时间}}`）保持原样；默认提示词正文属于主人内容和 AI 策略，不随 UI locale 翻译。QQ 工具与参数展示按 ID 本地化，Host 单 catalog 继续作为业务来源；未知提供商或未来插件 metadata 保留原文回退。

## Harness 与最小使用流程

全局导航为“概览 / 机器人 / Harness / 提示词管理 / 人格管理 / 设置”。“Harness → DeepSeek Harness”管理独立 OpenAI-compatible API 地址、精确模型名称、API Key、超时、输出 token 和可选自动启动。Key 只写不回显，留空保留，勾选并保存才清除；保存配置先停止旧运行时。

1. QQ 已连接，并开启“将收到的消息交给 AI”；群消息还需开启“将群消息交给 AI”。
2. 在 DSH 页填写主人提供的服务商地址、精确模型名与独立 Key，点击“保存配置”。
3. 当前实例专属运行时已预装，可跳过安装；新安装时等待后台实际完成。
4. 点击“启动 Harness”，核对运行状态、固定主会话与忙闲。启动就绪不证明真实服务商认证或本轮处理成功。

首版没有原生会话／聊天历史页，不借用主 DSH、Profile、现有凭据或当前 DSH GUI。真实模型认证和费用链路尚未验证。

## 消息、人格与可靠交接

Eating 只有同一个 AI。通用提示词与当前人格组成可信 system，群／私聊模板和逐条来源完整批次作为 external user 数据。修改策略或切换人格在下一请求生效，固定 session ID 不变；三份正式默认策略、空人格初态、最多 100 份人格／同时最多一份启用、11 项变量及 CAS／损坏保护保持。

DSH 自主决定是否回复并调用 QQ MCP 工具发送；普通文本和 `finalResponse` 不由 Host 自动转发。目录仍只有 9 项 `mcp__qq__…`，没有原生文件、Shell、资源、安装或固定人格写入口；不等于 OS 沙箱。QQ 当前四页签为“连接配置 / 实时日志 / 功能测试 / MCP 能力”，日志只在可见页签订阅、浏览器内存有界，离开清空。

只暂存有界未交接信封，不建 Eating 聊天历史。忙时暂停新投递、不耗重试；只有 `sessions.flush(session) === true` 并原子写入匹配批次 ACK，Host 才可靠交接并删正文。可靠接收不等于 AI 完成处理，未知先核对、不盲目重发，不承诺 exactly-once。QQ 自身回声不转投，发送防重复账本保持。

## 数据与运行边界

DSH 位于 `EATING_HOME/harness/dsh`，配置 0600、专属目录 0700，双 home、工作区和 runtime-home 分离。运行时安装校验三包固定版本及 lockfile 后原子发布，禁脚本、不经 Shell，取消／超时终止安装子进程。原生 JSONL 归所选 Harness，桥只保存有界恢复元数据，不复制历史。

Host 仅给 Harness 只读主人配置、已批准通讯 MCP 私有连接和唯一 sink 注册／wake；通讯插件拿不到这些服务。安装为 owner 管理 API，停用／停止／关闭均撤销 sink，即使 disconnect 失败也不恢复入口；跨 kind 升级不隐式迁移。
