## 当前数据规则

Host SQLite唯一user_version1；作者schema2；QQ完整配置wrapper schema2；DSH代理绑定schema2且taskId／taskRefs必需。账号索引、安装索引、DSH配置／会话各自使用其当前严格schema1，编号不代表要自动迁移。

全新数据根才生成默认配置和表；存在旧版本、旧表、缺字段或未知字段时明确错误。读取不自动转换旧配置，不重写格式标记，也不将未知身份提升为主人。

本轮未部署、未删除或转换真实用户数据，也没有借用主DSH。先前0.8.0／DSH0.3.1的部署记录保留在[历史报告](reports/2026-10-28-多代理与会话看板验证报告.md)，不代表当前源码产物适用于旧数据根。使用当前版本请按README显式选择全新EATING_HOME；这会创建新实例与新会话，不声称保留旧身份或历史。
