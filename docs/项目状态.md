## 提示词与人格管理

全局侧栏新增“提示词管理”“人格管理”，与“概览 / 机器人 / 设置”并列。提示词管理提供主 Agent、群聊、私聊三份正式中文策略默认值：保持同一 AI 身份、允许不回复、由 Agent 主动调用已授权 QQ MCP 完成实际发送、外部消息仅作数据、人格由主人独立配置后组合。首次读取只返回默认值，不写入配置。

人格列表初始为空，不生成示例或自动启用首个人格。可新增、改名、编辑正文、启停与删除，最多保存 100 份；同一 AI 同时最多启用一个，也可全部停用。切换启用原子替换当前选择，活跃人格必须先停用或切换后才能删除。人格名称 trim 后为 1 至 80 个字符，每份正文非空且不超过 50000 个 UTF-16 代码单元。

公开变量目录共 11 项：主提示词和人格正文仅可使用“当前时间、人格名称”；群聊与私聊还可使用“平台、机器人账号、会话编号、会话类型、发送者列表、消息列表、消息内容、消息数量、批次编号”，共 11 项。平台为实际 platform id，消息内容为本批最新一条文本，消息列表为带逐条来源的完整本批 JSON，发送者列表为本批唯一发送者 ID 的 JSON 列表。后九项按外部来源处理，不能用于主提示词或人格正文；不提供缺少稳定字段的变量或递归人格正文。

本地依赖 CodeMirror 6 的编辑器支持输入 `{{` 在光标处补全，合法变量绿色标记，错误变量红色标记并给出精确位置诊断；支持键盘和触屏选择。文档切换隔离撤销历史，同页各文档草稿仅留内存。保存冲突保留原草稿及保存版本，显式重新读取有未保存修改时需先确认。模板不执行代码，替换值只处理一次，其中的 `{{…}}` 保持原文。

主人配置保存在 Host 的 `host:authoring` 单 JSON setting，带 schema、全局版本与文档版本，总量不超过 5 MiB；快照只返回人格摘要，正文按单个人格读取。提示词/人格编辑和删除按各文档 CAS，启停按全局 CAS；冲突返回 409。损坏配置拒绝覆盖，只影响管理配置读取，不阻止 Host 构造或 QQ 服务。它只保存主人设置，不保存聊天历史。

## QQ、投递与存储

- QQ 仍通过正向统一 OneBot WebSocket 接收事件和调用 API。令牌仅写入，留空保留、显式清除；保存配置与手动连接分开，实际登录及 `online/good` 核验成功后才显示已连接。
- QQ 四个页签为“连接配置 / 实时日志 / 功能测试 / MCP 能力”。功能面板与 MCP 共用 9 项工具：账号、状态、版本、好友、群、单条消息、私聊发送、群发送、撤回。单条查询通过 OneBot `get_msg`，Eating 不维护本地聊天历史。
- UI 手测发送/撤回仍逐次确认，外发 `request_id` 按插件、实例和实际账号隔离。相同请求复用持久结果；结果未知不自动重做。删除历史或调整人格不删除发送防重复账本。
- 实时日志仅在页签打开、页面可见、插件启用且支持日志时订阅；默认 100 条，可选 50/100/200/500/1000，仅浏览器内存。隐藏、离开、pagehide、关闭或停用即退订清空，不补发离开期间内容，不建立后台日志缓存或文件。正常 QQ 接收不依赖打开网页。
- QQ 专属 Streamable HTTP MCP 仍使用独立 Bearer，仅显式查看配置时显示令牌；尚未自动注册到实际 Harness。QQ 空间发布/评论、反向连接和 API/event 分离仍未支持。

负责人已明确不需要聊天历史。Eating 只保存有界未交接信封，不转交消息不保存正文；可靠交接后删除正文。“设置 → 消息投递”的默认值为静默 500 ms、最长聚合 2000 ms、每批 10 条、目标 32 KiB、超时 15000 ms、拒收间隔 10000 ms、最多尝试 5 次。按会话聚合，条数/字节达到阈值提前投递；目标大小是软阈值，不是 token 数。

“队列与存储”默认本地暂存、1000 条、10 MiB、拒绝新消息，可切换仅内存或丢弃最旧 pending。容量计全部未交接信封的 UTF-8 JSON，不是整个数据库文件大小；保护 delivering/uncertain。模式切换、缩容和清空的事务/确认规则保持，发送账本和账号配置不受影响，详见[操作说明](operations/QQ配置与功能测试.md)。

仅接收端同时返回 `accepted: true`、`durable: true` 与非空回执，且本地确认提交成功后，才删除正文并累计可靠交接数；不表示模型已读、回复或完成动作。明确拒收才有限重试，超时或结果未知保留待核对。可靠回执后本地提交失败只重试本地确认，不重复调用 sink。

旧库迁移已保全全部未交接信封并删除终态正文、raw/text 副本与旧历史表，原库 VACUUM/checkpoint，不另做聊天备份。短期去重仅保留 24 小时的小哈希与回执元数据，常态最多 10000 个；SQLite 连清理也故障时，磁盘旧标识加内存后备合计最多 20000 个。细节与历史证据见[队列变更](changes/2026-10-27-投递设置与无历史队列.md)和[数据规范](technical/数据目录与账号实例.md)。
