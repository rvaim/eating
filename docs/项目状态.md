## 当前功能

- QQ 仍通过正向统一 OneBot WebSocket 接收事件和调用 API。令牌仅写入，留空保留、显式清除；保存配置与手动连接分开，实际登录及 `online/good` 核验成功后才显示已连接。
- QQ 四个页签为“连接配置 / 实时日志 / 功能测试 / MCP 能力”。功能面板与 MCP 共用 9 项工具：账号、状态、版本、好友、群、单条消息、私聊发送、群发送、撤回。单条查询通过 OneBot `get_msg`，可查询范围由协议端决定；Eating 不维护本地聊天历史。
- UI 手测发送/撤回仍逐次确认，外发 `request_id` 按插件、实例和实际账号隔离。相同请求复用持久结果；结果未知不自动重做。移除聊天历史不会删除发送防重复账本。
- 实时日志仅在页签打开、页面可见、插件启用且支持日志时订阅；默认 100 条，可选 50/100/200/500/1000，仅浏览器内存。隐藏、离开、pagehide、关闭或停用即退订清空，不补发离开期间内容，不建立后台日志缓存或文件。正常 QQ 接收不依赖打开网页。
- QQ 专属 Streamable HTTP MCP 仍使用独立 Bearer，仅显式查看配置时显示令牌；尚未自动注册到实际 Harness。QQ 空间发布/评论、反向连接和 API/event 分离仍未支持。

## 投递与存储

“消息投递”提供聚合静默时间、最长聚合等待时间、单批消息上限、批次目标大小、投递超时、拒收重试间隔、最大投递尝试次数。默认分别为 **500 ms、2000 ms、10 条、32 KiB、15000 ms、10000 ms、5 次**。按 `conversationId` 聚合，不跨会话；同会话新消息重置静默计时，最长等待从首条入队固定计时。达到条数或目标字节提前投递，单条超过目标时独立投递；目标大小是软阈值，不是 token 数或模型上下文长度。

“队列与存储”提供队列存储方式、队列消息上限、队列容量上限、队列溢出处理。默认 **本地暂存（重启恢复）、1000 条、10 MiB、拒绝新消息，保留现有队列**；也可选“仅内存（重启丢失）”及“丢弃最旧待投递消息”。界面容量单位 MB 按 MiB、KB 按 KiB 换算，实际限制为规范化信封 UTF-8 JSON 字节，包含待投递、投递中与结果未知消息；不承诺整个 SQLite 文件小于该值。

仅未交接的规范化 Harness 信封持有正文，不再保存原始 OneBot 事件或额外 text 副本；不转交的消息不存正文。接收端必须同时返回 `accepted: true`、`durable: true` 与非空 `receiptId`，本地确认提交成功后才删除正文。“已可靠交接”只代表接收端接管，不代表模型已读、回复或完成动作。超时、异常、缺少可靠凭据及结果未知均保留待核对，不自动补投；明确拒收才有限重试。

模式切换迁移现有未交接信封，事务失败保留原模式、设置与内容。拒新时显示计数、最近队列错误与实时日志准入结果，不假装排队；丢旧只裁剪最旧 pending，保护 delivering/uncertain。缩容无法满足保护条件时整次返回 409，不部分裁剪；revision 冲突保留前端草稿。清空需用户勾选确认，存在正在投递的消息时返回 409，账号配置和发送账本保留。具体操作见[配置与功能测试](operations/QQ配置与功能测试.md)。

旧 `incoming_events` 在事务中保全全部未交接信封，启动中的 delivering 转 uncertain；终态正文、raw/text 副本和旧表删除，再在原库执行一次 VACUUM/checkpoint，不另建聊天备份。旧 backlog 即使超过默认容量也保留，并显示超容量、拒绝新增。短期去重只保留哈希、小回执元数据，固定 24 小时、常态合计不超过 10000 个；SQLite 连清理也持续失败时，磁盘旧标识加内存故障缓存最多 20000 个，无正文。目录与迁移细节见[数据规范](technical/数据目录与账号实例.md)。

## 边界与后续

唯一身份、可替换 Harness、Host 不重写认知或长期人生记忆、模块独立注册与主人批准原则保持。MCP 日常工具调用不逐次人工审批，UI 手测发送/撤回仍确认。当前仍无 DSH 插件或真实 Harness 接收者；测试 sink 不代表真实认知接入，不把可靠交接写成 Agent 已读。

回环/Host/Origin、HttpOnly session、CSRF、MCP Bearer、scope、进程锁与损坏配置保护不等于完整 OS 恶意插件沙箱。长期记忆、自主活动、Tauri、Windows/Linux、多账号并行及 QQ 扩展能力仍未完成。当前共 13 份 ADR，本轮新增 Accepted [ADR-0013](decisions/ADR-0013-无历史消息与可配置投递队列.md)记录无历史与队列设置要求，状态见[索引](decisions/项目说明.md)。续接入口：[交接](开发交接.md)、[QQ 架构](architecture/QQ与平台能力.md)、[Harness 适配](architecture/Harness适配.md)。
