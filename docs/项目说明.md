## 决策与证据分级

| 标签 | 含义 | 不代表 |
| --- | --- | --- |
| 产品已确认 | 负责人认可的目标／约束 | 每项实现细节已确认或技术可行性已证明 |
| Proposed | 候选，待证据与选择 | 已最终采用 |
| Accepted | 当前已接受的决策，确认范围见各 ADR | 软件已实现或实验已通过 |
| Superseded | 原决定保留，已被后续替代 | 仍是当前规则 |
| 源码分析 | 定向阅读固定提交文档／实现 | 已在 Eating 运行 |
| 运行验证通过 | 有版本／环境／命令／实际结果 | 未覆盖场景也可用 |
| 未验证／未开始 | 没有充分证据或没有执行 | 通过、失败或保证支持 |

默认不兼容清理阶段完整构建／严格类型通过，41文件983/983含5项实际SDK、浏览器53/53；这些是历史范围。当前原生Web／时间／图片阶段增加了原生读取、clock、真实图片wire和后台只读验证，最终命令、数量及现场同步见[本轮报告](reports/2026-10-29-原生Web时间与图片验证报告.md)。自动验证只用独立临时home及回环，不能代表真实提供商识图。

## 历史验证与当前决定

重组前正式 Host＋QQ 阶段为 215 项、5 项浏览器；2026-10-27 单仓重组为 280 项、8 项浏览器及四包 pack；OneBot 目录阶段为 653 项、34 项浏览器。2026-10-28 分层阶段为 43 文件 855/855、53/53 浏览器，当时包含旧产物迁移案例。各报告保留当时版本、提交状态、数字及结论，历史目录重组映射只是源码归属事实，不要求现版保留运行时兼容。

本轮按用户顺序先提交多代理基线 efbd70e，再删除旧 API／配置／存储兼容。旧数据显式报错且原文件保持，只有用户明确要求才设计迁移；新的 EATING_HOME 代表新实例与新会话。当前 PATCH、空 Key 保持、正常重连、同版恢复、ACK 重建与幂等仍属当前业务，OneBot v11 正式协议别名与 OpenAI 接口继续有效。

当前共17份ADR，0017为Accepted的原样DSH Web决策，替代0016中的原生Web自定义界面和额外只读部分。0001／0002为Superseded，0003／0004／0005／0008为Proposed，其余为Accepted；0014的旧迁移和旧入口策略被0015替代。具体状态与替代关系见[ADR 索引](decisions/项目说明.md)。Host 最终 Cordis 底座、Tauri、长期记忆、OS 隔离、其他 Harness 及三平台完整运行仍须独立验证；回环成功不能证明付费提供商认证或真人动作成功。

## 维护

需求定义产品事实，架构解释方案，ADR 保存原因，研究保存协议与源码证据，验证报告记录实际执行。状态／交接引用正式文档，历史报告不追写成当前成果；旧决定不覆盖用户最新指令。中文正文为唯一来源，工具别名不维护重复内容。日期默认 Asia/Shanghai，不保存凭据、私人聊天或未批准软件代码。
