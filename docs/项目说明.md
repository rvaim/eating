## 决策与证据分级

| 标签 | 含义 | 不代表 |
| --- | --- | --- |
| 产品已确认 | 负责人认可的目标/约束 | 技术可行性已证明 |
| Proposed | 候选，待证据与选择 | 已最终采用 |
| Accepted | 当前已接受的决策 | 软件已实现/实验已通过 |
| Superseded | 原决定保留，已被后续决定替代 | 仍是当前规则 |
| 源码分析 | 定向阅读固定提交文档/实现 | 已在 Eating 运行 |
| 运行验证通过 | 有版本/环境/命令/实际结果 | 未覆盖场景也可用 |
| 未验证/未开始 | 没有充分证据或没有执行 | 通过、失败或保证支持 |

正式 Host + QQ 已完成完整 TypeScript 与 Vite 构建、Vitest 10 文件 215/215、Playwright 5/5；浏览器证据来自生产 `dist`、真实 Host 和临时回环 OneBot 协议夹具，开发地址 5180 已检查 pageerror 0、390px 无溢出。尚未配置真人 OneBot，不能写成真实 QQ 账号已验证；独立复核三项修复已定向PASS/SHIP，范围见正式报告。

`HarnessGateway` 已有持久 inbox 与唯一主 sink 契约，但无实际 sink；消息等待投递，`accepted` 只是准入，不等于 Agent 已读。QQ MCP 尚未注册到实际 Harness。Cordis 真实底座、Tauri、长期记忆、完整 OS 沙箱与 Windows/Linux 验证仍未完成。DSH 源码只证明其特定版本接口，不代表其他 Harness 能力等价。
