关键已证实结果：

- 小批次只保留原生 live JSONL，不生成每回合 archive；零操作仍产生 completed 与全零 changes。
- 同 request_id 同 hash 不重复 append；不同 hash 与过期 expected_sequence 拒绝。completed 回执可有界淘汰，旧请求仍不能用旧序列重复追加。
- 一个提取持锁时后续捕获可排队；另一个协调器不能启动并行提取。真实 Rust PathLock 的本地绑定也执行了这一断言。
- updater 调用前的只读提取失败可以主人显式 retry；原请求／task／raw IDs 与序列保持，不再追加。应用窗口未知的请求拒绝 retry。
- 故障分别发生在 capture intent／live 写、只读提取、archive raw／done 写、live 截断及 native meta 写时，恢复保留原文及稳定序列。
- 真实 MemoryUpdater 已写入一个实际记忆文件后立刻模拟进程崩溃：恢复回执为 unknown、阻塞新捕获，extracted_sequence 保持 0，没有第二次模型调用或记忆重写。
- 已提取前缀达到阈值才写原生 `archive_001`／`.done`；ArchiveStore 能读取完成状态与原始消息 IDs，未提取尾部不会再次作为旧批次提取。
- 官方 native privacy 先于任何 capture journal／raw 持久化；测试注册 secret 在全部写入内容中均不存在，保存的是 owner-bound reference。
- 原生 managed Session 的 append／batch／commit／config／delete 均被包装路由拒绝；官方读取继续可用。HTTP 能力与回执均经过官方鉴权，不同用户不能读另一用户 Session 回执。
- 原生 owner namespace、peer normalization 与 isolation 生效；Actor-Peer 沿用官方会话语义，不被误称为 Session ACL。
- 官方 diff 把现有记忆文件的重写分类为 updated，不用 written_uris 长度误称 added。原生 version／provenance 重写可能在正文不变时仍计 updated，未声称语义净变化。

## 真实边界与剩余限制

没有端到端 exactly-once 证明。官方 memory apply 与扩展 applied 回执没有共同原子事务；apply-start 以后、applied checkpoint 以前出现进程故障或部分错误，必须 unknown 并停止自动应用。checksum 损坏同样不从旧槽自动回退重放。没有自动解除 unknown 的接口。

重启恢复由下一次相同身份的认证请求／轮询触发。没有把凭据落盘，也没有提权启动扫描；没有请求时，重启前排队任务不会自行启动。

已验证真实本地 Rust PathLock；**没有验证 Redis 锁、跨进程／多主机进程终止、所有生产存储后端断电持久性、完整线上 auth lifespan、真实模型语义质量、向量索引服务或 Studio 浏览器渲染**。一般故障注入使用本包的本地文件与锁 fixture，不能把它等同于这些未运行场景。

提取只覆盖普通 user-stage 长期记忆，不执行 Agent Evolution／训练／session-skills。原生 auto-commit 必须关闭。服务端扩展托管后需持续使用包装应用；未包装的 stock 进程／嵌入式代码／拥有底层文件写权的调用者可以绕过 HTTP ownership guard，这类并行写入不属于已验证运行方式。

没有旧格式迁移，没有处理已有 pending native 原文，没有安装到用户服务器或替换其服务。所有代码留待审查。
